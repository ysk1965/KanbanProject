정리 · 권장

  • 옵션 A (컴팩트 프로퍼티 행) 를 추천합니다. 기존 정보 구조(라벨+값)를 유지하면서 세로 공간만 크게 줄여 위험이 낮고, 담당자 필터 등 기존 인터랙션을 그대로 살릴 수 있습니다.
  • 담당자는 개별 버튼(px-3 py-2 큰 박스) → 겹친 아바타 스택 + 요약 텍스트로 교체. 필터 토글은 아바타 클릭으로 유지.
  • 기간/태그가 비어 있을 때는 값 영역을 text-slate-500 로 옅게 처리해 "빈 큰 필드"의 시각 부담 제거.
  • 구현 위치: TaskDetailModal.tsx 1341~1617 (기간/담당자/태그 3개 블록)을 .propgrid 구조로 치환. 설명 섹션(1321~1339)·체크리스트(1620~)는 유지.
  • 디자인 토큰 준수: 카드 rounded-2xl, 행 구분선 border-foreground/[0.08], 라벨 text-xs font-bold ... text-slate-400.
