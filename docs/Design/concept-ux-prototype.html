④ 실행

싼 것부터 · 1~3번은 스키마 무변경

담당자 설계를 그대로 두기로 하면서 마이그레이션 부담이 줄었습니다. 앞의 셋만으로도 위 비교의 절반이 실현됩니다.

카드 표기 정리 — 숫자 4개 → 1개 이중 진행바·"담당 외 N개"·"진행중 N건 숨김" 제거 → 내 몫 N/M + 함께 N명 아바타. 담당자 설계는 그대로.
FE only · 1일
브레드크럼 + 기간 배지 카드마다 단계 › 주기 › 묶음 한 줄. 기간은 담긴 주기에서 상속해 표시(읽기 전용).
FE only · 1일
복잡도 3단계 게이팅 + 온보딩 3문답 sprintEnabled를 단계 값으로 일반화. 신규 보드는 1단계, 온보딩 종료 시 2단계 자동 승급.
FE + 값 확장 · 3일
태스크 날짜 파생 전환 생성 폼에서 날짜칸 제거. 기존 값은 date_override로 마킹해 ✎ 배지로 노출.
플래그 컬럼 1개 · 2일
피처 날짜 · 태스크 baseline 드롭 features.start_date/due_date, tasks.baseline_* 제거. 계획선은 "최초 담긴 주기".
마이그레이션 · 2~3일
