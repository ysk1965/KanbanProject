확정된 범위

항목결정이유
레일에 담는 사유 담당 없음 · 피쳐 없음 2종 “미담김”(백로그)은 좌측 업무 리스트가 이미 맡고 있어 역할이 겹친다. 레일 성격을 “담겼는데 정보가 빈 카드”로 좁혀 두 영역의 경계를 분명히 했다.
기본 상태 접힘 평소엔 보드 세로 공간을 돌려주고, 접힌 헤더에 사유별 건수를 남겨 누락이 숨지 않게 한다. localStorage에 유지.
기존 “미배정” 컬럼 제거 같은 카드가 컬럼과 레일에 중복으로 서는 걸 막는다. 늘 비어 있던 컬럼이 가로 폭만 먹던 문제도 함께 해소.
노출 뷰 구성원 뷰 전용 컬럼이 담당자 단위일 때만 “컬럼에 못 서는 카드”가 생긴다. Feature·JIRA 뷰와 과거 스프린트 미리보기에선 숨김.

레일 카드 해부

한 카드가 왜 여기 있는지를 카드 스스로 설명한다
피쳐 없음
리소스 정리 · 레거시 삭제
1/3정
  1. 1사유 칩 — 담당 없음 피쳐 없음. 두 조건에 걸리면 둘 다 붙는다.
  2. 2피쳐 칩 — 피쳐가 있으면 그 색으로 표시. 피쳐 없음 카드는 이 자리가 비어 결손이 눈에 보인다.
  3. 3진척 — 체크리스트 롤업(checklist_done / checklist_total).
  4. 4담당 아바타 — 있으면 이 카드가 구성원 컬럼에도 함께 서 있다는 신호. 담당 없음 카드엔 아바타가 없고, 그게 “레일 말고는 보이는 곳이 없다”는 뜻이다.
  5. 5해소 버튼 — 사유별로 붙는다. 둘 다면 버튼도 둘.
  6. 6점선 테두리 — 컬럼 카드(실선)와 구분되는 “아직 자리 못 잡음” 신호.
사유판정해소 경로해소 후
담당 없음 담당자·외주 관리담당이 모두 없음 (구성원 컬럼 라우팅 keysOf의 __none__와 동일 규칙) 구성원 컬럼으로 드롭 · “담당 지정” 버튼 → 태스크 상세 레일에서 빠지고 해당 구성원 컬럼에 선다
피쳐 없음 feature_id == null “피쳐 지정” 버튼 → 피쳐 선택 모달 taskAPI.moveTaskToFeature 후 레일에서 빠진다
담당 지정이 상세 모달로 가는 이유

v7.0부터 담당자는 태스크가 아니라 체크리스트 줄에 붙는다(taskAPI에 assignee_id가 없다). 그래서 버튼은 태스크 상세를 열어 줄 단위로 지정하게 하고, 드래그 드롭이 “담당이 빈 줄을 한 번에 그 사람으로 채우는” 일괄 경로다. 이미 누군가 잡고 있는 줄은 건드리지 않는다 — 드롭 한 번이 남의 담당을 덮어쓰면 안 되기 때문. 체크리스트가 하나도 없는 태스크는 담당을 붙일 자리가 없어, 안내 토스트와 함께 상세로 보낸다.

구현

전부 프론트 — 백엔드·마이그레이션 변경 없음
요소내용
uncategorized 담긴 카드(sprint_column_id) 중 미완료만 훑어 사유 배열을 붙인다. END 컬럼·completed 카드는 제외 — 레일은 지금 해결할 것만 담는다. 상단 필터바의 피쳐 필터를 그대로 반영. 정렬은 담당 없음 우선 → 긴급도.
memberColumns __none__ 키를 컬럼 목록에서 제외. 미배정 컬럼과 그 isNone 분기 전부 제거.
레이아웃 보드 영역을 flex flex-col로 바꾸고 컬럼 스트립(flex-1 min-h-0 overflow-x-auto) 아래에 레일을 붙였다. 미리보기·JIRA·Feature 뷰에선 렌더하지 않는다.
드롭 분기 uncatDragRef로 “레일에서 시작된 드래그”를 표시하고, 구성원 컬럼 onDrop이 컬럼 이동 대신 담당 배정을 태운다. 카드는 이미 스프린트에 담겨 있어 소속 컬럼은 건드리지 않는다.
담당 배정 checklistAPI.patchItem을 담당 없는 줄에 순차 적용 후 보드 재조회. run()은 중복 호출·실패를 삼켜 성공 토스트와 어긋나므로 직접 busyRef/try-catch로 돌린다.
피쳐 지정 MotionModal 기반 선택 모달 + taskAPI.moveTaskToFeature. 레일이 overflow-x-auto 컨테이너라 인라인 드롭다운은 잘린다 — 모달이 유일하게 안전한 표면이다.
상태 유지 접힘은 bridge:sprint-uncategorized:collapsed에 저장(기본 접힘). 고른 사유가 0건이 되면 필터를 자동으로 “전체”로 되돌린다.
확장 여지

사유는 UncatCause 유니온 하나로 모여 있어, 나중에 “미담김”이나 “마감 없음” 같은 칩을 붙이려면 판정 한 줄과 칩 하나만 추가하면 된다.
