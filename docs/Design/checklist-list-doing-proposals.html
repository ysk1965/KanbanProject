체크리스트 리스트 뷰 — DOING 상태 표시 방안

TaskDetailModal · CheckList 리스트 모드 개선 제안 (5안 비교)

현재 문제 — 리스트 뷰는 완료 초록 체크와 미완료 빈 원, 딱 2가지만 구분합니다. 보드 모드에는 있는 DOING(진행 중)이 리스트에서는 안 보입니다.

이미 있는 것 — 상태 파생 규칙은 구현돼 있습니다 (utils/checklistStatus.ts):
· done = completed === true
· doing = 미완료 & start_date ≤ 오늘 (마감 지나도 미완료면 DOING 유지)
· todo = 미완료 & 시작일이 미래이거나 없음
→ 저장값이 아니라 매 렌더 계산이라, 리스트 행에 resolveChecklistColumn(item, today)만 호출해 표현하면 됩니다. 백엔드/DB 변경 불필요.

추천 — 방안 3(컬러 바) + 방안 1(뱃지)의 절충, 또는 방안 2

가장 안전한 선택은 방안 2(3단계 체크박스)입니다. 레이아웃을 전혀 안 바꾸고, 보드 모드의 인디고=DOING 색과 일관되며, 상태 파생 함수만 재사용하면 됩니다. 단 체크박스 클릭 의미가 흐려지지 않도록 DOING 점 클릭 = 완료 토글임을 tooltip/aria로 명확히.

"진행중을 확실히 보여주고 싶다"가 핵심이면 방안 1(뱃지) 또는 방안 5(펄스)가 표현력이 가장 큽니다. 방안 5는 진행중만 강조해 개입이 최소지만 모션 접근성 처리가 필요합니다.

방안 4(그룹)는 표현은 가장 강력하나, 이 프로젝트의 수동 정렬(feature_position) + 드래그 정렬과 충돌하므로 이번 목적엔 과합니다.

모든 안 공통: 백엔드 변경 없음 · resolveChecklistColumn(item, today) 재사용 · ChecklistItemRow 한 곳만 수정. 원하시는 안 알려주시면 바로 구현하겠습니다.
