03

ConnectingPage 컴포넌트를 만든다

위 목업이 그대로 이 컴포넌트입니다. 기존 MaintenancePage· NightShutdownPage 와 같은 폴더·같은 토큰을 쓰고, attempt / nextRetryIn / navigator.onLine 세 값만 props 로 받습니다. window.addEventListener('online') 으로 복구 시 즉시 재시도합니다.

번외 — index.html 의 #root 안에 인라인 스플래시(위 “부팅” 상태)를 넣어두면 JS 번들이 뜨기 전 흰/검은 빈 화면 구간도 메워집니다. React 가 마운트되면 자동으로 덮어씁니다. CSS·마크업 모두 인라인이라 추가 요청이 없습니다.
