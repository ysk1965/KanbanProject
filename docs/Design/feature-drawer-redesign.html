  1. 스크롤 안에서만 존재하는 목록

    본문이 max-h-[70vh] overflow-y-auto인데 카드 7장 × 100px+ = 약 900px. 뷰포트에 3.5장만 들어가고 첫 항목이 반쯤 잘린 채 열린다. 설정 화면의 첫 임무 — 선택지 전체를 한눈에 보여주는 것 — 을 못 한다.

  2. 두 축이 같은 모양

    레벨은 택1 사다리, 옵션은 각각 독립 스위치인데 둘 다 같은 rounded-xl 카드 + 같은 인디고 테두리·틴트를 쓴다. 규칙이 다른 것은 모양도 달라야 한다.

  3. 인디고가 다섯 곳

    선택된 레벨 1개 + 켜진 옵션 4개 = 강조색 블록이 5개. 강조가 다섯이면 강조가 아니다. 켜진 상태를 카드 전체 틴트로 칠하니 목록이 색 덩어리로 읽힌다.

  4. 항상 펼쳐진 3줄 설명

    설명은 처음 한 번 읽는 문장인데 매 방문마다 카드 높이의 70%를 먹는다. 이미 아는 사람에게는 소음, 스크롤의 주범.

  5. 눌리지 않는 링크색

    “나타나는 자리 · …”가 teal(text-bridge-secondary)이라 링크로 보이는데 아무 일도 안 난다. 가짜 어포던스이고, 자리를 글로 지목하는 것 자체가 그림으로 대체돼야 할 신호다.

  6. 사다리가 사다리로 안 보임

    3이 2를 포함한다는 누적 구조를 1./2./3. 숫자와 “0겹/1겹/2겹” 글자로만 전달한다. 세로로 쌓인 카드 3장은 사다리가 아니라 그냥 목록이다.

  7. 결과 미리보기가 없다

    “컬럼을 사람으로 세웁니다”를 말로 설명한다. 이 모달이 바꾸는 건 화면 구조인데, 그 화면을 보여주지 않는다. 가장 큰 손실.

  8. 현재 조합 요약이 없다

    헤더가 제목 한 줄뿐. “지금 이 보드가 무슨 설정인지”를 알려면 스크롤해서 체크 표시를 찾아야 한다.

  9. 즉시 저장인데 저장 신호가 없다

    토글은 optimistic 즉시 반영인데 푸터 버튼은 “닫기”뿐. 저장 안 하고 닫는 건가? 하는 불안을 매번 만든다. 저장 표시는 토글 위 스피너 한 순간이 전부.

  10. 권한 없는 상태가 죽어 보이지 않음

    canEdit=false면 레벨 버튼이 disabled지만 시각적 변화가 없다(토글에만 opacity-40). 눌러도 반응 없는 UI가 된다.

구현

FeatureDrawer.tsx 에서 바뀌는 지점

데이터 계약(BoardUiConfig · useBoardFeatures)은 그대로다. 바뀌는 건 이 파일의 마크업과, OPTIONS 스펙에 한 줄 요약과 프리뷰 타깃 키를 추가하는 것뿐이다.

OptionSpec
desc 옆에 summary(≤22자 한 줄) 추가. where는 문자열 표시용에서 프리뷰 하이라이트 타깃으로 역할 변경 — target: 'sprintHeader' | 'columns' | 'checklist' | 'viewTabs'.
LEVELS
세로 button 3개 → role="radiogroup" 안 가로 세그먼트 3칸. desc는 카드 안이 아니라 선택된 것 하나만 사다리 아래 한 줄로. 겹 수는 막대 i 개수로 시각화.
델타 칩
LEVEL_DELTA[level] = { adds: [...], hides: [...] } 상수 추가. 레벨을 내릴 때 무엇이 숨는지를 칩으로 미리 말한다 — “마음 놓고 내리게 한다”는 원 설계 의도를 글이 아니라 UI로.
옵션 행
grid-cols-[3px_1fr_auto] — 레일 / 본문 / 토글. 틴트(bg-bridge-accent/[0.07])와 테두리 강조 제거, 켜짐은 레일 + 토글 색만. 설명은 useState<Set>로 행 단위 펼침.
잠긴 행
하단 문단 삭제. LOCKED 상수 3건(완료 컬럼 / 묶음▸작업▸할 일 / 할 일 담당자)을 같은 목록에 aria-disabled 행으로. 토글은 켜진 채 cursor-not-allowed.
BoardPreview
신규 컴포넌트 components/board/BoardMiniPreview.tsx. props = { level, options, highlight? }. 순수 프레젠테이션, 데이터 접근 없음. 옵션 행 hover 시 highlight로 해당 영역 링 애니메이션(useReducedMotion 분기).
헤더
제목 오른쪽에 요약 칩 2개 — 레벨명 / 옵션 n / 4. canEdit=false면 자물쇠 칩은 유지하되 컨트롤 전체를 opacity-50 pointer-events-none 로 감싸 죽은 UI를 죽어 보이게.
푸터
saving이 끝난 뒤 2초간 “저장됨” 표시(useEffect 타이머). 버튼 문구 닫기 → 완료 — 즉시 저장이라는 사실과 어긋나지 않는 말.
폭
sm:max-w-lg → sm:max-w-3xl. 본문 max-h-[70vh] overflow-y-auto는 남기되 실제로는 걸리지 않는다(모바일 안전장치). 프리뷰는 hidden md:flex + 모바일 접이식.
