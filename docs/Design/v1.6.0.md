# Design System v2.0.0 - BRIDGE Unified Token System

> **v2.0.0 통일 토큰 오버홀**: Organization / Board / MySpace 전 서비스에 걸쳐 디자인 토큰을 통일했습니다. `border-black/5 dark:border-white/5` 등 Tier 2 패턴을 `border-foreground/[0.08]` Tier 1 패턴으로 교체하고, 회색톤을 `slate-`로 통일하며, 뱃지/모달/버튼/입력 필드 스타일을 전면 표준화했습니다.

## 3-Tier 테마 시스템 [v2.0.0 CORE]

### 개요

| Tier | 방식 | `dark:` 필요 | 용도 |
|------|------|-------------|------|
| 1 | Bridge Colors + foreground (CSS Variables) | **불필요** (자동 전환) | 배경, 테두리, 카드, 모달 |
| 2 | `dark:` Prefix (Tailwind) | **필요** | Status 뱃지 텍스트 색상만 |
| 3 | BlockNote Colors | **불필요** | 노트 에디터 전용 |

### Tier 1: Bridge Colors (자동 전환) -- 권장

CSS 변수이므로 `dark:` 접두사 없이 자동으로 모드 전환된다. **v2.0.0에서 전 서비스 기본.**

```tsx
// 배경
<div className="bg-bridge-dark" />              // #191f2d <-> #fffcf8
<div className="bg-bridge-obsidian" />          // #151B28 <-> #efe6d8
<div className="bg-bridge-surface" />           // #1e2a42 <-> #efe3d2

// 텍스트
<span className="text-foreground" />            // oklch(0.985) <-> #3D2E1F
<span className="text-muted-foreground" />      // oklch(0.75) <-> #8C7B6B

// 테두리
<div className="border-foreground/[0.08]" />    // 카드 기본 테두리
<div className="border-foreground/10" />        // 인풋/모달 테두리

// 호버
<div className="hover:bg-foreground/5" />       // 통일 호버

// 액센트
<span className="text-bridge-accent" />         // #6366F1
<span className="text-bridge-secondary" />      // #2DD4BF <-> #14B8A6
```

### Tier 2: `dark:` Prefix -- Status 뱃지 텍스트 전용

v2.0.0에서 **Status 뱃지 텍스트 색상에만** 사용. 배경/테두리는 Tier 1으로 통일.

```tsx
// Status 뱃지 (텍스트만 dark: 분기, BG는 고정)
<span className="bg-emerald-500/15 text-emerald-600 dark:text-emerald-400" />
<span className="bg-amber-500/15 text-amber-600 dark:text-amber-400" />
<span className="bg-red-500/15 text-red-600 dark:text-red-400" />
<span className="bg-purple-500/15 text-purple-600 dark:text-purple-400" />
```

### Tier 3: BlockNote Colors (에디터 전용)

`data-color-scheme` 속성으로 자동 전환. `dark:` 접두사 불필요.

### 사용 가이드: 요소별 권장 Tier

| 요소 | Tier | 패턴 |
|------|------|------|
| 페이지 배경 | 1 | `bg-bridge-dark` |
| 카드/섹션 배경 | 1 | `bg-bridge-obsidian` |
| 입력 필드 배경 | 1 | `bg-foreground/[0.03]` |
| 모달 배경 | 1 | `bg-bridge-obsidian` |
| Primary 텍스트 | 1 | `text-foreground` |
| Secondary 텍스트 | -- | `text-slate-400` |
| 기본 테두리 | 1 | `border-foreground/[0.08]` |
| 인풋 테두리 | 1 | `border-foreground/10` |
| 액센트 | 1 | `text-bridge-accent`, `bg-bridge-accent` |
| 포커스 링 | 1 | `focus:ring-bridge-accent/50` |
| Status 뱃지 텍스트 | 2 | `text-emerald-600 dark:text-emerald-400` |

### v2.0.0 마이그레이션: 폐기된 패턴

```tsx
// DEPRECATED -- 더 이상 사용하지 않는 패턴
border-black/5 dark:border-white/5     // -> border-foreground/[0.08]
border-black/10 dark:border-white/10   // -> border-foreground/10
bg-black/5 dark:bg-white/5             // -> bg-foreground/5
text-slate-900 dark:text-white         // -> text-foreground
hover:bg-black/5 dark:hover:bg-white/5 // -> hover:bg-foreground/5
placeholder-slate-600                  // -> placeholder-slate-500
```

## 타이포그래피 [v2.0.0 UPDATE]

### 폰트 패밀리

- **Heading (Landing)**: `font-jakarta` (Plus Jakarta Sans)
- **Body (Landing)**: `font-inter` (Inter)
- **Heading (App)**: `font-serif` (serif 계열)

### 폰트 웨이트 제한 [v2.0.0 MANDATORY]

**`text-xs` (12px) 미만 사용 금지.** `text-[8px]` ~ `text-[11px]` 사용 금지 (랜딩 페이지 장식용 제외).

| 접두사 | 최소 너비 | 대표 기기 |
|--------|-----------|-----------|
| (없음) | 0px | 모바일 |
| `sm:` | 640px | 큰 모바일 |
| `md:` | 768px | 태블릿 |
| `lg:` | 1024px | 데스크톱 |
| `xl:` | 1280px | 넓은 데스크톱 |
| `2xl:` | 1536px | 대형 모니터 |

### Responsive Patterns [v2.0.0 통일]

```tsx
{/* 모달: 모바일 바텀시트 -> 데스크톱 센터 */}
className="rounded-t-2xl sm:rounded-2xl"
className="items-end sm:items-center"

{/* 사이드바: 모바일 오버레이 -> 데스크톱 고정 */}
className="fixed md:relative w-[300px] md:w-[340px] -translate-x-full md:translate-x-0"

{/* 그리드 반응형 (grid-cols-N, N>=3 시 브레이크포인트 필수) */}
className="grid grid-cols-2 lg:grid-cols-4 gap-4"
className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4"

{/* 텍스트 반응형 */}
className="text-xs md:text-sm"
className="text-xl md:text-2xl"

{/* 패딩 반응형 */}
className="p-3 md:p-5"
className="px-3 md:px-5 py-2 md:py-3"
```

### Flex Direction Change

```tsx
<div className="flex flex-col md:flex-row gap-4">
  <div className="w-full md:w-1/3">사이드 패널</div>
  <div className="w-full md:w-2/3">메인 컨텐츠</div>
</div>
```

### Mobile Overlay Pattern

```tsx
{/* 데스크톱: 사이드바 */}
<div className="hidden md:block w-80 border-l border-foreground/[0.08]">
  <Panel />

{/* 모바일: 오버레이 */}
<div className="md:hidden fixed inset-0 z-50 bg-bridge-dark/95">
  <Panel onClose={handleClose} />
</div>
```

### Horizontal Scroll Tabs (Mobile)

```tsx
<div className="flex overflow-x-auto scrollbar-hide gap-1 px-4 border-b border-foreground/[0.08]">

    <button key={tab.id} className="whitespace-nowrap px-3 py-2 text-sm flex-shrink-0">

    </button>
  ))}
```

## Dark/Light Mode

### Structure

- **기본**: 다크 모드
- **전환**: `ThemeContext.tsx`에서 `toggleTheme()` 호출
- **저장**: `localStorage` 및 서버 (User.theme 필드)
- **적용**: CSS 변수 + Tailwind `.dark` / `.light` 클래스

```css
/* theme.css */
:root { /* 다크 모드 기본 변수 */ }
.dark { /* shadcn/ui OKLCH 다크 오버라이드 */ }
.light { /* Bridge + shadcn 라이트 오버라이드 */ }
```

### Light Mode Colors (Warm Theme)

| 변수 | Dark Mode | Light Mode | 설명 |
|------|-----------|------------|------|
| `--bridge-dark` | `#191f2d` | `#fffcf8` | 메인 배경 (웜 화이트) |
| `--bridge-obsidian` | `#151B28` | `#efe6d8` | 카드 배경 (라이트 탄) |
| `--bridge-accent` | `#6366F1` | `#6366F1` | 인디고 (동일) |
| `--bridge-secondary` | `#2DD4BF` | `#14B8A6` | 틸 (조정) |
| `--bridge-surface` | `#1e2a42` | `#efe3d2` | 서피스 |
| `--bridge-surface-hover` | `#2a3a58` | `#ffffff` | 서피스 호버 |
| `--bridge-border` | `#384d6e` | `#E4DFDA` | 강조 테두리 (웜 탄) |
| `--background` | `#0A0E17` | `#FFFDF9` | 페이지 배경 |
| `--foreground` | `oklch(0.985)` | `#3D2E1F` | 텍스트 (다크 브라운) |
| `--primary` | `oklch(0.985)` | `#6366F1` | Primary (인디고) |
| `--border` | `oklch(0.269)` | `#E4DFDA` | 테두리 |
| `--ring` | `oklch(0.439)` | `#D4B483` | 포커스 링 (골드) |
| `--muted-foreground` | `oklch(0.75)` | `#8C7B6B` | Muted 텍스트 |
| `--destructive` | `oklch(0.396)` | `#EF4444` | 위험/삭제 |

### Theme Design Philosophy

**Dark Mode**: Deep navy 기반 (`#191f2d`). 차가운 톤, 높은 대비, 인디고/틸 액센트.
**Light Mode**: Warm cream 기반 (`#fffcf8`). 따뜻한 톤, 부드러운 대비, 베이지/탄 서피스, 골드 포커스 링.

## Tailwind CSS v4 Configuration

### CSS-First Setup

**설정 파일:** `frontend/src/styles/tailwind.css`
- `@import 'tailwindcss' source(none)` - Tailwind 코어
- `@source '../**/*.{js,ts,jsx,tsx}'` - 소스 스캔 경로
- `@import 'tw-animate-css'` - 애니메이션 유틸리티

- `@theme inline` 디렉티브로 디자인 토큰 정의
- Bridge 컬러 7종 + Surface Elevation 4종 + Border Scale 4종 + Shadow Tokens 5종
- shadcn 시맨틱 토큰 + Sidebar 토큰 + Chart 컬러 5종 + Radius 4종

### OKLCH Color Space

shadcn/ui 시맨틱 색상은 OKLCH 색상 공간 사용:

**Dark Mode:**
- `--background: oklch(0.145 0 0)`
- `--foreground: oklch(0.985 0 0)`
- `--muted-foreground: oklch(0.75 0 0)`
- `--destructive: oklch(0.396 0.141 25.723)`

**Light Mode:**
- `--foreground: oklch(0.145 0 0)`
- `--secondary: oklch(0.95 0.0058 264.53)`

## Component Rules (20 Rules) [v2.0.0 MANDATORY]

새 컴포넌트 작성 시 반드시 준수해야 하는 규칙:

| # | 규칙 | 설명 |
|---|------|------|
| 1 | **Bridge Colors** | 하드코딩 금지. `bridge-dark`, `bridge-obsidian` 사용 (자동 테마 전환) |
| 2 | **테두리** | `border-foreground/[0.08]` 전 서비스 통일. `border-black/5 dark:border-white/5` 사용 금지 |

| 4 | **호버** | `hover:bg-foreground/5` 통일 |
| 5 | **라운드** | 카드 `rounded-2xl`, 버튼/인풋 `rounded-xl`, 작은 요소 `rounded-lg`, 뱃지 `rounded-full` |
| 6 | **아이콘** | Lucide React (`import { Plus } from 'lucide-react'`) |
| 7 | **애니메이션** | Framer Motion -- `y: 8` 통일, delay: `index * 0.04`, `useReducedMotion()` 훅 대응 |
| 8 | **모달** | `MotionModal` 컴포넌트 (role=dialog, aria-modal, 포커스 트랩). padding 통일 |
| 9 | **뱃지 BG** | `/15` 통일. Status 텍스트만 `dark:` 분기 |
| 10 | **로딩** | `<Loader2 className="w-6 h-6 animate-spin text-bridge-accent" />` (커스텀 spinner 금지) |
| 11 | **placeholder** | `placeholder-slate-500` 통일 |
| 12 | **포커스** | `focus:outline-none focus:ring-2 focus:ring-bridge-accent/50` 통일 |
| 13 | **회색톤** | `slate-` 통일 (`zinc-` 사용 금지) |
| 14 | **스크롤바** | `custom-scrollbar` 통일 (`kanban-scrollbar` 사용 금지) |
| 15 | **아이콘 버튼** | `IconButton` 컴포넌트 (44x44px 최소 터치타겟, `aria-label` 필수) |
| 16 | **모바일 내비** | `MobileBottomNav` -- md:hidden, 5탭, safe-area 대응 |
| 17 | **접근성** | 아이콘 전용 버튼에 `aria-label` 필수. 이미지에 의미 있는 `alt` 텍스트 |
| 18 | **반응형 그리드** | `grid-cols-N` (N>=3) 사용 시 반드시 `sm:`/`md:` 브레이크포인트 포함 |
| 19 | **폰트 웨이트** | `font-normal`(400), `font-medium`(500), `font-bold`(700) 3종만 허용 |
| 20 | **최소 텍스트** | `text-xs` (12px) 미만 사용 금지 (랜딩 페이지 장식용 제외) |

## Change History

### v1.6.0 (2026-03-20) -- Design System v2.0.0 Unified Token Overhaul

**BREAKING CHANGE**: 전 서비스(Organization / Board / MySpace) 디자인 토큰 통일.

- **3-Tier 테마 시스템 전면 적용**
  - Tier 1 (Bridge Colors + foreground) 기본화. `dark:` Prefix는 Status 뱃지 텍스트에만 허용
  - Tier 2 패턴 (`border-black/5 dark:border-white/5`, `bg-black/5 dark:bg-white/5`, `text-slate-900 dark:text-white`) 전면 폐기
  - `border-foreground/[0.08]`, `bg-foreground/5`, `text-foreground`로 통일

- **테두리 토큰 통일**
  - 카드/패널: `border-foreground/[0.08]` (전 서비스)
  - 카드 호버: `hover:border-foreground/[0.12]`
  - 인풋/모달: `border-foreground/10`
  - Board 블록: `border-bridge-border`

- **뱃지 시스템 표준화**
  - BG 투명도: `/15` 통일 (`/10`, `/20` 사용 금지)
  - Status 텍스트만 `dark:` 분기 (`text-emerald-600 dark:text-emerald-400`)
  - Mention 블록: `bg-bridge-accent/20` -> `bg-bridge-accent/15`

- **타이포그래피 제한 강화**
  - 최소 텍스트 크기: `text-xs` (12px) 미만 금지
