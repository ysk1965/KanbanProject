### Foreground 투명도 시스템

마이스페이스 및 앱 전반에서 사용하는 `foreground` 기반 투명도 레이어링 시스템. 다크/라이트 모드 자동 대응.

| 토큰 | 용도 | 사용 예 |
|------|------|---------|
| `foreground/[0.01]` | 극미세 배경 | 빈 영역 힌트 |
| `foreground/[0.03]` | 초미세 배경 | 입력 필드 배경 (`bg-foreground/[0.03]`) |
| `foreground/[0.04]` | 미세 배경 | 인라인 입력 래퍼 |
| `foreground/5` | 약한 배경 | 호버, 비활성 버튼 (`bg-foreground/5`) |
| `foreground/[0.06]` | 위젯 헤더 | WidgetCard 헤더 배경 |
| `foreground/10` | 테두리/호버 | 기본 테두리, 강한 호버 (`border-foreground/10`) |
| `foreground/[0.08]` | 구분선 | 모달 내부 divider (`border-foreground/[0.08]`) |
| `foreground/[0.12]` | 카드 테두리 | 모달/위젯 외곽선 (`border-foreground/[0.12]`) |
| `foreground/15` | 강조 호버 | 입력 호버 테두리 |

### Assignee Colors (담당자 색상)

칸반 보드에서 멤버별 시각적 구분을 위한 6색 시스템. `frontend/src/app/utils/assigneeColor.ts`에 정의.

| 이름 | HEX | Tailwind BG | Light BG | Text |
|------|-----|-------------|----------|------|
| Indigo | `#6366F1` | `bg-indigo-500` | `bg-indigo-500/20` | `text-indigo-300` |
| Purple | `#8B5CF6` | `bg-purple-500` | `bg-purple-500/20` | `text-purple-300` |
| Teal | `#14B8A6` | `bg-teal-500` | `bg-teal-500/20` | `text-teal-300` |

**사용법:**
- `getAssigneeHex(name, customColor?)` - 인라인 스타일용 HEX 값
- `getAssigneeClasses(name, customColor?)` - Tailwind 클래스 객체 (`{ hex, bg, bgLight, text }`)
- 미지정 시 이름 해시 기반 자동 색상 할당
- Backend: `board_members.assignee_color` (VARCHAR(20), nullable)

### 폰트 패밀리

- **Heading (Landing)**: `font-jakarta` (Plus Jakarta Sans)

### MotionModal (기본 모달) [v1.5.0 UPDATE]

**파일:** `frontend/src/app/components/ui/MotionModal.tsx`

마이스페이스 전체에서 사용하는 통합 모달 컴포넌트. Framer Motion 기반.

#### Backdrop (오버레이)

```tsx
<motion.div
  className="fixed inset-0 z-50 flex items-end sm:items-center justify-center sm:p-4"
  initial={{ backgroundColor: 'rgba(0,0,0,0)', backdropFilter: 'blur(0px)' }}
  animate={{ backgroundColor: 'rgba(0,0,0,0.2)', backdropFilter: 'blur(2px)' }}
  exit={{ backgroundColor: 'rgba(0,0,0,0)', backdropFilter: 'blur(0px)' }}
  transition={{ duration: 0.3 }}
/>
```

#### Container

```tsx
<motion.div
  className="w-full sm:max-w-md bg-bridge-obsidian rounded-t-2xl sm:rounded-2xl

  initial={{ opacity: 0, y: 20, scale: 0.98 }}
  animate={{ opacity: 1, y: 0, scale: 1 }}
```

## 다크/라이트 모드

### 구조

- **기본**: 다크 모드
- **전환**: `ThemeContext.tsx`에서 `toggleTheme()` 호출
- **저장**: `localStorage` 및 서버 (User.theme 필드)
- **적용**: CSS 변수 + Tailwind `.dark` / `.light` 클래스

```css
/* theme.css */
:root { /* 다크 모드 기본 변수 */ }
.dark { /* shadcn/ui OKLCH 다크 오버라이드 */ }
.light { /* Bridge + shadcn 라이트 오버라이드 */ }
```

### 3-Tier 테마 시스템

| Tier | 시스템 | 모드 전환 방식 | `dark:` 접두사 필요 |
|------|--------|---------------|-------------------|
| 1 | **Bridge Colors** (CSS Variables) | `.light` 클래스로 변수값 자동 변경 | **불필요** |
| 2 | **`dark:` Prefix** (Tailwind) | 클래스 조건부 적용 | **필요** |
| 3 | **BlockNote Colors** | `data-color-scheme` 속성 | **불필요** |

#### Tier 1: Bridge Colors (자동 전환)

CSS 변수이므로 `dark:` 접두사 없이 자동으로 모드 전환된다. 가장 권장하는 방식.

```tsx
// ✅ dark: 접두사 불필요 - 자동 전환
className="bg-bridge-dark"           // #191f2d (dark) → #fffcf8 (light)
className="bg-bridge-obsidian"       // #151B28 (dark) → #efe6d8 (light)
className="text-bridge-accent"       // #6366F1 (양쪽 동일)
className="text-bridge-secondary"    // #2DD4BF (dark) → #14B8A6 (light)
className="border-bridge-border"     // #384d6e (dark) → #E4DFDA (light)
className="bg-bridge-surface"        // #1e2a42 (dark) → #efe3d2 (light)
```

`foreground`, `muted-foreground` 등 shadcn 시맨틱 토큰도 `.dark` 클래스로 자동 전환:

```tsx
// ✅ 시맨틱 토큰 - 자동 전환
className="text-foreground"          // oklch(0.985 0 0) (dark) → oklch(0.145 0 0) (light)
className="text-muted-foreground"    // oklch(0.75 0 0) (dark) → #717182 (light)
className="bg-foreground/5"          // 자동으로 밝은/어두운 배경 생성
className="border-foreground/10"     // 자동으로 밝은/어두운 테두리 생성
```

#### Tier 2: `dark:` Prefix (수동 전환)

Tailwind 기본 색상(`black`, `white`, `slate` 등)은 고정값이므로 `dark:` 접두사로 모드별 분기가 필요하다.

```tsx
// 배경
className="bg-black/5 dark:bg-white/5"             // 입력 필드, 보조 배경
className="bg-black/10 dark:bg-white/10"            // 호버 상태

// 테두리
className="border-black/5 dark:border-white/5"      // 기본 테두리
className="border-black/10 dark:border-white/10"    // 강조 테두리

// 텍스트
className="text-slate-900 dark:text-white"          // Primary 텍스트
className="text-slate-500 dark:text-slate-400"      // Secondary 텍스트
className="text-slate-600 dark:text-slate-500"      // Tertiary 텍스트
className="placeholder-slate-400 dark:placeholder-slate-600"

// 호버
className="hover:bg-black/10 dark:hover:bg-white/10"

// 뱃지 (Status Colors)
className="text-emerald-600 dark:text-emerald-400"  // Success
className="text-amber-600 dark:text-amber-400"      // Warning
className="text-red-600 dark:text-red-400"          // Danger
className="text-purple-600 dark:text-purple-400"    // Info
```

#### 사용 가이드: 언제 어떤 Tier를 쓸 것인가

| 요소 | 권장 Tier | 패턴 |
|------|-----------|------|
| 페이지 배경 | Tier 1 | `bg-bridge-dark` |
| 카드/섹션 배경 | Tier 1 | `bg-bridge-obsidian` |
| 입력 필드 배경 | Tier 2 | `bg-black/5 dark:bg-white/5` |
| 모달 배경 | Tier 1 | `bg-bridge-obsidian` |
| Primary 텍스트 | Tier 1 | `text-foreground` (마이스페이스) 또는 Tier 2 `text-slate-900 dark:text-white` (Org) |
| Secondary 텍스트 | Tier 2 | `text-slate-500 dark:text-slate-400` |
| 기본 테두리 | Tier 2 | `border-black/5 dark:border-white/5` (Org) 또는 Tier 1 `border-foreground/5` (마이스페이스) |
| 액센트 | Tier 1 | `text-bridge-accent`, `bg-bridge-accent` |
| 포커스 링 | Tier 1 | `focus:ring-bridge-accent/50` |

#### 버튼 (듀얼 테마)


### 테마 디자인 철학

**Dark Mode**: Deep navy 기반 (`#191f2d`). 차가운 톤, 높은 대비, 인디고/틸 액센트.
**Light Mode**: Warm cream 기반 (`#fffcf8`). 따뜻한 톤, 부드러운 대비, 베이지/탄 서피스, 골드 포커스 링.

## Tailwind CSS v4 설정

### CSS-First 설정 방식

**설정 파일:** `frontend/src/styles/tailwind.css`
- `@import 'tailwindcss' source(none)` - Tailwind 코어
- `@source '../**/*.{js,ts,jsx,tsx}'` - 소스 스캔 경로
- `@import 'tw-animate-css'` - 애니메이션 유틸리티

**테마 정의:** `frontend/src/styles/theme.css`
- `@theme inline` 디렉티브로 디자인 토큰 정의
- Bridge 컬러 7종 + shadcn 시맨틱 토큰 + Sidebar 토큰 + Chart 컬러 5종 + Radius 4종

### OKLCH 색상 공간

shadcn/ui 시맨틱 색상은 OKLCH 색상 공간 사용:

**Dark Mode:**
- `--background: oklch(0.145 0 0)`
- `--foreground: oklch(0.985 0 0)`
- `--muted-foreground: oklch(0.75 0 0)`
- `--destructive: oklch(0.396 0.141 25.723)`

**Light Mode:**
- `--foreground: oklch(0.145 0 0)`
- `--secondary: oklch(0.95 0.0058 264.53)`
