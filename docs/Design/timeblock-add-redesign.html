체크리스트 탭

선택 공간 확대

  • 두 개의 작은 스크롤 박스 → 하나의 통합 리스트 (sticky 섹션 헤더)
  • 모달 높이를 키우고 리스트가 남는 공간을 전부 사용
  • 오늘 체크리스트가 없으면 큰 빈 박스 대신 한 줄 안내로 축소
  • 검색창 추가 — 항목이 많을 때 바로 필터링
  • 섹션별 개수 뱃지로 전체 규모 파악
  • 기간 표시 — 데일리 체크리스트 추가와 동일 포맷: 📅 6.30 – 7.4 + 상태 칩 (기한 지남 · 오늘 마감 · D-N, 7일 초과는 칩 없음)
