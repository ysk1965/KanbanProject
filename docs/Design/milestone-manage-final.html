마일스톤 관리
최종 설계안

분석에서 내린 결정을 하나의 화면으로 통합한 확정본입니다. 핵심은 단 하나 — "마일스톤은 태스크에 붙는 기간 태그"라는 단일 정신 모델. 이 문장에서 오버뷰·배정·생성 플로우가 모두 파생됩니다.

홈 · 피처 × 마일스톤 매트릭스 배정 · 셀 → 태스크 슬라이드오버 공통은 원클릭 · 분리는 예외 덮어쓰기 작성일 · 2026-07-01
The Answer

1하나의 모델, 확정된 결정

Single Mental Model
마일스톤은 태스크에 붙는 기간 태그다.
피처는 그 태스크들의 기본 태그(default)를 정해줄 뿐.
→ 오버뷰 = 태그 매트릭스 · 배정 = 태그 바꾸기 · 생성 = 새 태그/새 그룹. 세 가지가 한 문장에서 나옵니다.

열린 질문(Q1~Q5)에 대한 최종 판단

결정 사항최종안이유
진입 오버뷰 매트릭스 (홈) "피처가 여러 마일스톤에 걸침"을 한 장으로 보여주는 유일한 형태. 마일스톤 6개 초과 시 가로 스크롤 + 컬럼 고정.
is_primary 재정의 피처의 기본 마일스톤 새 태스크가 상속 → 생성 마찰 제거. 모호했던 "대표"가 실제 기능을 얻음. 매트릭스에서 굵은 셀로 표시.
피처 생성 시 지정 기본 마일스톤 필드 노출 (선택) 활성 마일스톤(selectedMilestoneId)을 기본값 선제안. 비워두면 "미배정"으로 안전하게 시작.
스마트 채우기 기준 기간 겹침 우선 마일스톤이 날짜를 가지므로 태스크 due date 겹침이 가장 정확. "활성 피처"는 보조 제안.
진행률 정의 태스크 스코프 유지 기존 로직 유지하되, 항상 "이 마일스톤 기준" 라벨 + 피처 전체를 나란히 표기해 혼동 제거.
Home Screen

2최종 홈 — 매트릭스

관리 진입 시 보이는 단 하나의 홈. 상단 컴팩트 타임라인 + 피처×마일스톤 매트릭스. 셀을 누르면 태스크 배정 패널이 열립니다.

화면 해부

1
기본 마일스톤 (● 굵은 셀) — 피처마다 하나. 새 태스크가 여기로 상속돼 생성 마찰이 없음.
2
마일스톤 합계 — 태스크 스코프 진행률. "이 마일스톤 기준"이라는 맥락이 열 자체로 명확.
3
셀/행 카운트 — 그 교차점의 태스크 수. 클릭 시 배정 패널(§3). 행 헤더 = 피처 전체 요약.
4
피처 전체 열 — 마일스톤에 상관없는 피처 본연의 진행률. 합계와 나란히 보여 ③ 혼동 제거.
5
미배정 — 어느 마일스톤에도 없는 태스크. 뱃지로 드러나 일이 조용히 사라지지 않는 안전망.
Drill-down

3셀 클릭 → 태스크 배정

교차점(피처 × 마일스톤)을 누르면 우측 슬라이드오버. 이 피처의 모든 태스크를 보여주고, 칩으로 마일스톤을 바꿉니다. 여기서 task.milestone_id를 직접 편집 — "대표/이어짐" 조작은 없습니다.

Creation

4생성 플로우 (통합)

두 생성 모두 "공통 케이스는 원클릭, 분리는 예외" 원리를 따릅니다.

마일스톤 생성 = 새 컬럼
1

제목 + 기간

2필드만 받고 즉시 생성.

2

새 컬럼 하이라이트

매트릭스에 즉시 등장 + 스크롤.

3

기간 겹침 스마트 채우기

"이 기간에 걸치는 태스크 N개" 일괄 추가.

4

셀로 수동 보완

진행률·합계 실시간 갱신.

피처 생성 = 새 행
1

칸반에서 피처 생성

기존 유지. "기본 마일스톤" 필드(선택) 노출.

2

기본값 선제안

활성 마일스톤을 후보로. 비우면 미배정.

3

새 태스크 자동 상속

기본 마일스톤으로 채워짐 → 배정 마찰 0.

4

미배정은 뱃지 + 행 원클릭

"전체를 [마일스톤]에 →"로 일괄 배정.

결과 — 사용자는 대부분 "피처 만들 때 마일스톤 한 번 고르고 끝". 태스크마다 배정하는 일은 분리가 필요한 예외에서만 발생합니다.
Impact

5무엇이 바뀌나

현재

  • 피처 체크박스 링크와 태스크 배정, 두 모델이 충돌
  • "대표/이어짐" — 기능 없는 개념을 학습해야 함
  • 같은 피처가 화면마다 다른 진행률로 보임
  • 태스크 분리를 관리 UI에서 못 함 (태스크 열어야)
  • 모달·뷰·타임라인 3개 은유 재학습
  • 새 마일스톤 = 빈 껍데기, 채우는 안내 없음

최종안

  • 진실은 태스크 하나 — 매트릭스 = 단일 소스
  • "대표" = 기본 마일스톤, 새 태스크 상속이라는 실기능
  • 합계 vs 피처 전체를 나란히 라벨링, 혼동 제거
  • 셀 클릭 한 번으로 태스크 분리 직접 조정
  • 매트릭스 하나의 은유로 홈·배정·생성 통일
  • 새 마일스톤 = 기간 기반 스마트 채우기로 즉시 유용
Build Notes

6구현 메모

  • 재사용 — 매트릭스 셀 수치는 기존 countByMilestoneAndFeature 집계 그대로. 새 백엔드 없이 프론트 조립 가능.
  • 신규 컴포넌트 — MilestoneMatrix.tsx(홈) + 태스크 배정 슬라이드오버. 기존 MilestoneTimeline은 상단 스트립으로 컴팩트화해 재활용.
  • 백엔드 최소 변경 — is_primary의 의미를 "기본 마일스톤"으로 정착(값 자체 스키마 동일). 서브태스크 생성 시 피처의 기본 마일스톤 상속 로직 추가.
  • 신규 쿼리 1개 — 마일스톤 기간과 겹치는 미배정/후보 태스크 조회(스마트 채우기용).
  • 점진 적용 — P1 정합성 라벨 → P2 매트릭스 홈 → P3 상속·배정 패널 → P4 레거시 체크박스 링크 제거. (상세는 분석서 §7 참조)
