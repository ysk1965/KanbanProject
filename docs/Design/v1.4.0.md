## 타이포그래피

### 폰트 패밀리

- **Heading**: `font-serif` (serif 계열)
- **Body**: 시스템 기본 폰트 (sans-serif)
- **Code**: `font-mono` (monospace)

### 텍스트 스타일

| 스타일 | 클래스 | 용도 |
|--------|--------|------|
| H1 | `font-serif text-4xl font-bold tracking-tight` | 페이지 제목 |
| H2 | `font-serif text-2xl font-bold tracking-tight` | 섹션 제목 |
| H3 | `text-lg font-semibold` | 서브 섹션 |
| Body | `text-base font-light leading-relaxed` | 본문 |
| Label | `text-[11px] font-bold uppercase tracking-widest text-slate-400` | 라벨 |
| Small | `text-[10px] tracking-[0.3em] uppercase` | 작은 텍스트 |
| Caption | `text-xs text-slate-500` | 캡션 |

### Split Title 패턴

랜딩 페이지 섹션에서 사용하는 반응형 제목 분리 패턴. `<br />` 태그를 사용하여 제목을 두 줄로 나누어 가독성과 시각적 밸런스를 확보한다.

```tsx
<h2 className="font-serif text-3xl md:text-4xl font-bold tracking-tight text-white">
  {titleLine1}<br />
  {titleLine2}
</h2>
```

**사용 예시:**
```tsx
// i18n 기반 분리 제목
<h2>
  {t('landing.section.titleLine1')}<br />
  {t('landing.section.titleLine2')}
</h2>
```

**특징:**
- 랜딩 페이지 전체 섹션에서 일관되게 사용
- 번역 키를 `titleLine1` / `titleLine2`로 분리하여 다국어 환경에서도 적절한 줄바꿈 유지
- 데스크톱에서는 넓은 한 줄, 모바일에서는 자연스러운 줄바꿈 제공

## BlockNote 다크 테마 [v1.4.0 NEW]

### 개요

Tiptap 에디터에서 BlockNote로 마이그레이션하면서 `tiptap.css` 스타일을 삭제하고 `blocknote-dark.css`로 대체하였다. BlockNote 다크 테마는 Bridge 디자인 시스템의 컬러 팔레트를 기반으로 일관된 다크 모드 경험을 제공한다.

**파일:** `frontend/src/styles/blocknote-dark.css`
**삭제:** `frontend/src/styles/tiptap.css`

### CSS 변수

```css
/* BlockNote 다크 테마 - Bridge 디자인 시스템 컬러 사용 */
.bn-container[data-color-scheme="dark"] {
  --bn-colors-default-background: #0F1419;                    /* bridge-obsidian */
  --bn-colors-default-text: #e2e8f0;                          /* slate-200 */
  --bn-colors-default-border: rgba(255, 255, 255, 0.1);       /* white/10 */
  --bn-colors-editor-background: #0A0E17;                      /* bridge-dark */
  --bn-colors-menu-background: #0F1419;                        /* bridge-obsidian */
  --bn-colors-menu-text: #e2e8f0;                              /* slate-200 */
  --bn-colors-tooltip-background: #1e293b;                     /* slate-800 */
  --bn-colors-tooltip-text: #f1f5f9;                           /* slate-100 */
  --bn-colors-selected-background: rgba(99, 102, 241, 0.15);  /* bridge-accent/15 */
  --bn-colors-highlighted-background: rgba(99, 102, 241, 0.1); /* bridge-accent/10 */
```

## 커스텀 블록 스타일 [v1.6.0 NEW]

BlockNote 에디터에서 사용되는 7개 커스텀 블록의 스타일 정의. 모든 블록은 Bridge 디자인 시스템을 따른다.

### Callout 블록

4가지 타입 (info, warning, success, error)에 따라 다른 색상 스킴을 적용한다.

```css
/* 공통 스타일 */
.callout {
  @apply rounded-xl border-l-4 p-4 my-2;
}

/* Info (파란색) */
.callout-info {
  @apply border-l-blue-500 bg-blue-500/10;
  /* icon: Info, color: text-blue-400 */
}

/* Warning (앰버) */
.callout-warning {
  @apply border-l-amber-500 bg-amber-500/10;
  /* icon: AlertTriangle, color: text-amber-400 */
}

/* Success (초록) */
.callout-success {
  @apply border-l-emerald-500 bg-emerald-500/10;
  /* icon: CheckCircle, color: text-emerald-400 */
}

/* Error (빨강) */
.callout-error {
  @apply border-l-red-500 bg-red-500/10;
  /* icon: XCircle, color: text-red-400 */
}
```

### Toggle 블록

아코디언 형태의 접기/펼치기 콘텐츠 블록.

```css

  @apply border border-white/10 rounded-xl my-2 overflow-hidden;

  /* AnimatePresence for expand/collapse animation */
```

### Divider 블록

수평 구분선.

```css

  @apply border-t border-white/10 my-4;
```

### Scrollbar Hide

스크롤바를 숨기면서 스크롤 기능은 유지하는 유틸리티 클래스. 모바일 환경의 수평 스크롤 탭 네비게이션에서 주로 사용한다.

```css
.scrollbar-hide {
  -ms-overflow-style: none;  /* IE/Edge */
  scrollbar-width: none;     /* Firefox */
}
.scrollbar-hide::-webkit-scrollbar {
  display: none;             /* Chrome/Safari/Opera */
}
```

**사용 예시:**
```tsx
{/* ManagementView 탭 네비게이션 */}
<div className="flex overflow-x-auto scrollbar-hide gap-1 px-4">
  <button className="whitespace-nowrap px-3 py-2 text-sm">탭 1</button>
  <button className="whitespace-nowrap px-3 py-2 text-sm">탭 2</button>
  ...
</div>
```

**적용 위치:**
- `ManagementView` 탭 바 (모바일에서 수평 스크롤)
- `overflow-x-auto`와 함께 사용하여 터치 스와이프 가능

### 애니메이션

| 이름 | 클래스 | 설명 |
|------|--------|------|
| Fade In Up | `animate-fade-in-up` | 위로 페이드인 |
| Float | `animate-float` | 떠다니는 효과 |
| Spot Pulse | `animate-spot` | 점 펄스 |
| Spin Slow | `animate-spin-slow` | 느린 회전 |
| Shimmer | `text-shimmer` | 텍스트 그라데이션 애니메이션 |
| Slide In Banner | `animate-slide-in-banner` | 배너 슬라이드인 (0.3s ease-out) |
| Banner Progress | `animate-banner-progress` | 배너 프로그레스 투명도 펄스 (5s infinite) |

### 상세 키프레임 정의

| 이름 | 키프레임 | 설명 |
|------|----------|------|
| shimmer | `background-position: 0 → 200% center` | 인디고→틸 그라데이션 흐름 |
| fadeInUp | `opacity: 0, translateY(30px) → opacity: 1, translateY(0)` | 아래→위 페이드인 |
| float | `translateY(0) → translateY(-20px) rotate(2deg) → translateY(0)` | 떠다니는 효과 |
| spot-pulse | `opacity: 0.3, scale(1) → opacity: 0.6, scale(1.2)` | 점 펄스 |
| spot-glow | `box-shadow 확대/축소 + scale 애니메이션` | 글로우 점 효과 |
| spin | `rotate(0deg) → rotate(360deg)` | 회전 (.animate-spin-slow: 8s) |
| slideInBanner | `translateX(-100%), opacity(0) → translateX(0), opacity(1)` | 배너 슬라이드인 (0.3s ease-out) |
| bannerProgress | `opacity: 0.3 → 0.6 → 0.3` | 배너 프로그레스 펄스 (5s infinite) |

### Framer Motion 패턴

```tsx

  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5 }}

// 순차 등장

  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ delay: index * 0.1 }}

```

모바일에서 세로 정렬, 데스크톱에서 가로 정렬로 전환하는 패턴. AIReportPanel 등에서 사용.

```tsx
<div className="flex flex-col md:flex-row gap-4">
  <div className="w-full md:w-1/3">사이드 패널</div>
  <div className="w-full md:w-2/3">메인 컨텐츠</div>
</div>
```

#### 반응형 그리드 컬럼

컨텐츠 양과 화면 크기에 맞춰 단계적으로 컬럼 수를 증가시키는 패턴. ManagementView 등에서 사용.

```tsx
{/* 모바일: 2열 → 데스크톱: 4열 */}
<div className="grid grid-cols-2 lg:grid-cols-4 gap-4">
  <div>항목 1</div>
  <div>항목 2</div>
  <div>항목 3</div>
  <div>항목 4</div>
</div>
```

#### 모바일 오버레이 전환

데스크톱에서 사이드바로 표시하던 패널을 모바일에서 전체 화면 오버레이로 전환하는 패턴. History 패널 등에서 사용.

```tsx

  <HistoryPanel />
</div>

  <HistoryPanel onClose={handleClose} />
</div>
```

#### 수평 스크롤 탭 네비게이션

모바일에서 탭이 화면을 넘칠 때 수평 스크롤로 처리하는 패턴. `scrollbar-hide` 유틸리티와 함께 사용.

```tsx
  ))}
</div>
```

## Tailwind CSS v4 설정

### CSS-First 설정 방식
Tailwind CSS v4에서는 `tailwind.config.js` 대신 CSS 파일에서 직접 설정:

**설정 파일:** `frontend/src/styles/tailwind.css`
- `@import 'tailwindcss' source(none)` - Tailwind 코어
- `@source '../**/*.{js,ts,jsx,tsx}'` - 소스 스캔 경로
- `@import 'tw-animate-css'` - 애니메이션 유틸리티

**테마 정의:** `frontend/src/styles/theme.css`
- `@theme inline` 디렉티브로 디자인 토큰 정의
- 40+ 색상 변수, 라운딩, 차트 색상 등

### OKLCH 색상 공간
shadcn/ui 시맨틱 색상은 OKLCH 색상 공간 사용 (인지적 균일성, 넓은 색역):

**Light Mode 예시:**
- `--foreground: oklch(0.145 0 0)` (거의 검정)
- `--secondary: oklch(0.95 0.0058 264.53)` (연한 보라 회색)

**Dark Mode 예시:**
- `--background: oklch(0.145 0 0)` (거의 검정)
- `--foreground: oklch(0.985 0 0)` (거의 흰색)
- `--muted-foreground: oklch(0.75 0 0)` (밝아진 회색)
- `--destructive: oklch(0.396 0.141 25.723)` (어두운 빨강)

총 52개 OKLCH 색상 값 정의.
