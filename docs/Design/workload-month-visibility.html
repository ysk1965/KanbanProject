타임라인에서 “지금 몇 월인지”가 안 보이는 이유와 고치는 법

워크로드 간트는 오늘 기준 –84일 ~ +280일, 총 365칸을 한 줄로 펼칩니다. 그런데 월 표기는 매달 1일 칸 하나에만, 가장 흐린 글자로 붙어 있습니다. 나머지 29일 구간을 보고 있으면 화면 어디에도 월·연도 정보가 없습니다.

1. 진단

스크린샷의 “9월”이 왜 눈에 안 들어오는가

월 라벨이 1일 칸에만 존재

365칸 중 월 표기가 붙는 칸은 13개뿐입니다. 스크롤 위치가 월 중순이면 화면에 월 정보가 0개입니다. 스크린샷도 8월 31일과 9월 1일 경계라 우연히 보이는 상태입니다.

:2445  showMonth = dayNum === 1 || idx === 0

연도가 어디에도 없다

타임라인 범위가 13개월이라 최대 3개 연도를 가로지릅니다. 그런데 표기는 month: "short" 뿐이라 “1월”이 두 번 나와도 구분할 방법이 없습니다.

:593-596  –84d ~ +280d  /  :2498 month:"short"

화면에서 가장 약한 우선순위

날짜 숫자는 text-foreground font-medium인데 월 라벨은 text-slate-500 + absolute top-0.5 left-1. 가장 중요한 문맥 정보가 가장 흐리고, 셀 좌상단 모서리에 눌려 있습니다.

:2496-2499

축소하면 더 무너진다

줌 최소값은 셀 폭 32px. “9월”·“Sep” 라벨이 셀보다 넓어 옆 칸을 침범하고, 44px 미만에서는 요일 라벨까지 숨겨져 문맥이 한 번 더 사라집니다.

:68 ZOOM_PRESETS [32,44,60,80,100]  /  :2472 dayWidth >= 44

본문 그리드에 월 경계가 없다

주말·공휴일 음영은 있지만 월 구분선은 없습니다. 바 하나가 “한 달짜리 작업인지” 눈으로 셀 수 없어, 헤더를 놓치면 길이 감각도 같이 잃습니다.

:2513-2530 주말/공휴일 컬럼 렌더 루프

3. 개선안

우선순위 순 · A와 B는 서로 독립적으로 적용 가능
안 A · 권장

2단 헤더 — 월 밴드를 헤더 위쪽에 추가

작업량 中영향 헤더 전역
  • 높이 배분 — HEADER_HEIGHT 48을 월 밴드 18px + 일 밴드 30px으로 나눕니다. 총합을 48로 유지하면 마일스톤 행 sticky top, minHeight 등 기존 계산을 건드릴 필요가 없습니다.
  • 세그먼트 계산 — timelineDays를 한 번 훑어 월별 { startIdx, days, year, month }를 만들고 useMemo로 캐시합니다. (365칸 → 13개 세그먼트)
  • 라벨 고정 — 세그먼트 안의 라벨에 position: sticky; left: 200px를 주면, 세그먼트가 절반쯤 스크롤아웃돼도 라벨은 좌측 컬럼 바로 옆에 붙어 남습니다. 간트 표준 동작입니다.
  • 표기 포맷 — 2026년 9월. 세그먼트 폭이 좁으면(days * dayWidth < 90) 연도를 떨어뜨리고 9월만, 단 1월과 연도가 바뀌는 첫 세그먼트는 항상 연도를 붙입니다.
  • 현재 월 강조 — 오늘이 포함된 세그먼트에 bg-bridge-accent/10. 
// ScheduleResourceView.tsx — 상수 (:83 부근)
const HEADER_HEIGHT = 48;
const MONTH_BAND_HEIGHT = 18;
const DAY_BAND_HEIGHT = 30;
const HEADER_HEIGHT = MONTH_BAND_HEIGHT + DAY_BAND_HEIGHT; // 48 유지

// 월 세그먼트 (timelineDays 메모 아래)
const monthSegments = useMemo(() => {
  const segs: { startIdx: number; days: number; y: number; m: number }[] = [];
  timelineDays.forEach((d, i) => {
    const last = segs[segs.length - 1];
    if (last && last.y === d.getFullYear() && last.m === d.getMonth()) last.days++;
    else segs.push({ startIdx: i, days: 1, y: d.getFullYear(), m: d.getMonth() });
  });
  return segs;
}, [timelineDays]);
// 헤더 렌더 (:2433 "Day headers" 블록 바로 위에 밴드 추가)
<div className="relative" style={{ width: totalTimelineWidth, height: MONTH_BAND_HEIGHT }}>
  {monthSegments.map((s) => {
    const w = s.days * dayWidth;
    const isNow = todayIndex >= s.startIdx && todayIndex < s.startIdx + s.days;
    const withYear = w >= 90 || s.m === 0 || s.startIdx === 0;
    return (
      <div key={`${s.y}-${s.m}`} className={`absolute top-0 h-full border-l border-foreground/[0.14]
        ${isNow ? "bg-bridge-accent/10" : ""}`}
        style={{ left: s.startIdx * dayWidth, width: w }}>
        <span className="sticky inline-block px-2 text-xs font-bold text-foreground whitespace-nowrap"
          style={{ left: LEFT_COL_WIDTH }}>
          {withYear ? t("schedule.resource.ymLabel", "{{y}}년 {{m}}월", { y: s.y, m: s.m + 1 })
                    : t("schedule.resource.mLabel", "{{m}}월", { m: s.m + 1 })}
        </span>
      </div>
    );
  })}
</div>
주의 2가지. ① 일 밴드 셀의 height는 HEADER_HEIGHT가 아니라 DAY_BAND_HEIGHT로 바꿔야 합니다(:2466 부근 style). ② sticky 라벨의 z-index는 좌측 코너 셀(z-30)보다 낮게 둬야 라벨이 코너를 덮지 않습니다. 밴드 컨테이너는 z-0~10 범위로.
안 B · 즉시

좌측 코너에 “현재 보이는 달” 칩

작업량 小레이아웃 변경 없음

이미 스크롤할 때마다 visibleDayRange를 rAF로 측정하고 있습니다(:763-772). 이 값만 재활용하면 코드 20줄로 “지금 몇 월”을 항상 고정 노출할 수 있습니다. 200px 좌측 코너는 sticky라 절대 화면 밖으로 나가지 않습니다. 

const visibleMonthLabel = useMemo(() => {
  const r = visibleDayRange;
  if (!r) return null;
  const a = timelineDays[Math.max(0, r.start)];
  const b = timelineDays[Math.min(timelineDays.length - 1, r.end)];
  if (!a || !b) return null;
  const sameY = a.getFullYear() === b.getFullYear();
  const sameM = sameY && a.getMonth() === b.getMonth();
  if (sameM) return `${a.getFullYear()}년 ${a.getMonth() + 1}월`;
  if (sameY) return `${a.getFullYear()}년 ${a.getMonth() + 1}–${b.getMonth() + 1}월`;
  return `${a.getFullYear()}.${a.getMonth() + 1} – ${b.getFullYear()}.${b.getMonth() + 1}`;
}, [visibleDayRange, timelineDays]);

// 좌측 코너 (:2308 "직군별" 라벨 자리) — 임베드 모드에선 텍스트가 없으므로 칩만 표시
<span className="text-xs font-bold px-1.5 py-0.5 rounded-full bg-bridge-accent/15 text-bridge-accent whitespace-nowrap">
  {visibleMonthLabel}
</span>
좌측 코너는 이미 직군별 · 특별일 · ⚙ 3개가 200px를 나눠 쓰고 있습니다. 칩을 넣으려면 “직군별” 텍스트를 아이콘+툴팁으로 줄이거나 (그룹 기준은 설정 팝오버에도 있음), LEFT_COL_WIDTH를 220~240으로 올리는 편이 안전합니다.
안 C

본문에도 월 경계선 + 홀짝 월 미세 틴트

작업량 小가독성 이득 큼
  • 주말·공휴일 컬럼을 그리는 기존 루프(:2513-2530, 각 행 배경)에 day.getDate() === 1일 때 border-l border-foreground/[0.14] 한 줄을 추가합니다. 헤더의 월 밴드 구분선과 세로로 이어져 타임라인 전체가 월 단위로 분절됩니다.
  • 선택 사항 — 짝수 월 구간에 bg-foreground/[0.015] 수준의 극미세 틴트. 주말 음영(/[0.02])보다 옅게 둬야 두 신호가 싸우지 않습니다.
  • 바를 드래그해 날짜를 바꿀 때, 커서 옆 칩의 날짜 표기에도 M월 D일로 월을 포함시키면 이동 중에도 문맥이 유지됩니다.
안 D

월 점프 · 접근성 마감

작업량 小후속
  • 월 점프 — 안 B의 칩을 버튼으로 만들고 클릭 시 13개월 드롭다운. 선택하면 scrollLeft = seg.startIdx * dayWidth. “오늘” 버튼은 마운트 시 스크롤 로직(:741-745)을 그대로 재사용합니다.
  • 날짜 셀 aria — 현재 title은 공휴일명 또는 “우클릭: 휴무일/근무일 지정”뿐입니다. aria-label="2026년 9월 7일 월요일"를 추가하면 스크린리더에서 월을 알 수 있습니다.
  • 토큰 정합 — 월 라벨은 CLAUDE.md의 라벨 토큰 (text-xs font-bold)을 따르고, 현재의 text-slate-500은 본문 힌트용으로만 남깁니다. 최소 크기 text-xs 규칙도 그대로 지켜집니다.
