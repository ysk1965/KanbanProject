정리

  • 두 모달 동일 패턴: 제목 바로 아래 .metabar 한 줄 칩. Task는 기간 · 담당자 · 태그, Feature는 기간 · 태그 (Feature엔 담당자 개념 없음).
  • 빈 값 vs 채워진 값: 비어 있으면 옅은 기본 칩("날짜 선택"/"태그 추가"), 값이 있으면 filled 스타일(accent 배경)로 전환 → 데이터 유무를 색으로 구분.
  • 담당자(Task 전용): 겹친 아바타 스택 + "담당 N명". 칩 클릭 시 팝오버로 전체 목록·필터 토글 노출 (기존 필터 로직 그대로 재사용).
  • 구현: TaskDetailModal.tsx 1341~1617 / FeatureDetailModal.tsx 369~540 의 세로 블록을 각각 .metabar 로 치환. 설명 섹션은 메타바 아래로 이동.
  • 토큰 준수: 칩 rounded-lg, 태그 rounded-full, 구분선 border-foreground/[0.08], 라벨 text-xs font-bold ... text-slate-400.
