노트 FLOW 에디터 React Flow 기반 신규 노트 타입

기존 Excalidraw BOARD는 그대로 두고, 플로우차트·개념도·이미지/영상 임베드·노드 연결에 특화된 새 노트 타입 FLOW를 추가합니다. React Flow 세팅은 마인드맵에서, 저장·협업 구조는 Excalidraw 노트에서 재활용하는 하이브리드 설계라 마이그레이션 리스크가 0이고 대부분 검증된 코드입니다.

3 저장 스키마 (note.content JSON)

Excalidraw BOARD가 note.content(TEXT)에 scene JSON을 넣듯, FLOW도 동일 컬럼에 자체 스키마를 저장합니다. 별도 테이블 불필요.

// note.content 에 저장되는 JSON
{
  "type": "bridge-flow",
  "version": 1,
  "nodes": [
    { "id":"n1", "kind":"text",  "x":60,  "y":78,
      "data":{ "title":"4차 마일스톤 목표", "body":"..." } },
    { "id":"n2", "kind":"image", "x":385, "y":100, "width":180,
      "data":{ "url":"https://cdn.../wire_v3.png", "caption":"와이어프레임" } },
    { "id":"n3", "kind":"video", "x":150, "y":300,
      "data":{ "url":"https://cdn.../demo.mp4" } }
  ],
  "edges": [
    { "id":"e1", "source":"n1", "target":"n2",
      "source_handle":"r", "target_handle":"l", "label":"참고" }
  ]
}
협업(Yjs): Excalidraw가 Y.Map("excalidraw-elements")를 쓰듯, FLOW는 Y.Map("flow-nodes") + Y.Map("flow-edges")를 사용합니다. 노드 id를 키로 per-node 저장 → 두 명이 다른 노드를 옮겨도 충돌 없이 머지. 기존 NoteCollabHandler는 내용 불문 릴레이라 백엔드 협업 코드는 손댈 필요 없음.

6 이 접근의 이점 & 유의점

  • 마이그레이션 리스크 0 — 기존 Excalidraw BOARD는 그대로. FLOW는 별도 타입으로 공존, 데이터 변환 없음.
  • 대부분 검증된 코드 — React Flow 세팅은 마인드맵, 저장·협업은 Excalidraw 노트에서 이식. 신규 위험은 노드 컴포넌트 5종뿐.
  • 진짜 연결선 — edge가 데이터라 노드 이동 시 자동 추적. Excalidraw 화살표보다 우수.
  • 인터랙티브 미디어 — 영상 인라인 재생, 이미지 클릭. 커스텀 노드=React 컴포넌트라 확장 자유.
  • 번들 — React Flow는 이미 로드되는 청크(마인드맵과 공유). Excalidraw(~1.5MB) 대비 추가 부담 없음. lazy 로드 유지.
  • 유의 — 손그림(펜)은 지원 안 함. 자유 스케치가 필요한 사용자를 위해 Excalidraw BOARD는 남겨두는 이유.
