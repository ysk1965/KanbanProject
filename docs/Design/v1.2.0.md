|------|-----|-------------|----------|------|
| Indigo | `#6366F1` | `bg-indigo-500` | `bg-indigo-500/20` | `text-indigo-300` |
| Purple | `#8B5CF6` | `bg-purple-500` | `bg-purple-500/20` | `text-purple-300` |

## 효과 & 애니메이션

### Glass Morphism

```css
/* Dark Mode (default) */
.glass {
  background: rgba(255, 255, 255, 0.03);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.05);
}

/* Light Mode */
.light .glass {
  background: rgba(255, 255, 255, 0.8);
  backdrop-filter: blur(20px);
}

.login-glass {
  background: rgba(255, 255, 255, 0.05);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.08);
}
```

### 애니메이션

| 이름 | 클래스 | 설명 |
|------|--------|------|
| Fade In Up | `animate-fade-in-up` | 위로 페이드인 |
| Float | `animate-float` | 떠다니는 효과 |
| Spot Pulse | `animate-spot` | 점 펄스 |
| Spin Slow | `animate-spin-slow` | 느린 회전 |
| Shimmer | `text-shimmer` | 텍스트 그라데이션 애니메이션 |
| Slide In Banner | `animate-slide-in-banner` | 배너 슬라이드인 (0.3s ease-out) |
| Banner Progress | `animate-banner-progress` | 배너 프로그레스 투명도 펄스 (5s infinite) |

### 상세 키프레임 정의

| 이름 | 키프레임 | 설명 |
|------|----------|------|
| shimmer | `background-position: 0 → 200% center` | 인디고→틸 그라데이션 흐름 |
| fadeInUp | `opacity: 0, translateY(30px) → opacity: 1, translateY(0)` | 아래→위 페이드인 |
| float | `translateY(0) → translateY(-20px) rotate(2deg) → translateY(0)` | 떠다니는 효과 |
| spot-pulse | `opacity: 0.3, scale(1) → opacity: 0.6, scale(1.2)` | 점 펄스 |
| spot-glow | `box-shadow 확대/축소 + scale 애니메이션` | 글로우 점 효과 |
| spin | `rotate(0deg) → rotate(360deg)` | 회전 (.animate-spin-slow: 8s) |
| slideInBanner | `translateX(-100%), opacity(0) → translateX(0), opacity(1)` | 배너 슬라이드인 (0.3s ease-out) |
| bannerProgress | `opacity: 0.3 → 0.6 → 0.3` | 배너 프로그레스 펄스 (5s infinite) |

## Tailwind CSS v4 설정

### CSS-First 설정 방식
Tailwind CSS v4에서는 `tailwind.config.js` 대신 CSS 파일에서 직접 설정:

**설정 파일:** `frontend/src/styles/tailwind.css`
- `@import 'tailwindcss' source(none)` - Tailwind 코어
- `@source '../**/*.{js,ts,jsx,tsx}'` - 소스 스캔 경로
- `@import 'tw-animate-css'` - 애니메이션 유틸리티

**테마 정의:** `frontend/src/styles/theme.css`
- `@theme inline` 디렉티브로 디자인 토큰 정의
- 40+ 색상 변수, 라운딩, 차트 색상 등

### OKLCH 색상 공간
shadcn/ui 시맨틱 색상은 OKLCH 색상 공간 사용 (인지적 균일성, 넓은 색역):

**Light Mode 예시:**
- `--foreground: oklch(0.145 0 0)` (거의 검정)
- `--secondary: oklch(0.95 0.0058 264.53)` (연한 보라 회색)

**Dark Mode 예시:**
- `--background: oklch(0.145 0 0)` (거의 검정)
- `--foreground: oklch(0.985 0 0)` (거의 흰색)
- `--muted-foreground: oklch(0.75 0 0)` (밝아진 회색)
- `--destructive: oklch(0.396 0.141 25.723)` (어두운 빨강)

총 52개 OKLCH 색상 값 정의.
