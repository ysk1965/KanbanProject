동작 스펙

레이아웃

  • In Review·Done을 overflow-x 스크롤 컨테이너 밖으로 빼서 flex 형제로 배치 — Feature 컬럼 수와 무관하게 항상 보임
  • 접힘: 52px (컬럼 1개 260px 대비 80% 절약, 둘 합쳐 112px)
  • 펼침: 232px — 기존 컬럼과 동일한 카드 UI 또는 밀도형 1줄 카드
  • 둘 다 펼쳐도 476px — 화면이 좁으면 하나 펼치면 다른 하나 자동 접힘 (아코디언, md 이하)

접힌 레일에 담는 정보

  • 상단 카운트 뱃지 — 컬럼 톤 컬러(amber/emerald)
  • 세로 라벨 (writing-mode: vertical-rl)
  • 카드마다 미니 바 1개 — 좌측 보더는 담당자 컬러 → 누가 리뷰 대기 중인지 한눈에
  • Done 레일 하단 "오늘 +N" — 오늘 완료 흐름이 보여 팀 사기·회고에 유용

드래그 & 드롭

  • 접힌 레일도 그대로 드롭 타겟 — 카드를 끌어다 놓으면 이동 (기존 onDropColumn 재사용)
  • 드래그 중 레일 위 0.3초 호버 시 자동 펼침 — 특정 위치에 놓고 싶을 때
  • 드래그 진입 시 톤 컬러 글로우로 드롭 가능 표시
  • 기존 카드 호버 액션(리뷰·완료 원클릭 이동)은 그대로 유지 — 레일은 보조 경로
검토한 대안

A. 우측 도킹 레일 (추천)

✓ 채택 제안

칸반의 좌→우 진행 멘탈모델 유지. 드롭 타겟이 항상 같은 자리에 있어 드래그 동선이 짧고 예측 가능. 구현도 컬럼 렌더 위치만 옮기면 되어 변경 범위가 작음.

B. 하단 도크 바

✗ 보류

가로 공간은 전혀 안 쓰지만 세로 공간(카드 리스트 높이)을 깎고, "아래로 드롭"이 칸반 진행 방향과 어긋남. 모바일에선 하단 내비와 충돌.

C. 통합 슬림 컬럼 (리뷰+완료 합침)

✗ 보류

한 컬럼이라 가장 좁지만 두 상태를 한 컬럼에 섞으면 드롭 타겟이 모호해지고(위쪽=리뷰, 아래쪽=완료?), 컬럼=상태라는 기존 구조·백엔드 모델과 어긋남.
