💡 개선안: "오늘 내 작업"이 먼저 보이는 3단 위계

  1. ① 히어로 존 "내가 포함된 Task" — 내 항목 강조. 액센트 테두리 + 인디고 배경으로 영역 자체를 격상. 내 담당 항목은 액센트 좌측 바 + "내 항목" 칩으로 크게, 경로(블록 › 태스크)는 브레드크럼으로 축약. 3열 배열 유지. 기간(📅 시작–종료) + 마감 상태 칩(오늘 마감 / D-N / 기한 지남)으로 오늘 우선순위 판단 지원.
  2. ② 같은 태스크의 팀 항목은 접어서 보관. 동료 항목은 "팀 항목 N개" 토글 뒤로 — 필요할 때만 펼쳐서 함께 추가. 소음은 제거하되 맥락은 유지.
  3. ③ 다른 Task는 디밍 + 블록 아코디언. 기본 접힘 & 투명도 낮춤 → "그 다음에 보는 영역"이라는 시각 신호. 검색 시엔 자동으로 펼쳐짐.
  4. 이미 추가된 항목은 리스트 하단으로 + 취소선. 오늘 남은 일이 위로 모임.
  5. 즉석 추가 기능 유지. 태스크별 ＋ → 인라인 입력으로 새 체크리스트 즉석 생성(자동 선택 · "새 항목" 칩), 블록 헤더 ＋ → 새 Task 추가. 기존 모달의 quick-add 흐름 그대로.
