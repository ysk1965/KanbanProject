# BRIDGE - 프로젝트 기획서 (투자자/외부 발표용)

> **AI-Powered Collaborative Project Management Platform**
> 최종 업데이트: 2026-02-14 | 코드베이스 기반 실측 작성

---

## 1. Executive Summary

**BRIDGE**는 소규모 팀(2~20명)을 위한 올인원 프로젝트 협업 플랫폼입니다. 칸반 보드를 중심으로 일정 관리, 미팅 기록, 팀 노트, AI 기반 리포트까지 하나의 서비스에서 제공합니다.

기존 도구(Jira, Notion, Slack)를 여러 개 조합해야 했던 팀 워크플로우를 **단일 플랫폼**으로 통합하여, 도구 간 컨텍스트 전환 비용을 제거합니다.

| 지표 | 현황 |
|------|------|
| 핵심 도메인 | 31개 (칸반, 일정, 미팅, 노트, AI 리포트 등) |
| API 엔드포인트 | 100+ REST API |
| 지원 언어 | 10개국어 (한/영/일/중/베/태/스페인/포르투갈/힌디) |
| 실시간 동기화 | WebSocket (STOMP) + Yjs CRDT |
| AI 기능 | 미팅 전사/요약, 주간 리포트, 노트 AI 제안 |
| 구독 모델 | Freemium (Trial 7일) → Standard → Premium |

## 2. 해결하는 문제

### 2.1 시장 페인포인트

| 문제 | 현재 상태 | BRIDGE 해결책 |
|------|-----------|---------------|
| **도구 파편화** | Jira(칸반) + Notion(문서) + Slack(소통) + Google Calendar(일정) | 단일 플랫폼에서 모두 제공 |
| **컨텍스트 전환** | 도구 간 이동 시 평균 23분 집중력 회복 소요 | 칸반 → 일정 → 미팅 → 노트 탭 전환 |
| **미팅 기록 유실** | 회의록 수동 작성, 공유 누락 | AI 자동 전사 + 요약 + 액션 아이템 추출 |
| **진행 상황 파악** | 수동 리포트, 스프레드시트 취합 | AI 주간 리포트 자동 생성 |
| **소규모 팀 비용** | Jira($7.75/user) + Notion($8/user) = $15.75+/user | $5/seat (월간) |

### 2.2 타겟 사용자

- **Primary**: 2~20명 규모의 스타트업, 에이전시, 프리랜서 팀
- **Secondary**: 사내 프로젝트 TF, 학교/학원 프로젝트 팀
- **Geography**: 아시아-태평양 (10개국어 지원, 한국 결제 연동)

## 3. 핵심 기능

### 3.1 칸반 보드 (Core)

프로젝트의 중심 허브입니다.

- **Feature → Task 계층 구조**: Feature(Epic) 아래 Task를 구성, 진행률 자동 계산
- **커스텀 블록**: FEATURE / TASK / DONE 기본 컬럼 + 무제한 커스텀 컬럼
- **드래그 앤 드롭**: @dnd-kit 기반 카드/컬럼 실시간 재배치
- **자동 완료 로직**: Task를 DONE 블록으로 이동 시 자동 완료 처리 → Feature 진행률 자동 반영
- **태그 시스템**: Feature/Task에 커스텀 태그 부착, 필터링
- **마일스톤**: 프로젝트 페이즈 관리, 리소스 배분, 진행률 추적
- **실시간 동기화**: 모든 변경 사항이 WebSocket으로 전체 보드 멤버에게 즉시 반영

### 3.2 일정 관리 (Schedule)

- **일간/주간 타임라인 뷰**: 체크리스트 아이템과 미팅을 시간축에 배치
- **Baseline 비교**: 원래 일정 vs 실제 일정 차이 시각화
- **작업 시간 설정**: 보드별 근무 시간, 휴식 시간 커스터마이징

### 3.3 미팅 (Meeting)

- **캘린더 뷰**: 미팅 일정 시각화
- **반복 미팅**: recurrence_rule 기반 정기 미팅
- **AI 전사 (Transcription)**: 음성 녹음 → 텍스트 자동 변환
- **AI 요약**: 미팅 내용 자동 요약 + 액션 아이템 추출
- **실시간 참석 표시**: WebSocket 기반 참석자 온라인 상태

### 3.4 팀 노트 (Notes)

- **폴더/문서 계층 구조**: 최대 4단계 깊이
- **BlockNote 리치 에디터**: 블록 기반 편집기
- **Yjs CRDT 동시 편집**: 여러 사용자가 동시에 같은 문서 편집 (충돌 없음)
- **버전 관리**: 문서 변경 이력 추적
- **AI 콘텐츠 제안**: 문서 내용 기반 AI 제안

### 3.5 AI 기능

| 기능 | 설명 | AI 모델 |
|------|------|---------|
| 주간 팀 리포트 | 보드 전체 진행 상황 요약 | GPT-4o-mini / Claude Haiku |
| 개인 리포트 | 개인 기여도 및 할 일 정리 | GPT-4o-mini / Claude Haiku |
| 스탠드업 리포트 | 일일 스탠드업 자동 생성 | GPT-4o-mini / Claude Haiku |
| 미팅 전사 | 음성 → 텍스트 변환 | GPT-4o-mini / Claude Haiku |
| 미팅 요약 | 회의 요약 + 액션 아이템 | GPT-4o-mini / Claude Haiku |
| 노트 AI 제안 | 문서 내용 기반 AI 추천 | GPT-4o-mini / Claude Haiku |

- **듀얼 AI 프로바이더**: OpenAI / Claude 중 선택 가능 (환경변수 전환)
- **크레딧 시스템**: 월간 크레딧 + 추가 구매 가능, 매일 UTC 자정 리셋

### 3.6 협업 & 알림

- **댓글 시스템**: Task별 스레드, @멘션, 파일 첨부, 이모지 리액션 (커스텀 이모지 포함)
- **실시간 알림**: 멘션, 체크리스트 배정, 태스크 댓글 3종
- **사용자별 알림 설정**: 보드별로 알림 유형 On/Off
- **Slack 연동**: 개인별 Slack Webhook으로 알림 전달 (Premium)
- **활동 로그**: 모든 변경 이력 기록 및 조회

### 3.7 관리자 기능

- **대시보드**: 시스템 전체 메트릭
- **사용자 관리**: 활성화/비활성화, 역할 변경
- **구독 관리**: 플랜 업/다운그레이드, Trial 연장
- **공지사항**: 시스템 전체 공지 (PUBLIC, MAINTENANCE, ALERT)
- **문의 관리**: 고객 문의 접수 및 응답
- **시스템 설정**: 점검 모드 토글

## 5. 기술적 차별점

### 5.1 실시간 협업 아키텍처

```
┌─────────────┐     STOMP/WebSocket      ┌─────────────┐
│  Browser A   │ ◄────────────────────►  │  Spring Boot │
│  (React 18)  │                         │  (WS Broker) │
└─────────────┘                          └──────┬──────┘
                                                │
┌─────────────┐     Yjs CRDT Sync        ┌──────▼──────┐
│  Browser B   │ ◄────────────────────►  │ NoteCollab   │
│  (BlockNote) │                         │ WebSocket    │
└─────────────┘                          └─────────────┘
```

- **STOMP WebSocket**: 칸반/미팅/일정 실시간 동기화
- **Yjs CRDT**: 노트 동시 편집 (충돌 없는 분산 데이터 구조)
- **온라인 상태 추적**: 실시간 접속 멤버 표시

### 5.2 프로덕션 인프라

```
┌─────────┐     ┌────────────┐     ┌──────────────────┐
│ Route 53 │────►│ CloudFront │────►│  S3 (Frontend)   │
│  (DNS)   │     │   (CDN)    │     │  React SPA       │
└─────────┘     └────────────┘     └──────────────────┘
                      │
                      ▼
                ┌────────────┐     ┌──────────────────┐
                │    ALB     │────►│ Elastic Beanstalk │
                │(Load Bal.) │     │ (Spring Boot ×2~4)│
                └────────────┘     └────────┬─────────┘
                                            │
                              ┌─────────────┼──────────────┐
                              ▼             ▼              ▼
                      ┌────────────┐ ┌──────────┐ ┌──────────┐
                      │ Aurora     │ │ Redis    │ │   S3     │
                      │ Serverless │ │(Elasti-  │ │ (Files)  │
                      │ v2 (PG)   │ │ Cache)   │ │          │
                      └────────────┘ └──────────┘ └──────────┘
```

- **Aurora Serverless v2**: 자동 스케일링 DB (0.5~4 ACU)
- **Elastic Beanstalk**: Rolling 배포, Auto Scaling (2~4 인스턴스)
- **CloudFront + S3**: 글로벌 CDN 배포
- **Redis ElastiCache**: 캐시 레이어
- **Terraform IaC**: 전체 인프라 코드 관리 (dev/prod 분리)
- **CI/CD**: GitHub Actions (테스트 → 빌드 → 배포 자동화)

### 5.3 보안 & 모니터링

- **JWT 인증** + **Google OAuth2** 소셜 로그인
- **이메일 인증** 필수 (Gmail SMTP)
- **역할 기반 접근 제어**: OWNER → ADMIN → MEMBER → VIEWER
- **Rate Limiting**: Bucket4j 기반 API 요청 제한
- **Sentry**: 실시간 에러 추적
- **CloudWatch**: 인프라 메트릭 (CPU, 메모리, DB 커넥션)
- **커스텀 모니터링**: 느린 API(>3초), 에러율(>5%) 자동 알림
