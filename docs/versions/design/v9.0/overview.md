## 1. 서비스 개요

### 1.1 프로젝트 목적

**서비스 이름**: BRIDGE SPOTS
**슬로건**: "복잡한 협업을 단순한 흐름으로. 팀원들의 시간을 가장 가치 있게 연결합니다."

소규모 팀(5~15명)이 **Feature 단위**로 업무를 관리하고, 자유로운 워크플로우를 구성할 수 있는 **칸반보드 웹 애플리케이션**

**핵심 3요소**
- 명확한 마일스톤과 피쳐 관리
- 효율적인 칸반 보드, 간트 차트 시스템
- 실시간 협업 및 일정 관리

### 1.2 핵심 가치 제안

#### 1. 현업 PM이 설계한 실용적인 칸반 구조

> **"Feature → Task → Done, 핵심만 고정하고 나머지는 자유롭게"**

| 특징 | 설명 |
|------|------|
| **고정 블록** | 칸반의 본질인 Feature, Task, Done 세 블록만 고정 |
| **자유 확장** | In Progress, Review, QA 등 팀 프로세스에 맞는 블록 자유롭게 추가 |
| **자동 연동** | Feature 아래 Task 생성 시 Task 블록에 자동 배치 |
| **실시간 반영** | Done으로 이동하면 Feature 진행률 즉시 업데이트 |
| **마일스톤** | Feature들을 스프린트 단위로 묶어 기간별 관리 |

#### 2. 칸반 기반 간트차트 + 데일리 스케줄 통합

> **"작업 흐름부터 오늘 할 일까지, 팀 전체가 한눈에"**

| 뷰 | 용도 |
|------|------|
| **칸반 보드** | 전체 작업 흐름 파악, 블록 간 Task 이동 |
| **위클리 간트** | Task 기간 시각화, 일정 조정 |
| **데일리 스케줄** | 팀원별 오늘 할 일, 어디서 막혀 있는지 확인 |
| **데일리 체크리스트** | 날짜별 체크리스트 할당, 멤버별 우선순위 관리 ← v9.0 추가 |

**장점**
- 네 가지 뷰의 데이터가 연동 → 한 곳에서 수정하면 다른 뷰에 즉시 반영
- 서로의 업무 현황 파악 용이 → 자연스러운 유기적 협업
- 데일리 스크럼 시 화면만 띄워도 효과적인 회의 가능

#### 3. PM을 위한 통합 관리 대시보드

> **"마일스톤 관리부터 인원 배분까지, 프로젝트 전체를 컨트롤"**

| 기능 | 설명 |
|------|------|
| **번다운 차트** | 마일스톤 진행 상황 시각화 |
| **팀원 부하 현황** | 정상 / 과열 / 여유 상태 실시간 확인 |
| **자동 감지** | 3일 이상 정체 Task, 5일 넘게 막힌 체크리스트 알림 |
| **인원 할당** | 마일스톤별 누가 얼마나 투입 가능한지 사전 계획 |
| **통합 관리** | 인원 배분, 작업량 조정까지 하나의 대시보드에서 처리 |

#### 4. 부담 없는 시작, 숨겨진 비용 없음

> **"핵심 칸반은 무료, 프리미엄도 업계 최저 수준"**

| 항목 | BRIDGE | 타 서비스 |
|------|--------|----------|
| **무료 체험** | 7일 Premium 전체 기능 | 제한적 |
| **무료 후** | Feature → Task → Done 칸반 무제한 | 기능 대폭 제한 |
| **Premium 가격** | **$5/user/month** | Trello, Flow 등 대비 저렴 |
| **추가 결제** | 없음 (보이는 가격이 전부) | 플러그인마다 추가 과금 |

### 1.3 핵심 컨셉

| 컨셉 | 설명 |
|------|------|
| **고정 블록 3개** | Feature, Task, Done (삭제/수정 불가) |
| **커스텀 블록** | 팀 상황에 맞게 Task와 Done 사이에 자유롭게 추가 |
| **Feature-Task 연동** | Feature 내 서브태스크 추가 시 Task 블록에 카드 자동 생성 |
| **완료 추적** | Task가 Done 블록으로 이동하면 Feature 진행률 자동 반영 |
| **팀 협업** | 보드에 멤버 초대 및 역할 기반 권한 관리 |
| **태그 시스템** | Feature/Task에 태그 부여하여 분류 및 필터링 |
| **체크리스트** | Task 내부에 세부 항목 관리 |
| **마일스톤** | Feature들을 마일스톤 단위로 그룹화하여 기간별 관리 |
| **데일리 스케줄** | 구성원별 시간/블록 기반 업무 배치 및 관리 |
| **위클리 스케줄** | Task 기간을 Gantt 차트 형태로 시각화 및 조정 |
| **데일리 체크리스트** | 날짜별 체크리스트 할당 및 멤버별 우선순위 관리 ← v9.0 추가 |
| **보드 티어** | Standard/Premium 보드 구분 |
| **관리 대시보드** | 마일스톤 건강도, 팀 생산성, 지연 항목 관리 |
| **마일스톤 할당** | 멤버별 마일스톤 작업 시간 할당 및 추적 |
| **이메일 인증** | 회원가입 시 이메일 인증 필수 |
| **비밀번호 재설정** | 이메일 기반 비밀번호 재설정 |
| **테마 설정** | 다크/라이트 모드 지원 |
| **가중치 시스템** | Task별 중요도 가중치 설정 및 임팩트 분석 |

## 4. 회원 및 권한 시스템

### 4.1 회원 가입/로그인

- 이메일 + 비밀번호
- 소셜 로그인 (Google, GitHub)
- **이메일 인증 필수**
- **비밀번호 재설정**
- 프로필: 이미지, 이름, 이메일, **테마 설정**
- 내 보드 목록, 즐겨찾기 보드

### 4.2 이메일 인증 시스템

| 항목 | 설명 |
|------|------|
| **인증 시점** | 회원가입 완료 후 즉시 인증 이메일 발송 |
| **토큰 유효기간** | 24시간 |
| **재발송** | 60초 쿨다운 후 재발송 가능 |
| **미인증 상태** | 로그인 가능, 일부 기능 제한 표시 |

**인증 흐름**:
```
회원가입 완료 → 인증 이메일 발송 → 이메일 내 링크 클릭 → 인증 완료
                     ↓ (미클릭 시)
              인증 대기 페이지 → 재발송 요청 가능
```

### 4.3 비밀번호 재설정

| 항목 | 설명 |
|------|------|
| **요청 방법** | 로그인 화면 "비밀번호 찾기" 클릭 |
| **토큰 유효기간** | 1시간 |
| **비밀번호 규칙** | 8자 이상, 영문자+숫자 필수 |

**재설정 흐름**:
```
비밀번호 찾기 → 이메일 입력 → 재설정 링크 발송 → 새 비밀번호 입력 → 완료
```

### 4.4 보드 역할 (Role)
