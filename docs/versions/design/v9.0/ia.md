## 2. 네비게이션 구조

### 2.1 GNB (Global Navigation Bar)

```
┌─────────────────────────────────────────────────────────────────────┐
│  [로고]  [보드 선택 ▼]                    [알림] [사용자 메뉴 ▼]     │
└─────────────────────────────────────────────────────────────────────┘
```

| 요소 | 동작 | 조건 |
|------|------|------|
| 로고 | → 보드 목록 | 로그인 시 |
| 로고 | → 랜딩 페이지 | 비로그인 시 |
| 보드 선택 | 드롭다운: 내 보드 목록 | 로그인 시 |
| 알림 | 알림 드롭다운 | 로그인 시 |
| 사용자 메뉴 | 드롭다운: 설정, 로그아웃 | 로그인 시 |

### 2.2 보드 내 탭 네비게이션

```
┌─────────────────────────────────────────────────────────────────────┐
│  [칸반보드] [위클리] [데일리] [체크리스트] [관리] [통계]  [마일스톤 ▼] [설정] │
└─────────────────────────────────────────────────────────────────────┘
```

| 탭 | 경로 | Standard | Premium |
|----|------|:--------:|:-------:|
| 칸반보드 | `/boards/:id` | O | O |
| 위클리 | `/boards/:id/weekly` | 🔒 | O |
| 데일리 | `/boards/:id/daily` | 🔒 | O |
| 체크리스트 | `/boards/:id/checklist` | 🔒 | O | ← v9.0 추가
| 관리 | `/boards/:id/management` | 🔒 | O |
| 통계 | `/boards/:id/statistics` | 🔒 | O |

**🔒 표시**: 클릭 시 업그레이드 모달 표시

### 2.3 사용자 메뉴 드롭다운

```
┌─────────────────┐
│  [사용자명]      │
│  user@email.com │
├─────────────────┤
│  설정           │
│  ─────────────  │
│  로그아웃       │
└─────────────────┘
```

## 3. 화면 흐름 (User Flows)

### 3.1 회원가입 → 첫 보드 생성

```
┌─────────┐    ┌─────────┐    ┌─────────────┐    ┌─────────┐
│ 랜딩    │ → │ 회원가입 │ → │ 이메일 인증  │ → │ 보드 목록│
│ 페이지  │    │         │    │ 대기 페이지  │    │ (빈상태) │
└─────────┘    └─────────┘    └──────┬──────┘    └────┬────┘
                                     │                │
                              이메일 링크 클릭         │
                                     ↓                │
                              ┌─────────────┐         │
                              │ 인증 완료   │─────────┘
                              │ 페이지      │
                              └─────────────┘

보드 목록 (빈상태)
       │
       │ [+ 새 보드] 클릭
       ↓
┌─────────────┐    ┌─────────┐
│ 보드 생성   │ → │ 칸반 뷰  │
│ 모달        │    │ (빈상태) │
└─────────────┘    └─────────┘
```

### 3.2 로그인 → 보드 작업

```
┌─────────┐    ┌─────────┐    ┌─────────┐
│ 로그인  │ → │ 보드 목록│ → │ 칸반 뷰 │
│         │    │         │    │         │
└─────────┘    └─────────┘    └─────────┘
                                   │
         ┌───────────────────┬─────┼─────┬───────────────────┐
         │                   │           │                   │
         ↓                   ↓           ↓                   ↓
   ┌───────────┐      ┌───────────┐ ┌───────────┐     ┌───────────┐
   │ 위클리 뷰  │      │ 데일리 뷰  │ │체크리스트뷰│     │ 관리 뷰   │
   │ (Premium)  │      │ (Premium)  │ │(Premium)  │     │ (Premium)  │
   └───────────┘      └───────────┘ └───────────┘     └───────────┘
                                          ↑
                                     v9.0 추가
```

### 3.3 Task 생성 흐름

```
칸반 뷰
    │
    │ [+ Feature] 클릭
    ↓
┌─────────────┐    ┌─────────────┐
│ Feature     │    │ Feature     │
│ 생성 폼     │ → │ 카드 생성됨  │
└─────────────┘    └──────┬──────┘
                          │
                          │ Feature 카드 클릭
                          ↓
                   ┌─────────────┐
                   │ Feature     │
                   │ 상세 모달   │
                   └──────┬──────┘
                          │
                          │ [+ 서브태스크] 클릭
                          ↓
                   ┌─────────────┐    ┌─────────────┐
                   │ Task        │ → │ Task 카드   │
                   │ 생성 폼     │    │ Task 블록에 │
                   └─────────────┘    │ 자동 생성   │
                                      └─────────────┘
```

### 3.4 비밀번호 재설정 흐름

```
┌─────────┐    ┌─────────────┐    ┌─────────────┐
│ 로그인  │ → │ 비밀번호    │ → │ 이메일 발송 │
│ 페이지  │    │ 찾기 페이지  │    │ 완료 안내   │
└─────────┘    └─────────────┘    └─────────────┘
    │                                    │
    │                             이메일 링크 클릭
    │                                    ↓
    │                            ┌─────────────┐
    │                            │ 비밀번호    │
    │                            │ 재설정 페이지│
    │                            └──────┬──────┘
    │                                   │
    │                            변경 완료
    │                                   ↓
    └────────────────────────── ┌─────────────┐
                                │ 로그인      │
                                │ (자동 이동)  │
                                └─────────────┘
```

## 5. 에러/예외 화면

### 5.1 에러 페이지

| 상황 | 화면 | 동작 |
|------|------|------|
| 404 Not Found | 페이지 없음 | "페이지를 찾을 수 없습니다" + 홈으로 버튼 |
| 403 Forbidden | 권한 없음 | "접근 권한이 없습니다" + 보드 목록으로 |
| 500 Server Error | 서버 오류 | "문제가 발생했습니다" + 새로고침 버튼 |
| 네트워크 오류 | 연결 실패 | "인터넷 연결을 확인하세요" + 재시도 |

### 5.2 인라인 에러

| 상황 | 표시 위치 | 메시지 예시 |
|------|----------|------------|
| 폼 유효성 | 입력 필드 하단 | "이메일 형식이 올바르지 않습니다" |
| API 실패 | 토스트 알림 | "저장에 실패했습니다. 다시 시도해주세요" |
| 중복 데이터 | 입력 필드 하단 | "이미 사용 중인 이메일입니다" |
| 중복 체크리스트 | 토스트 알림 | "이미 추가된 항목입니다" | ← v9.0 추가

### 5.3 에러 바운더리 (ErrorBoundary)

| 상황 | 표시 내용 | 동작 |
|------|----------|------|
| 컴포넌트 에러 | "오류가 발생했습니다" | 홈으로/새로고침/재시도 버튼 |
| 개발 모드 | 상세 에러 정보 | 스택 트레이스 표시 |

## 6. 반응형 브레이크포인트

### 6.1 브레이크포인트 정의

| 이름 | 범위 | 주요 레이아웃 변화 |
|------|------|-------------------|
| Mobile | < 768px | 단일 컬럼, 햄버거 메뉴 |
| Tablet | 768px ~ 1024px | 2컬럼, 축소된 사이드바 |
| Desktop | > 1024px | 풀 레이아웃 |
