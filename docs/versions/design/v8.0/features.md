## 2. 카드 시스템

### 2.1 계층 구조

```
Feature (피쳐 카드)
    │
    ├── 제목, 설명, 담당자, 우선순위, 마감일, 태그
    ├── 진행률 (완료 Task / 전체 Task)
    │
    └── Task (태스크 카드)
            │
            ├── 제목, 설명, 시작일, 마감일, 태그
            ├── 예상 시간 (estimated_minutes)
            ├── 가중치 (weight_level)
            ├── 현재 블록 위치
            │
            └── Checklist (체크리스트)
                    │
                    ├── 항목명, 담당자
                    ├── 시작일, 마감일, 완료일
                    ├── 완료 여부
                    │
                    └── Schedule Block (타임블록)
                            │
                            ├── 날짜, 시작시간, 종료시간
                            └── 담당자
```

### 2.2 Task 담당자 개념

> **핵심 원칙**: Task 자체에는 담당자가 없으며, ChecklistItem의 담당자가 Task의 "소속 멤버"를 결정합니다.

| 항목 | 설명 |
|------|------|
| **Task 담당자** | ChecklistItem.assignee들로 결정 (Task.assignee 없음) |
| **ChecklistItem 담당자** | 각 체크리스트 항목에 담당자 지정 |
| **Task 소속 멤버** | 해당 Task의 ChecklistItem에 담당자로 지정된 모든 멤버 |
| **작업 시간 산정** | 멤버가 담당한 ChecklistItem → ScheduleBlock 시간 집계 |
| **통계 기준** | 팀 생산성, 작업 부하 등 모든 통계는 ChecklistItem.assignee 기준 |

```
예시:
Task: "API 개발"
├── Checklist: "JWT 구현" → 담당자: 김개발
├── Checklist: "OAuth 연동" → 담당자: 김개발
├── Checklist: "테스트 작성" → 담당자: 박QA
└── Checklist: "문서화" → 담당자: 이문서

→ Task 소속 멤버: 김개발, 박QA, 이문서
→ 카드에 3명의 아바타 표시
```

### 2.3 카드 생성 규칙

| 카드 | 생성 위치 | 생성 방법 | Standard 제한 |
|------|----------|----------|:-------------:|
| Feature | Feature 블록 | [+ Feature] 버튼 | - |
| Task | Task 블록 (자동) | Feature 상세 → 서브태스크 추가 | **10개** |
| Checklist | Task 내부 | Task 상세 → 체크리스트 추가 | - |
| Schedule Block | 데일리 스케줄 | 시간 영역 드래그 | Premium only |

### 2.4 카드 이동

- Feature: 이동 불가 (고정)
- Task: Task ↔ 커스텀 ↔ Done 자유롭게 이동
- Done 이동 시 Feature 진행률 자동 업데이트

### 2.5 Task 날짜 및 시간 필드

| 필드 | 설명 | 용도 |
|------|------|------|
| **start_date** | 시작일 | 주간 스케줄에서 Task 기간 표시 |
| **due_date** | 마감일 | 마감 관리, 상태 색상 결정 |
| **estimated_minutes** | 예상 시간 (분) | 용량 계획, 번다운 차트 |

### 2.6 Task 가중치 시스템

| 레벨 | 기본 가중치 | 용도 |
|------|:----------:|------|
| **Low** | 0.5 | 낮은 중요도 작업 |
| **Medium** | 1.0 | 일반 작업 (기본값) |
| **High** | 1.5 | 높은 중요도 작업 |
| **Critical** | 2.0 | 매우 중요한 작업 |

**활용**:
- 임팩트 점수 = Task 소요 시간 × 가중치
- 우선순위 기반 리소스 배분 의사결정
- 팀원별 임팩트 기여도 분석

## 3. 마일스톤 시스템 (Premium)

### 3.1 개요

마일스톤은 보드 내 Feature들을 **기간 단위로 그룹화**하여 관리하는 기능

### 3.2 마일스톤 구조

```
Milestone
├── title (제목)
├── description (설명, 선택)
├── start_date (시작일)
├── end_date (종료일)
├── features (연결된 Feature 목록)
├── progress_percentage (진행도)
├── allocations (멤버 할당 목록)
├── default_hours_per_day (기본 일일 시간, 기본값 6시간)
└── created_by (생성자)
```

### 3.3 Feature 연결

- 하나의 Feature는 **여러 마일스톤**에 포함될 수 있음 (다대다)
- 마일스톤 생성/수정 시 Feature 선택
- 마일스톤 선택 시 해당 Feature와 Task만 필터링 표시

### 3.4 진행도 계산

```
진행도 = (연결된 Feature들의 완료 Task 합계 / 전체 Task 합계) × 100
```

## 4. 마일스톤 할당 시스템

### 4.1 개요

마일스톤별로 멤버의 **작업 가능 일수와 시간**을 사전에 할당하여 용량 계획을 수립

### 4.2 할당 데이터

| 필드 | 설명 | 기본값 |
|------|------|:------:|
| **working_days** | 작업 일수 | - |
| **hours_per_day** | 일일 작업 시간 | 6시간 |
| **total_allocated_hours** | 총 할당 시간 | working_days × hours_per_day |
| **actual_worked_hours** | 실제 작업 시간 | ScheduleBlock 기반 계산 |

### 4.3 할당 설정 UI

```
┌────────────────────────────────────────────────────────────────────┐
│ 마일스톤 할당 관리 - Sprint 1                                    [X] │
├────────────────────────────────────────────────────────────────────┤
│  기간: 2026.01.06 ~ 2026.01.20 (15일)                              │
│  기본 일일 작업시간: 6시간                                          │
├────────────────────────────────────────────────────────────────────┤
│  팀원        │  참여일수  │  할당시간  │  실제시간  │  차이  │ 상태  │
│  ────────────────────────────────────────────────────────────────  │
│  김개발      │  12일     │  72h      │  68h      │  -4h  │ 정상  │
│  박디자인    │  10일     │  60h      │  78h      │ +18h  │ 과열  │
│  이기획      │  15일     │  90h      │  52h      │ -38h  │ 여유  │
│  ────────────────────────────────────────────────────────────────  │
│  합계        │   -       │  222h     │  198h     │ -24h  │       │
├────────────────────────────────────────────────────────────────────┤
│                                      [취소]    [저장]              │
└────────────────────────────────────────────────────────────────────┘
```

### 4.4 할당 상태 판정

| 상태 | 조건 | 의미 |
|------|------|------|
| **NORMAL (정상)** | -10% ≤ 차이 ≤ +10% | 적정 작업량 |
| **OVER (과열)** | 실제 > 할당의 110% | 할당 대비 과다 작업 |
| **UNDER (여유)** | 실제 < 할당의 90% | 할당 대비 적은 작업 |

### 4.5 할당 활용

| 용도 | 설명 |
|------|------|
| **용량 계획** | 마일스톤 기간 내 가용 시간 파악 |
| **오버커밋 분석** | Task 예상 시간 합 vs 가용 시간 비교 |
| **번다운 차트** | 이상적 작업량 계산 기준 |
| **작업 부하 분석** | 실제 작업 시간과 할당 시간 비교 |

## 5. 관리 대시보드 (Premium)

### 5.1 개요

프로젝트 관리자가 **마일스톤 건강도**, **팀 생산성**, **지연 항목**을 한눈에 파악할 수 있는 대시보드

### 5.2 대시보드 구조

```
┌────────────────────────────────────────────────────────────────────┐
│ 관리 대시보드                            [마일스톤: Sprint 1 v] [↻] │
├────────────────────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐              │
│  │ 건강 점수 │ │ 마일스톤  │ │ 팀원 현황 │ │ 지연 항목 │              │
│  │    78    │ │  2/3 정상 │ │  4/5 정상 │ │    3건   │              │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘              │
│                                                                    │
│  [마일스톤 건강도]  [팀원 생산성]  [지연 항목]                       │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │            현재 선택된 탭 콘텐츠                               │  │
│  └──────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

### 5.3 마일스톤 건강도 섹션

#### 건강 상태

| 상태 | 조건 | 색상 |
|------|------|------|
| **ON_TRACK** | 예상 완료일 ≤ 마감일 | 초록색 |
| **SLOW** | 예상 완료일 > 마감일 (7일 이내) | 주황색 |
| **AT_RISK** | 예상 완료일 > 마감일 (7일 초과) | 빨간색 |
| **OVERDUE** | 마감일 지남 & 미완료 | 빨간색 진함 |

#### 번다운 차트

```
작업량 ▲
      │
  100 ├─●──────────────────────────── 이상적 (점선)
      │   ╲
   80 ├─────●─────────────────────── 실제 (실선)
      │       ╲
   60 ├─────────●───────────────
      │           ●─●
   40 ├─────────────────●──────────

      │                         ╲
    0 ├───────────────────────────●
      └─────┼─────┼─────┼─────┼─────► 날짜
```

### 5.4 팀원 생산성 섹션

#### 테이블 컬럼

| 컬럼 | 설명 | 계산 방식 |
|------|------|----------|
| **팀원** | 팀원 정보 | - |
| **할당** | 담당 Task 수 | ChecklistItem assignee 기준 Task 카운트 |
| **완료** | 완료한 Task 수 | 위 기준 + Task.completed = true |
| **완료율** | 완료율 | 완료/할당 × 100 |
| **작업시간** | 실제/예상 시간 | ScheduleBlock 시간 / estimated_minutes |
| **상태** | 작업 부하 상태 | 아래 참조 |

#### 작업 부하 상태

| 상태 | 조건 | 의미 |
|------|------|------|
| **NORMAL (정상)** | 70% ≤ 완료율 ≤ 130% | 적정 작업량 |
| **OVERWORKED (과열)** | 완료율 > 130% | 할당 대비 과다 완료 |
| **RELAXED (여유)** | 완료율 < 70% | 할당 대비 적은 완료 |

## 6. 통계 분석 시스템 (Premium)

### 6.1 개요

보드와 개인의 **생산성 지표**, **임팩트 분석**, **일별 트렌드**를 시각화하는 분석 시스템

### 6.2 통계 대시보드 구조

```
┌────────────────────────────────────────────────────────────────────┐
│ 통계 분석                                   [필터] [기간: 1주 v]    │
├────────────────────────────────────────────────────────────────────┤
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐              │
│  │ 총 작업시간│ │ 완료 Task │ │ 임팩트점수│ │ 생산성   │              │
│  │   42.5h   │ │    28개   │ │   156.5  │ │  85%    │              │
│  └──────────┘ └──────────┘ └──────────┘ └──────────┘              │
│                                                                    │
│  [시간 분석]  [Task 분석]  [임팩트 분석]  [멤버 분석]  [트렌드]       │
│                                                                    │
│  ┌──────────────────────────────────────────────────────────────┐  │
│  │            현재 선택된 탭 콘텐츠                               │  │
│  └──────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────┘
```

### 6.3 시간 통계

| 지표 | 설명 | 계산 |
|------|------|------|
| **총 작업 시간** | 기간 내 ScheduleBlock 시간 합계 | Σ(endTime - startTime) |
| **예상 시간** | 기간 내 Task estimated_minutes 합계 | Σ(estimated_minutes) |
| **시간 효율** | 예상 대비 실제 | 예상/실제 × 100 |
| **평균 일일 시간** | 기간 내 일평균 작업 시간 | 총시간 / 일수 |

### 6.4 임팩트 분석

| 지표 | 설명 | 계산 |
|------|------|------|
| **임팩트 점수** | 가중치 적용 작업량 | Σ(작업시간 × 가중치) |
| **평균 가중치** | 완료 Task 평균 중요도 | Σ(가중치) / Task수 |
| **고중요 비율** | High/Critical Task 비율 | (High+Critical) / 전체 |

### 6.5 멤버별 통계

| 지표 | 설명 |
|------|------|
| **담당 Task** | ChecklistItem 담당자 기준 |
| **완료율** | 완료 Task / 담당 Task |
| **작업 시간** | 해당 멤버의 ScheduleBlock 시간 |
| **임팩트 점수** | 완료한 Task의 가중치 적용 점수 |
| **기여도** | 전체 대비 개인 임팩트 비율 |

### 6.6 통계 필터

| 필터 | 옵션 |
|------|------|
| **기간** | 1주, 2주, 1개월, 3개월, 전체 |
| **마일스톤** | 특정 마일스톤 선택 |
| **Feature** | 특정 Feature 선택 |
| **멤버** | 특정 멤버 선택 |
| **태그** | 특정 태그 선택 |

## 7. 위클리 스케줄 시스템 (Premium)

### 7.1 개요

Task의 시작일~마감일을 **Gantt 차트** 형태로 시각화하고, 드래그로 날짜를 조정하는 뷰

### 7.2 핵심 기능

| 기능 | 설명 |
|------|------|
| **일/주 토글** | 일 단위(60px/일) ↔ 주 단위(80px/주) 전환 |
| **날짜 범위 선택** | 시작일~종료일 직접 지정 |
| **오늘 버튼** | 오늘 위치로 스크롤 이동 |
| **Feature 접기/펼치기** | Feature 클릭으로 하위 Task 토글 |
| **Task 바 리사이즈** | 좌우 핸들 드래그로 시작일/마감일 조정 |
| **Task 바 이동** | 롱프레스(0.3초) 후 드래그로 전체 기간 이동 |
| **마일스톤 필터** | 선택한 마일스톤의 Feature/Task만 표시 |
| **체크리스트 게이지** | Task 바에 원형 진행률 표시 |

### 7.3 Task 상태별 색상

| 상태 | 색상 | 조건 |
|------|------|------|
| 완료 | 초록색 | task.completed = true |
| 마감 초과 | 빨간색 | due_date < today & 미완료 |
| 마감 임박 | 주황색 | due_date = today 또는 tomorrow |
| 진행 중 | 파란색 | start_date ≤ today ≤ due_date |
| 진행 전 | 회색 | start_date > today |

## 8. 데일리 스케줄 시스템 (Premium)

### 8.1 개요

구성원별로 하루 근무시간을 시각화하고, Checklist 단위로 업무를 시간/블록에 배치

### 8.2 표시 모드

| 모드 | 설명 | 표시 예시 |
|------|------|----------|
| **시간 기준** | 시작/종료 시간으로 관리 | 09:00 ~ 18:00 |
| **블록 기준** | 블록 개수로 관리 | 1번 ~ 16번 블록 |

### 8.3 핵심 기능

| 기능 | 설명 |
|------|------|
| **세로 드래그 생성** | 빈 영역을 세로로 드래그하여 타임블록 생성 |
| **리사이즈** | 블록 상/하단 핸들로 시작/종료 시간 조절 |
| **롱프레스 드래그 이동** | 블록 길게 누른 후 상/하 이동 |
| **중복 감지** | 이동 시 다른 블록과 겹치면 빨간색 경고 표시 |
| **계층 연결** | Time Block → Checklist → Task → Feature |

### 8.4 블록 색상

| 상태 | 색상 | 조건 |
|------|------|------|
| 기본 | 파란색 | Checklist 미완료 |
| 완료 | 초록색 | Checklist 완료 |
| 마감 임박 | 주황색 | due_date가 오늘/내일 |
| 마감 초과 | 빨간색 | due_date 지남 & 미완료 |
| 미연결 | 회색 | Checklist 연결 없음 |
