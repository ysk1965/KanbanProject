## 모듈 구성

### Frontend 모듈

| 모듈 | 경로 | 설명 |
|------|------|------|
| Auth | `contexts/AuthContext.tsx` | 인증 상태 관리 (JWT, Google OAuth) |

## 핵심 데이터 흐름

### 1. Feature → Task 진행률 연동

```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant TaskAPI
    participant FeatureAPI
    participant DB

    User->>Frontend: Task를 Done 블록으로 드래그
    Frontend->>TaskAPI: PATCH /tasks/{id}/move
    TaskAPI->>DB: Task.blockId 업데이트
    TaskAPI->>FeatureAPI: Feature 진행률 재계산 요청
    FeatureAPI->>DB: Feature.progress 업데이트
    FeatureAPI-->>Frontend: 업데이트된 Feature 반환
    Frontend-->>User: UI 갱신
```

### 2. 보드 진입 통합 API (NEW)

```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant BoardAPI
    participant DB

    User->>Frontend: 보드 클릭
    Frontend->>BoardAPI: GET /boards/{id}/full
    BoardAPI->>DB: 블록, 피쳐, 태스크, 멤버, 태그 등 일괄 조회
    BoardAPI-->>Frontend: BoardResponse.Full 반환
    Frontend-->>User: 칸반 보드 렌더링
    Note over Frontend: 기존 13개 API → 1개로 통합
```

### 3. Slack 멘션 알림 (NEW)

```mermaid
sequenceDiagram
    participant User
    participant Frontend
    participant CommentAPI
    participant SlackService
    participant Slack

    User->>Frontend: @멘션 포함 댓글 작성
    Frontend->>CommentAPI: POST /comments
    CommentAPI->>SlackService: 멘션된 사용자 알림 요청 (Async)
    SlackService->>Slack: Webhook POST (Block Kit 메시지)
    Slack-->>SlackService: 200 OK
    Note over SlackService: 사용자별/보드별 Webhook 설정 확인
```
