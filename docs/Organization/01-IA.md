## 1. Navigation Structure

```
BRIDGE SPOTS
──────────────────
  모든 보드          /boards
  조직 관리          /organizations       ← NEW
  마이 스페이스       /my-board
```

## 3. Screen Wireframes (Text)

### O-01: 조직 목록 (`/organizations`)

```
┌──────────────────────────────────────────────────────────┐
│  내 조직                                                  │
│  {N}개의 조직에 소속되어 있습니다                            │
│                                                          │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐   │
│  │ ████████████ │  │ ████████████ │  │              │   │
│  │ (gradient)   │  │ (gradient)   │  │              │   │
│  │              │  │              │  │     +        │   │
│  │ CookApps     │  │ Side Project │  │  조직 생성    │   │
│  │ 12명         │  │ 4명          │  │              │   │
│  │ 3 보드       │  │ 1 보드       │  │              │   │
│  │ 내 역할: Admin│  │ 내 역할: Owner│  │              │   │
│  └──────────────┘  └──────────────┘  └──────────────┘   │
└──────────────────────────────────────────────────────────┘
```

**구성 요소:**
- 페이지 헤더: 타이틀 + 소속 조직 수
- 조직 카드 그리드 (2~3 columns, 반응형)
  - 그라디언트 배경 (보드 카드와 유사)
  - 조직명
  - 멤버 수, 보드 수
  - 내 역할 뱃지
- 조직 생성 카드 (점선 테두리 + 아이콘)

**구성 요소:**
- 필터 바: 부서, 직무 그룹, 계약 형태, 근무 상태 (Select/Dropdown)
  - **근무 상태 기본값**: 재직 중 + 휴직 중 (ACTIVE + ON_LEAVE)
  - **퇴사(RESIGNED)**: 드롭다운에서 선택 시에만 노출
- 검색: 이름/이메일 텍스트 입력
- 정렬: 입사 최신순 / 이름순
- 멤버 카드 그리드 (2 columns, 반응형)
  - 프로필 이미지 + 온라인 상태 인디케이터
  - 이름 + 계약형태 뱃지 (색상 구분)
  - 부서명
  - 직무/역할 설명
  - 클릭 → 프로필 상세 (O-04)
- 하단 멤버 초대 버튼 (OrgAdmin+ only)

**구성 요소:**

  - 보드명, 태스크 진행률, 멤버 수, Owner
  - 방출 버튼 (OrgAdmin+, 확인 다이얼로그)
    - 확인 문구: "방출 후 비조직원도 이 보드에 참여할 수 있습니다. 재편입 시 모든 멤버가 조직원이어야 합니다."
- 보드 편입 버튼 → AddBoardToOrgModal (M-05)
  - 현재 사용자가 Owner인 미연동 보드만 표시
  - **[R1] 편입 전 검증**: 보드 멤버 전원이 조직원인지 사전 검증
- 새 보드 생성 → 기존 CreateBoardModal + 자동 조직 연동

**구성 요소:**
- 내 휴가 잔여 현황 바 (상단, 본인의 잔여일)
- 날짜 네비게이션 (◀ 날짜 ▶)
- 휴가 신청 버튼 → LeaveRequestModal (M-04)
- 카테고리별 섹션:
  - 연차 / 병가 / 리프레시 휴가 / 기타
  - 각 섹션별 테이블 (No, 소속, 이름, Type, 사유, Actions)
  - 데이터 없으면 "데이터 없음" 표시
- Actions: OrgAdmin+ → 승인/거절/편집

> **참고**: 현재 Phase 1의 사용일수는 캘린더 일수 기준 (주말/공휴일 포함). 영업일 기반은 Phase 2 예정.
