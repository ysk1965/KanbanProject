## 프로젝트 관리, 왜 이렇게 복잡할까?

팀 프로젝트를 하다 보면 이런 경험, 한 번쯤은 있지 않으셨나요?

- "이 태스크 누가 하고 있는 거지?"
- "이번 주까지 뭘 끝내야 하는 거였더라..."
- "슬랙에서 멘션 왔는데, 어느 작업 건인지 모르겠다"
- "엑셀로 일정 관리하다가 버전이 꼬였다"

저도 팀 프로젝트를 하면서 이 고민을 반복했습니다.

Notion은 자유도는 높은데 프로젝트 관리에 특화되어 있지 않고, Jira는 너무 무겁고, Trello는 기본 기능이 부족해서 Power-Up을 붙여야 쓸 만하고... 게다가 다 **인당 과금**이라 팀원이 늘수록 비용이 확 올라가더라고요.

그러다 **BRIDGE**라는 서비스를 써봤는데, 딱 맞았습니다. 칸반 보드 기반인데, 기존 도구들의 아쉬운 점을 정확히 채워주더라고요.

직접 써보면서 느꼈던 점들을 공유해볼게요.

## BRIDGE, 뭐가 다른데?

BRIDGE는 **칸반 보드를 중심으로 팀의 업무 흐름을 한눈에 파악하고 관리할 수 있는 웹 서비스**입니다.

처음에 "또 칸반 보드?"라고 생각했는데, 써보니까 좀 달랐어요.

가장 큰 차이는 **3단계 계층 구조**입니다.

```
Feature (기능 단위)
  └─ Task (작업 단위)
       └─ Checklist (세부 항목)
```

Trello는 카드가 전부 같은 레벨이에요. 그래서 "이 카드가 큰 기능인지, 세부 작업인지" 구분이 안 됩니다. BRIDGE는 **큰 그림(Feature)과 실행(Task)이 분리**되어 있고, Task를 Done으로 옮기면 Feature의 진행률이 자동으로 올라갑니다.

이게 진짜 편합니다. 일일이 퍼센트를 계산하거나, 스프레드시트에 완료 여부를 체크할 필요가 없어요.

## 핵심 기능 7가지

### 1. 칸반 보드 — 고정 3블록 + 자유 확장

BRIDGE의 칸반 보드는 구조가 명확합니다.

- **Feature 블록** (고정): 프로젝트의 기능 단위
- **Task 블록** (고정): 세부 작업
- **커스텀 블록** (자유 추가): "진행중", "리뷰중", "QA" 등 팀에 맞게
- **Done 블록** (고정): 완료 작업 자동 집계

핵심 흐름인 **Feature → Task → Done**은 고정되어 있고, 그 사이에 팀 프로세스에 맞는 블록을 자유롭게 넣는 구조예요. 개발팀이면 "In Progress → Code Review → QA"를, 디자인팀이면 "디자인 → 피드백 → 수정"을 넣으면 됩니다.

[이미지: Feature 상세 모달 — 진행률 바 + 하위 Task 목록]

### 2. 데일리 스케줄 — 오늘 할 일을 시간 단위로

"오늘 뭐부터 하지?" 하는 순간, 데일리 뷰를 열면 됩니다.

- **타임블록**: 체크리스트 항목을 30분 단위로 시간에 배치
- **데일리 체크리스트**: 오늘 처리할 항목을 멤버별로 정리
- **주간 뷰**: 이번 주 전체를 한눈에 조감

드래그로 시간을 조정하고, 클릭하면 연결된 Task까지 바로 확인됩니다. 매일 아침 이 화면만 열면 되니까, "오늘 뭐하지" 고민이 사라지더라고요.

[이미지: 데일리 스케줄 뷰 — 멤버별 타임블록 배치 화면]

### 3. 간트차트 — 스프레드시트 간트차트는 이제 그만

Task에 시작일/마감일을 설정하면 **간트차트로 전체 일정을 시각화**할 수 있습니다.

- Feature 단위로 접기/펼치기
- 바(Bar)를 드래그해서 일정 직접 조정
- 마일스톤별 필터링

엑셀로 간트차트를 만들어 본 분이라면 아실 거예요. 행 하나 추가할 때마다 수식이 깨지고, 색상을 다시 칠하고... BRIDGE에서는 그냥 카드를 만들면 바가 알아서 그려집니다.

[이미지: 간트차트 뷰 — Feature별 Task 바가 날짜 그리드 위에 표시된 화면]

### 4. @멘션 댓글 + Slack 알림 — 작업 맥락 안에서 소통

Task 카드 안에서 바로 댓글을 남기고, **@멘션**으로 팀원을 태그할 수 있습니다. 멘션하면 **인앱 알림과 Slack 알림이 동시에** 갑니다.

"이 부분 확인 부탁드려요"를 슬랙에 따로 보내고, 링크 첨부하고, 맥락을 설명하고... 이런 과정이 필요 없어요. **작업 맥락 안에서 바로 소통**하니까 슬랙에서 링크 찾아 헤매는 시간이 확 줄었습니다.

알림도 세밀하게 제어됩니다. 댓글 멘션, 체크리스트 배정, 태스크 댓글 — 이 세 가지를 인앱/Slack 각각 따로 On/Off 할 수 있어서, "중요한 멘션만 Slack으로 받고 나머지는 인앱으로" 같은 설정이 가능합니다.

[이미지: Task 상세 모달의 댓글 패널 — @멘션 하이라이트가 보이는 상태]

### 5. AI 주간 리포트 — "이번 주에 뭐 했지?"를 AI가 정리해줍니다

금요일마다 팀에 주간 보고를 쓰느라 고생하셨다면, 이 기능이 딱입니다.

BRIDGE는 칸반 보드의 활동 데이터(태스크 진행, 체크리스트, 시간 기록, 댓글)를 **AI가 교차 분석해서 서술형 주간 리포트**를 자동 생성합니다. 단순히 "체크리스트 3개 완료"가 아니라, "로그인 API 작업에 약 5시간을 투입했지만 OAuth 연동 이슈로 체크리스트가 정체됐고, 댓글에서 스펙 변경이 논의됐다" 같은 **맥락 있는 분석**을 해줍니다.

- **개인 리포트**: 나의 이번 주 활동을 Feature/Task별로 정리
- **팀 리포트**: 팀 전체의 병목, 워크로드 불균형, 마일스톤 리스크를 인사이트로 도출
- **스탠드업 요약**: 하루의 팀 활동을 데일리 스크럼용으로 자동 요약

프로젝트 활동 데이터를 AI가 분석해서 주간 리포트를 써주는 기능은 Trello, Asana, Jira, Notion **어디에도 없습니다.** BRIDGE **Premium($5/인/월)에만 있는 킬러 기능**입니다.

[이미지: AI 리포트 화면 — 구조화된 데이터 카드 + AI 서술형 분석]

### 6. Slack 데일리 스탠드업 — 매일 아침 Slack에 팀 현황이 옵니다

데일리 스크럼 전에 "어제 뭐 했더라?" 정리하는 시간, 사라집니다.

BRIDGE는 전일 보드 활동 데이터(타임블록, 체크리스트 완료, 댓글)를 **AI가 분석해서 매일 지정된 시간에 Slack으로 자동 발송**합니다.

- **시간/타임존 설정**: 팀 타임존에 맞춰 발송 시간 지정 (예: 매일 오전 9시)
- **AI 요약 생성**: 어제의 주요 성과, 논의 사항, 주의 항목을 자동 정리
- **Slack 채널 전송**: 보드 멤버 전원의 Slack 웹훅으로 발송
- **다국어 지원**: 한국어/영어 중 선택

스탠드업 미팅에서 AI 요약을 기반으로 **논의가 필요한 항목만 집중**하면, 미팅 시간이 절반 이하로 줄어듭니다.

[이미지: Slack 데일리 스탠드업 메시지 — AI 요약 + "BRIDGE에서 보기" 버튼]

### 7. AI 회의록 — 회의가 끝나면 Feature/Task가 생깁니다

회의 후 30분 걸리던 "회의록 정리 → 액션 아이템 추출 → 보드에 카드 생성"을 **10분으로 줄여줍니다.**

- **녹음**: 브라우저에서 바로 녹음 (별도 앱 불필요)
- **텍스트 변환**: OpenAI Whisper가 음성을 텍스트로 변환
- **AI 분석**: 메모 + 트랜스크립트를 AI가 분석 → 핵심 포인트 + 주제별 요약 + Feature/Task/Checklist 제안
- **보드 적용**: 체크박스로 원하는 항목만 골라서 칸반 보드에 자동 생성
- **중복 감지**: 기존 보드의 Feature/Task를 인식해서 겹치지 않게 제안

**"회의에서 나온 아이디어가 보드에 안 올라간다"**는 문제가 사라집니다. 회의 → 실행의 간극을 AI가 메워줍니다.

[이미지: AI 회의록 — 녹음 + AI 분석 결과 + Feature/Task/Checklist 트리]

## 요금제 — 솔직히 이게 제일 마음에 들었습니다

프로젝트 관리 도구의 가장 큰 고민이 **가격**이잖아요.

기존 도구들의 실질 비용을 보면:

| 서비스 | 인당 월 요금 | 10명 팀 월 비용 | 추가 과금 |
|--------|:-----------:|:-------------:|:---------:|
| Trello | $5~10 | $50~100 | Power-Up별 추가 |
| Asana | $11~25 | $110~250 | Business 이상 필요 |
| Jira | $7~12 | $70~120 | Marketplace 앱 별도 |
| Notion | $8~15 | $80~150 | AI 기능 $8/인 추가 |
| **BRIDGE** | **$5** | **$50** | **없음** |

인당 월 $10이면, 10명 팀은 매달 10만원 이상입니다. 여기에 간트차트, 타임라인 뷰 같은 기능을 붙이면 비용이 또 올라가요. 결국 제대로 쓰려면 **인당 $15~25**는 각오해야 하는 구조입니다.

BRIDGE는 다릅니다. **$5/인/월, 추가 과금 없음.** 간트차트도, Slack 연동도, 마일스톤도 다 포함입니다. 별도 플러그인을 구매할 필요가 없어요.

무료 Standard로도 기본 칸반 보드는 사용 가능하고, 보드 생성 시 **7일간 Premium 전체 기능을 무료 체험**할 수 있습니다. 가격표 보면서 고민하기 전에, 일단 써보시는 걸 추천합니다.
