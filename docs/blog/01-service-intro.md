# 팀워크 레벨업 #1 | 팀 프로젝트 관리, 아직도 스프레드시트로 하세요?

> **시리즈: 팀워크 레벨업** — BRIDGE SPOTS로 팀 협업을 한 단계 올리는 방법
> #1 서비스 소개편

## 프로젝트 관리, 왜 이렇게 복잡할까?

PO로 프로젝트를 관리하면서 JIRA, Trello, Flow, Notion — 거의 다 써봤습니다. 10명 내외 소규모 팀에서는 Trello가 가장 가볍고, 오토메이션 커스터마이징이 가능해서 꽤 오래 썼습니다.

그런데 쓸수록 한계가 명확했습니다.

- **오토메이션**을 원하는 수준으로 세팅하면 **퍼포먼스가 급격히 저하**
- **체크리스트를 보드에서 보는 것** 같은 단순 기능조차 **파워업 추가 비용** 발생
- **관리자 페이지**는 인당 월 구독료 **별도 부과**
- 결국 제대로 쓰려면 **비용이 계속 늘어나는 구조**

Notion은 자유도는 높은데 프로젝트 관리에 특화되어 있지 않고, Jira는 10명 팀에게는 너무 무겁고, Trello는 기본 기능이 부족해서 Power-Up을 붙여야 쓸 만하고... 게다가 다 **인당 과금**이라 팀원이 늘수록 비용이 확 올라갑니다.

이 문제를 직접 해결하고자 팀을 꾸려 **BRIDGE SPOTS**를 만들었습니다. 기존 도구들의 아쉬운 점을 정확히 채우는, 칸반 보드 기반의 프로젝트 관리 서비스입니다.

어떤 점이 다른지 공유해볼게요.

## BRIDGE SPOTS, 뭐가 다른데?

BRIDGE SPOTS는 **칸반 보드를 중심으로 팀의 업무 흐름을 한눈에 파악하고 관리할 수 있는 웹 서비스**입니다.

"또 칸반 보드?" 할 수 있는데, 기존 도구들과 결정적으로 다른 점이 두 가지 있습니다. **체계적인 계층 구조**와 **AI 네이티브 기능**입니다.

먼저 가장 큰 구조적 차이인 **3단계 계층 구조**부터 보겠습니다.

```
Feature (기능 단위)
  └─ Task (작업 단위)
       └─ Checklist (세부 항목)
```

Trello는 카드가 전부 같은 레벨이에요. 그래서 "이 카드가 큰 기능인지, 세부 작업인지" 구분이 안 됩니다. BRIDGE SPOTS는 **큰 그림(Feature)과 실행(Task)이 분리**되어 있고, Task를 Done으로 옮기면 Feature의 진행률이 자동으로 올라갑니다.

이게 진짜 편합니다. 일일이 퍼센트를 계산하거나, 스프레드시트에 완료 여부를 체크할 필요가 없어요. Trello에서 오토메이션으로 비슷하게 구현하려면 퍼포먼스가 눈에 띄게 떨어지는데, BRIDGE SPOTS에서는 기본 동작입니다.

[이미지: 칸반 보드 메인 화면 — Feature/Task/커스텀 블록/Done이 보이는 전체 뷰]

## 핵심 기능 8가지

### 1. 칸반 보드 — 고정 3블록 + 자유 확장

BRIDGE SPOTS의 칸반 보드는 구조가 명확합니다.

- **Feature 블록** (고정): 프로젝트의 기능 단위
- **Task 블록** (고정): 세부 작업
- **커스텀 블록** (자유 추가): "진행중", "리뷰중", "QA" 등 팀에 맞게
- **Done 블록** (고정): 완료 작업 자동 집계

핵심 흐름인 **Feature → Task → Done**은 고정되어 있고, 그 사이에 팀 프로세스에 맞는 블록을 자유롭게 넣는 구조예요. 개발팀이면 "In Progress → Code Review → QA"를, 디자인팀이면 "디자인 → 피드백 → 수정"을 넣으면 됩니다.

[이미지: Feature 상세 모달 — 진행률 바 + 하위 Task 목록]

### 2. 데일리 스케줄 — 오늘 할 일을 시간 단위로

"오늘 뭐부터 하지?" 하는 순간, 데일리 뷰를 열면 됩니다.

- **타임블록**: 체크리스트 항목을 30분 단위로 시간에 배치
- **데일리 체크리스트**: 오늘 처리할 항목을 멤버별로 정리
- **주간 뷰**: 이번 주 전체를 한눈에 조감

드래그로 시간을 조정하고, 클릭하면 연결된 Task까지 바로 확인됩니다. 매일 아침 이 화면만 열면 되니까, "오늘 뭐하지" 고민이 사라지더라고요.

[이미지: 데일리 스케줄 뷰 — 멤버별 타임블록 배치 화면]

### 3. 간트차트 — 스프레드시트 간트차트는 이제 그만

Task에 시작일/마감일을 설정하면 **간트차트로 전체 일정을 시각화**할 수 있습니다.

- Feature 단위로 접기/펼치기
- 바(Bar)를 드래그해서 일정 직접 조정
- 마일스톤별 필터링

엑셀로 간트차트를 만들어 본 분이라면 아실 거예요. 행 하나 추가할 때마다 수식이 깨지고, 색상을 다시 칠하고... BRIDGE SPOTS에서는 그냥 카드를 만들면 바가 알아서 그려집니다.

[이미지: 간트차트 뷰 — Feature별 Task 바가 날짜 그리드 위에 표시된 화면]

### 4. 실시간 댓글 + @멘션 + Slack 알림 — 작업 맥락 안에서 소통

Task 카드 안에서 바로 **실시간 댓글**을 남기고, **@멘션**으로 팀원을 태그할 수 있습니다. 댓글은 **실시간으로 반영**되어 팀원이 같은 카드를 보고 있다면 새로고침 없이 바로 확인됩니다. 멘션하면 **인앱 알림과 Slack 알림이 동시에** 갑니다.

"이 부분 확인 부탁드려요"를 슬랙에 따로 보내고, 링크 첨부하고, 맥락을 설명하고... 이런 과정이 필요 없어요. **작업 맥락 안에서 바로 소통**하니까 슬랙에서 링크 찾아 헤매는 시간이 확 줄었습니다. Slack 없이도 서비스 내에서 실시간으로 대화가 가능하다는 점이 핵심입니다.

알림도 세밀하게 제어됩니다. 댓글 멘션, 체크리스트 배정, 태스크 댓글 — 이 세 가지를 인앱/Slack 각각 따로 On/Off 할 수 있어서, "중요한 멘션만 Slack으로 받고 나머지는 인앱으로" 같은 설정이 가능합니다.

[이미지: Task 상세 모달의 댓글 패널 — @멘션 하이라이트가 보이는 상태]

### 5. AI 보고서 — 일간/주간 리포트를 AI가 자동 생성합니다

금요일마다 팀에 주간 보고를 쓰느라 고생하셨다면, 이 기능이 딱입니다.

BRIDGE SPOTS는 칸반 보드의 활동 데이터(태스크 진행, 체크리스트, 시간 기록, 댓글)를 **AI가 교차 분석해서 서술형 리포트**를 자동 생성합니다. 단순히 "체크리스트 3개 완료"가 아니라, "로그인 API 작업에 약 5시간을 투입했지만 OAuth 연동 이슈로 체크리스트가 정체됐고, 댓글에서 스펙 변경이 논의됐다" 같은 **맥락 있는 분석**을 해줍니다.

- **개인 리포트**: 구성원별 일간/주간 활동을 Feature/Task별로 정리
- **팀 리포트**: 팀 전체의 병목, 워크로드 불균형, 마일스톤 리스크를 인사이트로 도출 — **Slack으로 자동 알림**
- **스탠드업 요약**: 하루의 팀 활동을 데일리 스크럼용으로 자동 요약

프로젝트 활동 데이터를 AI가 분석해서 보고서를 써주는 기능은 Trello, Asana, Jira, Notion **어디에도 없습니다.** BRIDGE SPOTS만의 **AI 네이티브 기능**입니다.

[이미지: AI 리포트 화면 — 구조화된 데이터 카드 + AI 서술형 분석]

### 6. Slack 데일리 스탠드업 — 매일 아침 Slack에 팀 현황이 옵니다

데일리 스크럼 전에 "어제 뭐 했더라?" 정리하는 시간, 사라집니다.

BRIDGE SPOTS는 전일 보드 활동 데이터(타임블록, 체크리스트 완료, 댓글)를 **AI가 분석해서 매일 지정된 시간에 Slack으로 자동 발송**합니다.

- **시간/타임존 설정**: 팀 타임존에 맞춰 발송 시간 지정 (예: 매일 오전 9시)
- **AI 요약 생성**: 어제의 주요 성과, 논의 사항, 주의 항목을 자동 정리
- **Slack 채널 전송**: 보드 멤버 전원의 Slack 웹훅으로 발송
- **다국어 지원**: 한국어/영어 중 선택

스탠드업 미팅에서 AI 요약을 기반으로 **논의가 필요한 항목만 집중**하면, 미팅 시간이 절반 이하로 줄어듭니다.

[이미지: Slack 데일리 스탠드업 메시지 — AI 요약 + "BRIDGE SPOTS에서 보기" 버튼]

### 7. AI 회의록 — 회의가 끝나면 Feature/Task가 생깁니다

회의 후 30분 걸리던 "회의록 정리 → 액션 아이템 추출 → 보드에 카드 생성"을 **10분으로 줄여줍니다.**

- **녹음**: 브라우저에서 바로 녹음 (별도 앱 불필요)
- **텍스트 변환**: OpenAI Whisper가 음성을 텍스트로 변환
- **AI 분석**: 메모 + 트랜스크립트를 AI가 분석 → 핵심 포인트 + 주제별 요약 + Feature/Task/Checklist 제안
- **보드 적용**: 체크박스로 원하는 항목만 골라서 칸반 보드에 자동 생성
- **중복 감지**: 기존 보드의 Feature/Task를 인식해서 겹치지 않게 제안

**"회의에서 나온 아이디어가 보드에 안 올라간다"**는 문제가 사라집니다. 회의 → 실행의 간극을 AI가 메워줍니다.

[이미지: AI 회의록 — 녹음 + AI 분석 결과 + Feature/Task/Checklist 트리]

### 8. AI 문서 분석 — 문서를 올리면 작업이 제안됩니다

기획서, 회의 정리 문서, 스펙 문서 등을 BRIDGE SPOTS에 올리면, **AI가 문서를 분석해서 필요한 Feature/Task/Checklist를 자동으로 제안**합니다.

- **문서 업로드**: 기획서, 요구사항 정의서 등 프로젝트 관련 문서를 업로드
- **AI 분석**: 문서 내용을 파악하고, 어떤 작업이 필요한지 판단
- **작업 제안**: Feature/Task/Checklist를 구조화해서 제안
- **선택 적용**: 제안된 항목 중 원하는 것만 골라서 보드에 바로 반영

기획서를 받고 "이거 카드로 쪼개야 하는데..."라고 고민하는 시간이 사라집니다. **문서 → 실행 가능한 작업 목록**까지 AI가 연결해줍니다.

[이미지: AI 문서 분석 — 업로드된 문서 + AI 제안 Feature/Task 트리]

## 요금제 — Trello 가격에 AI까지 포함됩니다

프로젝트 관리 도구의 가장 큰 고민이 **가격**이잖아요.

Trello를 직접 써보면서 느꼈던 건, **기본 요금은 저렴해 보이는데 제대로 쓰려면 비용이 계속 늘어난다**는 점이었습니다.

| | Trello | BRIDGE SPOTS |
|--|:------:|:------------:|
| 기본 요금 | $5/인/월 | **무료** (Standard) |
| 프리미엄 | 추가 비용 계속 발생 | **$5/인/월** (Premium) |
| 관리자 기능 | **별도 과금** | 기본 포함 |
| AI 기능 | 없음 | **포함** |

Trello의 기본 요금제($5) 수준의 기능을 **무료**로 제공하고, 같은 가격($5)에 **AI 회의 자동화, AI 보고서, AI 문서 분석** 등 BRIDGE SPOTS에서만 가능한 기능들을 모두 사용할 수 있습니다.

AI 기능은 Premium 구독 시 **충분한 크레딧이 기본 제공**되며, 더 많이 사용하고 싶다면 **필요한 만큼 크레딧을 추가 구매**하면 됩니다. AI를 쓸 때마다 별도 요금이 붙는 구조가 아니라, 기본 제공량 안에서 자유롭게 사용할 수 있습니다.

다른 도구들과도 비교해보면:

| 서비스 | 인당 월 요금 | 10명 팀 월 비용 | 추가 과금 |
|--------|:-----------:|:-------------:|:---------:|
| Trello | $5~10 | $50~100 | Power-Up별 추가 |
| Asana | $11~25 | $110~250 | Business 이상 필요 |
| Jira | $7~12 | $70~120 | Marketplace 앱 별도 |
| Notion | $8~15 | $80~150 | AI 기능 $8/인 추가 |
| **BRIDGE SPOTS** | **$5** | **$50** | **없음** |

BRIDGE SPOTS는 **$5/인/월, 추가 과금 없음.** 간트차트도, Slack 연동도, 마일스톤도, AI 기능도 다 포함입니다. 별도 플러그인을 구매할 필요가 없어요.

| | Standard (무료) | Premium ($5/인/월) |
|--|:--------------:|:------------------:|
| 칸반 보드 | O | O |
| Task | 10개 제한 | 무제한 |
| 데일리 스케줄 | X | O |
| 간트차트 | X | O |
| 마일스톤 | X | O |
| AI 보고서 | X | O |
| AI 문서 분석 | X | O |
| Slack 데일리 스탠드업 | X | O |
| AI 회의록 | X | O |
| Slack 연동 | O | O |
| 관리자 기능 | O | O |
| 추가 과금 | **없음** | **없음** |

무료 Standard로도 기본 칸반 보드는 사용 가능하고, 보드 생성 시 **7일간 Premium 전체 기능을 무료 체험**할 수 있습니다. 가격표 보면서 고민하기 전에, 일단 써보시는 걸 추천합니다.

## 이런 팀에게 추천합니다

- **스타트업 / 사이드 프로젝트**: 가볍게 시작하고, 필요하면 확장
- **개발팀**: Feature → Task → Checklist 계층이 개발 워크플로우에 딱 맞음
- **디자인팀**: 간트차트로 일정 관리, 마일스톤으로 릴리즈 추적
- **프리랜서**: 여러 클라이언트 프로젝트를 보드별로 분리
- **학교 팀 프로젝트**: 누가 뭘 하고 있는지 투명하게 공유

## 마치며

PO로 JIRA, Trello, Flow, Notion을 다 써봤고, 결국 직접 만들었습니다. BRIDGE SPOTS는 **"딱 필요한 만큼"** 이라는 철학으로 설계했습니다.

화려한 기능이 잔뜩 있는 게 아니라, 매일 쓰는 칸반 보드가 정말 잘 동작합니다. 카드를 드래그하면 진행률이 올라가고, 멘션 하나로 팀원에게 알림이 가고, AI가 보고서를 정리해주고, 오늘 할 일을 타임블록으로 정리하고, 매일 아침 Slack에 팀 현황이 자동으로 오고, 회의가 끝나면 AI가 작업을 보드에 올려주고, 문서를 올리면 필요한 작업을 AI가 제안해주는 — **체계적인 업무 관리 + 실시간 협업 + AI 네이티브 기능**, 이 세 가지가 팀의 생산성을 만들어줍니다.
