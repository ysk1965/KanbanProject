### 컷 1: 칸반 보드 (0:05 ~ 0:07, 2.5초)

**연출**: Task 카드를 Done 블록으로 드래그 → Feature 진행률 바가 올라가는 인터랙션. 좌하단에 태그 뱃지 "3단계 계층 구조"

| ID | 유형 | 소스 설명 | 촬영 조건 |
|:--:|:----:|----------|----------|
| S02-1A | **화면 녹화** (3~5초) | Task 카드를 잡고 → Done 블록에 드롭 → Feature 진행률 바가 상승하는 장면 | **보드 뷰**(모달 아닌)에서 진행률 변화가 보여야 함. 드래그 동작이 부드럽게 |
| S02-1B | **스크린샷** | 칸반 보드 전체 뷰. Feature/Task/커스텀 블록("In Progress","Code Review","QA")/Done이 모두 보이는 상태 | 각 블록에 카드 2~3개씩 분산. Feature 카드에 진행률 바 30~70%. Done에 완료 카드 1~2개 |

**촬영 체크리스트**:
- [ ] Feature 블록에 진행률 바가 보이는 카드가 있는가
- [ ] 커스텀 블록명이 "In Progress", "Code Review" 등으로 설정되었는가
- [ ] Done 블록에 완료 카드 1~2개가 있는가
- [ ] 드래그 전/후 진행률 수치 변화가 눈에 보이는가

## S03 — AI가 일합니다 (0:20 ~ 0:32)

### 연출

타이틀 카드 "AI가 일하는 시간" (틸 글로우, 1초). 이후 **3분할 가로 레이아웃**으로 동시에 보여줌:

### 나레이션

> "회의를 녹음하면 AI가 Feature와 Task를 자동 생성하고, 주간 보고서를 AI가 대신 써주고, 기획서를 올리면 필요한 작업을 제안합니다. 프로젝트 관리 도구에 AI가 네이티브로 들어간 건, BRIDGE SPOTS가 유일합니다."
