## 영상 개요

| 항목 | 내용 |
|------|------|
| **목적** | 서비스 소개 + 가입 유도 |
| **타겟** | PM, PO, 스타트업 팀, 사이드 프로젝트 팀 |
| **톤앤매너** | 공감형 → 해결형 → 데모형 |
| **예상 길이** | 2분 30초 ~ 3분 |

## Scene 1 — 공감 (0:00 ~ 0:20)

**화면**: 어두운 배경에 텍스트 타이핑 효과

> "프로젝트 관리, 아직도 이렇게 하고 있나요?"

**빠르게 전환되는 장면들** (각 2~3초):

| # | 장면 | 설명 |
|---|------|------|
| 1 | 스프레드시트 간트차트 | 수식 깨지는 모습 |
| 2 | Trello 보드 | Power-Up 결제 팝업 |
| 3 | Slack 채널 | "이거 어디까지 됐어요?" 반복 |
| 4 | Jira 설정 화면 | 끝없는 스크롤 |

**내레이션**:

> "JIRA는 너무 무겁고, Trello는 기본 기능이 부족하고, Notion은 프로젝트 관리에 특화되어 있지 않고... 게다가 다 인당 과금."

**BGM**: 약간 답답한 톤의 미니멀 일렉트로닉

---

## Scene 2 — 전환 (0:20 ~ 0:30)

**화면**: 화면이 어두워지며 중앙에 BRIDGE SPOTS 로고 등장 (우주/코스믹 테마 글로우 효과)

**내레이션**:

> "그래서 직접 만들었습니다."

**텍스트 오버레이**:

> **BRIDGE SPOTS** — 체계적 업무 관리 + 실시간 협업 + AI

**BGM**: 전환 — 밝고 모던한 톤으로 변경

---

## Scene 3 — 핵심 구조 소개 (0:30 ~ 0:55)

**화면**: 칸반 보드 실제 화면 (데모 보드)

**모션 그래픽**으로 3단계 계층 구조 시각화:

```
Feature (기능 단위)
  └─ Task (작업 단위)
       └─ Checklist (세부 항목)
```

**내레이션**:

> "BRIDGE SPOTS는 Feature, Task, Checklist 3단계 계층 구조입니다. Trello에서는 카드가 전부 같은 레벨이라 큰 기능인지 세부 작업인지 구분이 안 되죠. BRIDGE SPOTS에서는 Task를 Done으로 옮기면 Feature 진행률이 자동으로 올라갑니다."

**화면 액션**:

1. Task 카드를 드래그해서 Done 블록으로 이동
2. Feature 카드의 진행률 바가 실시간으로 올라가는 모습
3. 커스텀 블록(In Progress, Code Review, QA) 추가하는 모습

---

## Scene 4 — 핵심 기능 쇼케이스 (0:55 ~ 1:50)

빠른 템포로 기능별 실제 화면 전환. 각 기능 10~12초씩.

### 4-1. 데일리 스케줄 (0:55 ~ 1:05)

**화면**: 타임블록 뷰

**내레이션**:

> "오늘 뭐부터 하지? 데일리 스케줄에서 체크리스트를 시간 단위로 배치하세요. 드래그 한 번이면 하루가 정리됩니다."

**화면 액션**: 체크리스트 항목을 타임블록에 드래그하는 모습

---

### 4-2. 간트차트 (1:05 ~ 1:15)

**화면**: 간트차트 뷰

**내레이션**:

> "스프레드시트 간트차트는 이제 그만. 카드를 만들면 바가 알아서 그려지고, 드래그로 일정을 조정할 수 있습니다."

**화면 액션**: 간트차트 바를 드래그해서 일정 변경

---

### 4-3. 실시간 댓글 + 알림 (1:15 ~ 1:25)

**화면**: Task 상세 모달 댓글 영역

**내레이션**:

> "작업 맥락 안에서 바로 소통하세요. @멘션 하나로 인앱 알림과 Slack 알림이 동시에 갑니다."

**화면 액션**: 댓글에 @멘션 입력 → Slack 알림 도착 애니메이션

---

### 4-4. AI 기능 하이라이트 (1:25 ~ 1:50)

화면 전환 속도 높이며 AI 기능 3개 연속.

#### ① AI 보고서 (1:25 ~ 1:33)

**내레이션**:

> "금요일 주간 보고? AI가 활동 데이터를 분석해서 서술형 리포트를 자동 생성합니다."

**화면**: AI 리포트 화면 — 구조화된 카드 + AI 분석 텍스트 생성되는 모습

#### ② AI 회의록 (1:33 ~ 1:41)

**내레이션**:

> "회의가 끝나면 녹음 파일에서 Feature와 Task가 자동으로 제안됩니다."

**화면**: 녹음 → 트랜스크립트 → Feature/Task 트리 생성 → 체크박스 선택 → 보드에 반영

#### ③ AI 문서 분석 (1:41 ~ 1:50)

**내레이션**:

> "기획서를 올리면 필요한 작업을 AI가 제안합니다. 문서에서 실행까지, AI가 연결합니다."

**화면**: 문서 업로드 → AI 분석 → Feature/Task 제안 트리
