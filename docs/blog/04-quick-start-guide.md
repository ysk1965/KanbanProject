# 팀워크 레벨업 #4 | 5분 만에 팀 보드 만들기 (따라하기)

> **시리즈: 팀워크 레벨업** — BRIDGE로 팀 협업을 한 단계 올리는 방법
> #4 실전 가이드편

---

## 5분이면 됩니다

지금까지 BRIDGE가 무엇인지(#1), Trello와 뭐가 다른지(#2), 가격이 얼마나 합리적인지(#3) 이야기했는데요.

이번 편은 **직접 해보는 시간**입니다.

회원가입부터 첫 Feature 생성, 팀원 초대까지 — 실제로 5분이면 팀 보드가 완성됩니다. 스크린샷과 함께 따라해보세요.

---

## Step 1. 회원가입 (1분)

BRIDGE 사이트에 접속하면 랜딩 페이지가 나옵니다. 우측 상단 **"시작하기"** 버튼을 클릭하세요.

### 가입 방법 2가지

**방법 A: 이메일 가입**

1. 이름 입력
2. 이메일 입력
3. 비밀번호 입력
4. 이용약관 동의 체크
5. "가입하기" 클릭

비밀번호는 **8자 이상, 영문 대/소문자 + 숫자 + 특수문자** 포함이어야 합니다.

가입 후 인증 이메일이 발송됩니다. 메일함에서 인증 링크를 클릭하면 완료!

**방법 B: Google 로그인** (추천)

Google 계정으로 원클릭 가입. 별도 인증 없이 바로 시작할 수 있어서 더 빠릅니다.

[이미지: 로그인 화면 — 이메일 입력 필드 + Google 로그인 버튼]

---

## Step 2. 보드 만들기 (30초)

로그인하면 대시보드(보드 목록)로 이동합니다. 여기서 **"새 보드 만들기"** 버튼을 클릭하세요.

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:----:|------|
| 보드 이름 | O | 프로젝트 이름 (예: "MVP 개발", "2월 스프린트") |
| 설명 | X | 프로젝트 한 줄 설명 |
| 배경 색상 | O | 6가지 그라데이션 중 선택 |

배경 색상을 고르면 미리보기가 실시간으로 바뀝니다. 마음에 드는 걸 고르고 **"만들기"**를 누르세요.

> 보드를 만드는 순간 **7일 Premium Trial**이 자동 시작됩니다. 간트차트, 데일리 스케줄, 마일스톤 등 전체 기능을 7일간 무료로 써볼 수 있어요.

[이미지: 보드 만들기 모달 — 이름 입력 + 그라데이션 색상 선택 + 미리보기]

---

## Step 3. 첫 Feature 만들기 (1분)

보드에 들어가면 칸반 보드가 보입니다. 기본으로 **Feature, Task, Done** 세 개의 고정 블록이 있어요.

Feature 블록에서 **"+ Feature"** 버튼을 클릭합니다.

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:----:|------|
| 제목 | O | 기능 이름 (예: "사용자 인증") |
| 설명 | X | 기능에 대한 설명 |
| 마감일 | X | 목표 완료일 |

제목만 입력하고 **"추가"**를 누르면 Feature 카드가 생성됩니다.

예시로 이렇게 만들어보세요:

```
Feature 1: "사용자 인증"
Feature 2: "대시보드 UI"
Feature 3: "결제 시스템"
```

[이미지: Feature 추가 모달 — 제목/설명/마감일 입력]

> Feature 카드를 클릭하면 상세 모달이 열립니다. 여기서 **색상**, **태그**, **설명** 등을 추가할 수 있어요. 지금은 넘어가고, 나중에 필요할 때 설정하면 됩니다.

---

## Step 4. Task 추가하기 (1분)

Feature를 만들었으면, 이제 세부 작업(Task)을 추가합니다.

방금 만든 Feature 카드를 **클릭**하면 상세 모달이 열려요. 하단에 **서브태스크 추가** 입력란이 있습니다.

### 추가 방법

1. Feature 카드 클릭 → 상세 모달 열기
2. 하단 입력란에 Task 제목 입력
3. Enter 또는 "추가" 클릭

Task를 추가하면 **자동으로 Task 블록에 카드가 생성**됩니다. 직접 Task 블록에서 만드는 게 아니라, Feature 안에서 만드는 거예요. 이게 BRIDGE의 핵심 구조입니다.

예시:

```
Feature "사용자 인증"
  ├─ Task "로그인 API 구현"        ← 추가!
  ├─ Task "회원가입 페이지 개발"    ← 추가!
  └─ Task "비밀번호 재설정 기능"    ← 추가!
```

Task를 추가할 때마다 **진행률 바**가 업데이트됩니다. 3개 중 0개 완료니까 0%. 나중에 Task를 Done으로 드래그하면 자동으로 올라가요.

[이미지: Feature 상세 모달 — 서브태스크 목록 + 진행률 바 + 하단 입력란]

---

## Step 5. 팀원 초대하기 (1분)

혼자 쓰는 보드도 좋지만, 팀 보드가 진짜 힘을 발휘합니다.

보드 상단의 **"공유"** 버튼을 클릭하면 공유 모달이 열립니다.

### 초대 방법 2가지

**방법 A: 초대 링크 공유** (추천)

1. 공유 모달에서 **"링크 복사"** 클릭
2. 복사된 링크를 슬랙, 카톡 등으로 팀원에게 전달
3. 팀원이 링크를 열고 가입하면 자동으로 보드에 참여

가장 빠르고 간편합니다. 링크 하나로 여러 명을 한 번에 초대할 수 있어요.

**방법 B: 이메일로 직접 초대**

1. 팀원 이메일 입력
2. 역할 선택 (Admin / Member / Observer)
3. "초대" 클릭

역할별 권한은 이렇습니다:

| 역할 | 할 수 있는 것 |
|------|-------------|
| **Admin** | 보드 설정, 멤버 관리, Feature/Task 생성 |
| **Member** | Feature/Task 생성 및 수정, 댓글 |
| **Observer** | 읽기 전용 (외부 이해관계자에게 적합) |

[이미지: 공유 모달 — 멤버 목록 + 역할 뱃지 + 초대 링크 복사 버튼]

> 각 멤버에게 **고유 색상**이 자동으로 배정됩니다. 칸반 보드에서 카드에 표시되는 아바타 색상으로, 누가 어떤 작업을 맡고 있는지 한눈에 구분돼요. 색상은 공유 모달에서 변경할 수도 있습니다.

---

## Step 6. 워크플로우 커스텀하기 (30초)

기본 블록은 **Feature → Task → Done** 세 개입니다. 여기에 팀 프로세스에 맞는 블록을 추가해보세요.

보드 상단 또는 블록 사이의 **"+"** 버튼을 클릭합니다.

### 입력 항목

| 항목 | 필수 | 설명 |
|------|:----:|------|
| 블록 이름 | O | 예: "진행중", "리뷰", "QA" |
| 색상 | O | 8가지 프리셋 중 선택 |

팀 유형별 추천 커스텀 블록:

```
개발팀:    Task → [In Progress] → [Code Review] → [QA] → Done
디자인팀:  Task → [디자인] → [피드백] → [수정] → Done
기획팀:    Task → [작성중] → [리뷰] → [승인] → Done
```

커스텀 블록은 **Task와 Done 사이**에 자유롭게 추가됩니다. 이름과 색상은 나중에 언제든 변경할 수 있어요.

[이미지: 블록 추가 모달 — 이름 입력 + 8색 컬러 선택]

## 완성! 30초 만에 확인하는 결과물

여기까지 따라하셨다면, 이런 보드가 만들어져 있을 거예요.

```
┌─────────────┬─────────────┬─────────────┬─────────────┬─────────────┐
│   Feature   │    Task     │ In Progress │ Code Review │    Done     │
│             │             │             │             │             │
│ ┌─────────┐ │ ┌─────────┐ │             │             │             │
│ │사용자 인증│ │ │로그인 API│ │             │             │             │
│ │ 진행률 0%│ │ │         │ │             │             │             │
│ └─────────┘ │ ├─────────┤ │             │             │             │
│ ┌─────────┐ │ │회원가입  │ │             │             │             │
│ │대시보드UI│ │ │페이지   │ │             │             │             │
│ │ 진행률 0%│ │ ├─────────┤ │             │             │             │
│ └─────────┘ │ │비밀번호  │ │             │             │             │
│ ┌─────────┐ │ │재설정   │ │             │             │             │
│ │결제 시스템│ │ └─────────┘ │             │             │             │
│ │ 진행률 0%│ │             │             │             │             │
│ └─────────┘ │             │             │             │             │
└─────────────┴─────────────┴─────────────┴─────────────┴─────────────┘
```

이제 Task 카드를 **드래그 앤 드롭**으로 In Progress, Code Review, Done으로 옮겨보세요. Feature의 진행률이 자동으로 올라가는 걸 확인할 수 있습니다.

[이미지: 완성된 칸반 보드 — Feature 3개 + Task 여러 개 + 커스텀 블록]

## 자주 묻는 질문

**Q. 보드를 여러 개 만들 수 있나요?**

네. 프로젝트별로 보드를 분리해서 쓸 수 있습니다. 각 보드마다 독립적으로 멤버를 초대하고 관리할 수 있어요.

**Q. Task는 Feature 없이 만들 수 없나요?**

네. Task는 반드시 Feature의 하위 항목으로 생성됩니다. 이게 BRIDGE의 핵심 설계예요. 모든 작업이 "어떤 기능을 위한 작업인지" 명확해지고, 진행률 자동 추적이 가능해집니다.

**Q. 무료(Standard)로는 어디까지 쓸 수 있나요?**

칸반 보드(Feature/Task/Done) + 멤버 초대 + 태그 + 체크리스트 + Slack 연동은 무료입니다. Task가 보드당 10개로 제한되고, 데일리 스케줄/간트차트/마일스톤은 Premium 전용이에요.

**Q. Trial이 끝나면 데이터가 사라지나요?**

아니요. Standard로 자동 전환되지만, **기존 데이터는 모두 유지**됩니다. Premium 기능(간트차트, 데일리 등)에 접근만 제한될 뿐, 만들어둔 Task나 Feature는 그대로예요.
