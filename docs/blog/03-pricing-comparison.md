# 팀워크 레벨업 #3 | 프로젝트 관리 도구, 인당 $5면 충분합니다

> **시리즈: 팀워크 레벨업** — BRIDGE로 팀 협업을 한 단계 올리는 방법
> #3 가격 비교편

---

## 가격표만 보면 모릅니다

프로젝트 관리 도구를 고를 때, 대부분 이렇게 검색합니다.

"Trello 가격", "Asana 요금제", "Jira 비용"

그런데 가격표 페이지를 보고 "인당 $5~10이면 괜찮네" 하고 결제하면, 나중에 **생각보다 많이 나옵니다.**

왜냐면 가격표에 적힌 금액은 "기본 기능"의 가격이고, 팀이 실제로 필요로 하는 기능을 쓰려면 **한두 단계 위 플랜**이나 **추가 결제**가 필요한 경우가 대부분이기 때문이에요.

오늘은 Trello, Asana, Jira, Notion, 그리고 BRIDGE — 5개 도구의 **"실질 비용"**을 10명 팀 기준으로 직접 계산해봤습니다.

> 아래 가격은 2026년 기준이며, 각 서비스의 요금 정책에 따라 변동될 수 있습니다.

## 1. Trello — 기본은 싸지만, Power-Up이 문제

### 가격표

| 플랜 | 인당 월 가격 | 주요 기능 |
|------|:-----------:|----------|
| Free | $0 | 보드 10개, Power-Up 제한 |
| Standard | $5 | 무제한 보드, 체크리스트 |
| Premium | $10 | 달력/타임라인 뷰, 대시보드 |
| Enterprise | $17.50 | 조직 관리, 보안 |

### 실질 비용

Trello Standard($5)로 시작하면 기본 칸반은 됩니다. 그런데 팀이 실제로 필요한 것들을 붙이기 시작하면:

| 필요한 기능 | 해결 방법 | 추가 비용 |
|------------|----------|:---------:|
| 간트차트 | Power-Up 또는 Premium 업그레이드 | +$5~10/인 |
| 보드에서 체크리스트 보기 | Power-Up | +$3~5/인 |
| 통계/분석 | Power-Up | +$3~5/인 |
| 고급 자동화 | Butler 한도 초과 시 업그레이드 | +$5/인 |

결국 "제대로" 쓰려면 Premium($10/인)으로 올리거나, Standard + Power-Up 2~3개를 붙여야 합니다. 거기다 #2편에서 말했듯이, Power-Up을 붙일수록 보드가 느려지는 문제도 있고요.

**10명 팀 실질 비용: 월 $100~150**

## 2. Asana — 기능은 강력하지만, 가격도 강력하다

### 가격표

| 플랜 | 인당 월 가격 | 주요 기능 |
|------|:-----------:|----------|
| Personal | $0 | 10명 제한, 기본 기능 |
| Starter | $10.99 | 타임라인, 워크플로우 빌더 |
| Advanced | $24.99 | 포트폴리오, 목표, 워크로드 |
| Enterprise | 별도 문의 | SSO, SAML, 감사 로그 |

### 실질 비용

Asana는 기능이 확실히 많습니다. 문제는 **팀에서 많이 쓰는 기능들이 대부분 Starter 이상**이라는 점이에요.

| 기능 | 필요 플랜 |
|------|:---------:|
| 타임라인 (간트차트) | Starter ($10.99) |
| 대시보드 (보고서) | Starter ($10.99) |
| 마일스톤 | Starter ($10.99) |
| 워크로드 (팀 부하 분석) | Advanced ($24.99) |
| 포트폴리오 (프로젝트 그룹) | Advanced ($24.99) |
| 목표 추적 | Advanced ($24.99) |

간트차트와 대시보드만 필요해도 $10.99/인. 워크로드 분석까지 쓰려면 $24.99/인. 10명이면 **월 $250**입니다. 연간으로 하면 $3,000이에요.

Asana의 기능 자체는 훌륭하지만, 소규모 팀이 쓰기에는 가격 부담이 상당합니다.

**10명 팀 실질 비용: 월 $110~250**

## 3. Jira — 개발팀 표준이지만, 가볍지 않다

### 가격표

| 플랜 | 인당 월 가격 | 주요 기능 |
|------|:-----------:|----------|
| Free | $0 | 10명 제한, 기본 칸반/스크럼 |
| Standard | $7.16 | 250명, 감사 로그 |
| Premium | $12.48 | 고급 로드맵, 샌드박스 |
| Enterprise | 별도 문의 | 무제한, 분석 |

### 실질 비용

Jira Free는 10명 이하 팀이라면 꽤 괜찮습니다. 그런데 10명을 넘거나, 고급 로드맵이 필요하면 유료 플랜으로 넘어가야 해요.

여기서 숨은 비용이 생깁니다:

| 필요한 기능 | 해결 방법 | 추가 비용 |
|------------|----------|:---------:|
| 간트차트 | Marketplace 앱 (Advanced Roadmaps 등) | Premium 필요 |
| 시간 추적 | Marketplace 앱 (Tempo 등) | +$8~10/인 |
| 문서 관리 | Confluence 연동 | +$5~6/인 |
| 디자인 연동 | Figma/Zeplin 앱 | 별도 과금 |

Jira 자체는 $7.16이지만, Confluence + Marketplace 앱을 합치면 쉽게 $15~25/인이 됩니다.

그리고 솔직히, 5~10명 규모의 팀에게 Jira는 너무 무겁습니다. 학습 곡선이 높고, 설정할 것이 많고, "칸반 보드 하나 만들자"에 비해 들어가는 초기 시간이 큽니다.

**10명 팀 실질 비용: 월 $70~250 (Marketplace 앱 포함)**

## 4. Notion — 만능이지만, 프로젝트 관리 전문은 아니다

### 가격표

| 플랜 | 인당 월 가격 | 주요 기능 |
|------|:-----------:|----------|
| Free | $0 | 블록 제한, 10명 게스트 |
| Plus | $8 | 무제한 블록, 파일 업로드 |
| Business | $15 | 고급 권한, 차트 |
| Enterprise | 별도 문의 | SSO, 감사 로그 |
| AI 애드온 | +$8/인 | Notion AI |

### 실질 비용

Notion의 강점은 자유도입니다. 칸반 보드도 만들 수 있고, 데이터베이스, 문서, 위키까지 다 됩니다. 프로젝트 관리 "전용" 도구가 아니라 "범용" 도구예요.

문제는:

- **칸반 보드를 직접 구성해야 함**: 템플릿이 있긴 하지만, Feature → Task → Checklist 같은 계층 구조를 만들려면 직접 데이터베이스를 설계해야 합니다
- **자동 진행률 추적 없음**: 수식(Formula)으로 직접 만들어야 함
- **간트차트**: Timeline 뷰가 있지만, Plus 이상 필요
- **AI를 쓰려면**: 인당 $8 추가

Plus($8) + AI($8) = $16/인. 팀이 10명이면 **월 $160**.

Notion은 "프로젝트 관리 + 문서 + 위키"를 하나에서 하고 싶은 팀에게는 좋지만, **프로젝트 관리만 놓고 보면 가성비가 낮습니다.** 칸반 보드에 자동 진행률도 없고, 간트차트도 기본 수준이고, 데일리 스케줄 같은 뷰는 아예 없으니까요.

**10명 팀 실질 비용: 월 $80~160**

|------|:---------:|
| 칸반 보드 (3단계 계층) | O |
| 자동 진행률 추적 | O |
| 간트차트 | O |
| 데일리 스케줄 (타임블록) | O |

| 마일스톤 + 번다운 차트 | O |

| **추가 과금** | **없음** |

$5 안에 이 기능이 전부 들어 있습니다. "간트차트 쓰려면 다음 플랜으로"가 아니에요.

**10명 팀 실질 비용: 월 $50 (연 $500)**

## 무료 플랜만으로도 쓸 만한가?

"일단 무료로 써보고 싶다"면, 각 도구의 무료 플랜을 비교해보세요.

| | Trello Free | Asana Personal | Jira Free | Notion Free | BRIDGE Standard |
|--|:-----------:|:-------------:|:---------:|:-----------:|:--------------:|
| 인원 제한 | 없음 | 10명 | 10명 | 없음 | 없음 |
| 칸반 보드 | 10개 | O | O | O | **무제한** |
| Task 제한 | 없음 | 없음 | 없음 | 없음 | **10개/보드** |
| 간트차트 | X | X | 기본 | 제한적 | X |
| 체크리스트 | O (카드 내부) | O | O | O | **O** |
| 팀 협업 | O | O (10명) | O (10명) | O | **O (무제한)** |

BRIDGE Standard는 Task가 10개로 제한되지만, 칸반 보드와 멤버 초대는 무제한입니다. 소규모 작업이나 시험 용도로 충분해요.

그리고 보드를 새로 만들면 **7일간 Premium 전체 기능을 무료 체험**할 수 있습니다. 다른 도구들은 유료 플랜 체험 자체가 없거나 제한적이에요.
