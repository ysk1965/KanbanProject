## 프로젝트 관리, 왜 이렇게 복잡할까?

팀 프로젝트를 하다 보면 이런 경험, 한 번쯤은 있지 않으셨나요?

- "이 태스크 누가 하고 있는 거지?"
- "이번 주까지 뭘 끝내야 하는 거였더라..."
- "슬랙에서 멘션 왔는데 어디서 온 건지 모르겠다"
- "엑셀로 일정 관리하다가 버전이 꼬였다"

저도 팀 프로젝트를 진행하면서 같은 고민을 반복했습니다. Notion은 자유도가 높지만 프로젝트 관리에 특화되지 않았고, Jira는 너무 무겁고, Trello는 기본 기능이 부족해서 Power-Up을 붙여야 하고... 게다가 다 **인당 과금**이라 팀원 늘어날수록 비용이 확 올라가더라고요. 딱 맞는 도구를 찾기 어려웠어요.

그러다 최근에 **BRIDGE**라는 서비스를 써봤는데, 솔직히 이게 딱이었습니다. 칸반 보드 기반인데, 기존 도구들의 아쉬운 점을 잘 채워주더라고요.

오늘은 직접 사용해보면서 느꼈던 점들을 공유해볼게요.

## BRIDGE는 어떤 서비스인가요?

BRIDGE는 **칸반(Kanban) 보드를 중심으로 팀의 업무 흐름을 한눈에 파악하고 관리할 수 있는 웹 서비스**입니다.

처음에 "또 칸반 보드?"라고 생각했는데, 써보니까 좀 달랐어요. Feature(기능 단위) → Task(작업 단위) → Checklist(세부 항목)의 **3단계 계층 구조**로, 큰 그림부터 세부 실행까지 하나의 플랫폼에서 관리할 수 있습니다.

이게 진짜 편합니다. Trello처럼 단순히 카드를 옮기는 게 아니라, 기능 단위로 묶어서 진행률까지 자동으로 나오거든요.

## 핵심 기능 소개

### 1. 칸반 보드 - 한눈에 보는 업무 현황

BRIDGE의 메인 화면은 칸반 보드입니다. 블록(컬럼)을 자유롭게 추가하고, 카드를 드래그 앤 드롭으로 이동시킬 수 있어요.

- **Feature 블록**: 프로젝트의 큰 기능 단위를 관리
- **Task 블록**: 세부 작업을 담당자별로 추적
- **커스텀 블록**: "진행중", "리뷰중" 등 팀에 맞는 워크플로우 구성
- **Done 블록**: 완료된 작업을 자동 집계

특히 마음에 들었던 건, 카드를 Done 블록으로 옮기면 **Feature의 진행률이 자동으로 업데이트**된다는 점이에요. 일일이 퍼센트를 계산할 필요가 없습니다.

> 📸 **[스크린샷 2]** 칸반 보드 메인 화면
> - 촬영: `/boards/:boardId` 칸반 뷰에서 Feature, Task, 커스텀 블록, Done 블록이 모두 보이는 전체 화면
> - 포인트: 카드에 담당자 아바타, 태그, 진행률 바가 보이도록 데이터가 있는 상태

> 📸 **[스크린샷 3]** Feature 상세 모달
> - 촬영: Feature 카드 클릭 → 상세 모달에서 진행률 바, Task 목록, 담당자, 태그가 보이는 상태
> - 포인트: 3단계 계층 (Feature → Task 목록)이 한눈에 드러나도록

### 2. 데일리 스케줄 - 오늘 할 일을 시간 단위로

"오늘 뭐부터 해야 하지?" 하는 순간, 데일리 스케줄 뷰를 열어보세요.

- **타임블록**: 30분 단위로 멤버별 일정을 배치
- **체크리스트 뷰**: 오늘 처리해야 할 항목을 한 화면에서 확인
- **주간 뷰**: 이번 주 전체 일정을 한눈에 조감

타임블록을 드래그해서 시간을 조정하거나, 클릭하면 연결된 Task와 체크리스트까지 바로 확인할 수 있습니다. 이거 써보니까 매일 아침 "오늘 뭐하지" 고민이 사라지더라고요.

> 📸 **[스크린샷 4]** 데일리 스케줄 뷰 (타임블록)
> - 촬영: 데일리 탭 → 일간(day) 뷰에서 멤버 컬럼별 타임블록이 배치된 화면
> - 포인트: 2~3명의 멤버 컬럼에 색상별 타임블록이 여러 개 있는 상태, 우측에 상세 패널이 열린 모습이면 더 좋음

> 📸 **[스크린샷 5]** 주간 뷰
> - 촬영: 데일리 탭 → 주간(week) 뷰에서 7일간의 멤버별 블록 요약이 보이는 화면
> - 포인트: 멤버별 색상 카드와 요일별 블록 카운트가 한눈에 보이도록

### 3. 간트차트 - 일정 기반 프로젝트 추적

Feature와 Task에 시작일/마감일을 설정하면 **간트차트 형태로 전체 일정**을 볼 수 있습니다.

- 마일스톤별 필터링
- 바(Bar)를 직접 드래그해서 일정 조정
- Feature 단위로 접기/펼치기

스프레드시트로 간트차트를 만들 때의 그 번거로움, 이제 안녕입니다.

> 📸 **[스크린샷 6]** 간트차트 뷰
> - 촬영: 간트차트 탭에서 Feature별 Task 바가 날짜 그리드 위에 표시된 전체 화면
> - 포인트: Feature 접기/펼치기, 날짜 범위, 마일스톤 필터가 보이도록

### 4. 마일스톤 - 목표 기반 관리

"이번 스프린트에서 무엇을 완성해야 하는가?"를 명확하게 정의합니다.

- 마일스톤에 Feature를 연결
- 멤버별 작업 시간 할당
- 진행률 자동 계산
- 번다운 차트로 속도 추적

처음 마일스톤을 사용하시는 분을 위한 **온보딩 가이드**도 준비되어 있어서, 어렵지 않게 시작할 수 있었어요.

> 📸 **[스크린샷 7]** 마일스톤 뷰
> - 촬영: 마일스톤 탭에서 마일스톤 카드 (진행률 바 + 연결된 Feature 목록)가 보이는 화면
> - 포인트: 진행률 퍼센트, Feature 색상 Dot, 날짜 범위가 보이도록

### 5. 실시간 댓글 & @멘션

Task 카드 안에서 바로 댓글을 남길 수 있습니다.

- **@멘션**으로 팀원 태그
- 멘션되면 **인앱 알림 + Slack 알림** 동시 발송
- 이미지 첨부 지원 (최대 5개)
- 댓글 수정/삭제

"이 부분 확인해주세요"라고 슬랙에 따로 메시지 보낼 필요 없이, **작업 맥락 안에서 바로 소통**할 수 있습니다. 이게 은근히 큰 차이더라고요. 슬랙에서 링크 찾아 헤매는 시간이 줄었어요.

> 📸 **[스크린샷 8]** Task 상세 모달 - 댓글 패널
> - 촬영: Task 카드 클릭 → 상세 모달에서 우측 댓글 패널이 열린 상태. @멘션이 하이라이트된 댓글이 1~2개 보이면 좋음
> - 포인트: 댓글 목록, @멘션 하이라이트(보라색), 이미지 첨부, 입력창이 보이도록

### 6. Slack 연동 & 알림 설정

이미 Slack을 쓰고 계신다면 더 편합니다.

- 보드별로 개인 Slack Webhook을 설정
- @멘션, 체크리스트 배정, 태스크 댓글 알림을 Slack으로 수신
- **알림 타입별 On/Off** 설정 가능 (인앱/Slack 각각)

알림이 너무 많으면 오히려 중요한 걸 놓치게 되는데, BRIDGE는 **3가지 알림 타입별로 인앱/Slack 채널을 독립적으로 제어**할 수 있습니다.

| 알림 타입 | 설명 | 인앱 | Slack |
|-----------|------|:----:|:-----:|
| 댓글 멘션 | @멘션으로 태그되었을 때 | On/Off | On/Off |
| 체크리스트 배정 | 체크리스트 항목에 배정되었을 때 | On/Off | On/Off |
| 태스크 댓글 | 관련 태스크에 새 댓글이 달렸을 때 | On/Off | On/Off |

"중요한 멘션만 Slack으로 받고, 나머지는 인앱으로" 같은 세밀한 설정이 가능해서 좋았어요. 보드마다 다르게 설정할 수도 있습니다.

> 📸 **[스크린샷 9]** 알림 드롭다운 + Slack 설정 + 알림 설정 패널
> - 촬영: 우측 상단 벨 아이콘 클릭 → 알림 드롭다운이 열린 상태. Slack 설정 패널과 알림 설정(인앱/Slack 토글) 패널이 함께 보이면 이상적
> - 포인트: 읽지 않은 알림 뱃지, Slack 연결 상태, 타입별 토글 스위치가 보이도록

### 7. 팀 관리 & 권한 체계

보드에 팀원을 초대하고 역할을 부여할 수 있습니다.

- **Owner**: 보드 소유자 (삭제, 결제 관리)
- **Admin**: 멤버/블록/설정 관리
- **Member**: Feature/Task 생성 및 수정
- **Viewer**: 읽기 전용 (외부 이해관계자에게 딱!)

초대 링크를 생성해서 공유하면, 회원가입 후 바로 보드에 참여할 수 있습니다. 멤버마다 **고유 색상**이 지정되어 칸반 보드에서 누가 어떤 작업을 맡고 있는지 한눈에 구분됩니다.

> 📸 **[스크린샷 10]** 멤버 초대 / 공유 모달
> - 촬영: 공유 버튼 클릭 → ShareBoardModal에서 멤버 목록 (역할 뱃지 + 담당자 색상), 초대 링크 섹션이 보이는 상태
> - 포인트: Owner/Admin/Member 등 역할 뱃지와 멤버별 고유 색상 dot이 보이도록

## 다크 모드 & 세련된 디자인

개인적으로 BRIDGE 쓰면서 제일 만족했던 부분 중 하나가 디자인이에요.

기본적으로 **다크 모드**인데, 개발자 친화적인 어두운 배경에 인디고 액센트 컬러를 사용해서 오래 봐도 눈이 편합니다. **라이트 모드**도 지원하고요.

Glass Morphism 효과와 부드러운 애니메이션이 적용되어 있어서, 단순히 기능만 있는 도구가 아니라 쓰는 재미가 있습니다.

> 📸 **[스크린샷 11]** 다크 모드 vs 라이트 모드 비교
> - 촬영: 같은 칸반 보드 화면을 다크 모드 / 라이트 모드 각각 캡처 → 나란히 배치
> - 포인트: 동일한 보드 상태에서 두 모드의 분위기 차이가 드러나도록

## 요금제 - 솔직히 이게 제일 마음에 들었습니다

프로젝트 관리 도구의 가장 큰 고민이 **가격**이잖아요. 기존 도구들의 요금제를 보면:

| 서비스 | 기본 요금 (인당/월) | Power-Up / 추가 기능 | 실질 비용 |
|--------|:-------------------:|:--------------------:|:---------:|
| **Trello** | $5~$10 | Power-Up별 추가 과금 | 💸💸 |
| **Asana** | $10.99~$24.99 | 고급 기능은 Business 이상 | 💸💸💸 |
| **Jira** | $7.16~$12.48 | Marketplace 앱 별도 과금 | 💸💸💸 |
| **Notion** | $8~$15 | AI 기능 추가 $8/인 | 💸💸 |

**인당 월 $10이면**, 10명 팀 기준 **매달 10만원 이상**입니다. 여기에 간트차트 Power-Up, 타임라인 뷰, 고급 자동화 같은 "있으면 좋은 기능"을 붙이면 비용이 또 올라갑니다. 결국 제대로 쓰려면 **인당 $15~25**는 각오해야 하는 구조예요.

BRIDGE는 이 부분이 확실히 다릅니다:

| | Trial | Standard | Premium |
|--|-------|----------|---------|
| 기간 | 7일 무료 | - | - |
| 칸반 보드 | O | O | O |
| Feature/Task | O | Task 10개 제한 | 무제한 |
| 데일리 스케줄 | X | X | O |
| 간트차트 | X | X | O |
| 마일스톤 | X | X | O |
| Slack 연동 | O | O | O |
| **추가 과금** | - | **없음** | **없음** |

**핵심은 "추가 과금이 없다"는 겁니다.** 다른 도구들처럼 기본 기능에 Power-Up을 붙여야 제대로 쓸 수 있는 구조가 아니라, **해당 플랜의 모든 기능이 포함**되어 있습니다. 간트차트? Premium에 포함. Slack 연동? 기본 포함. 마일스톤? Premium에 포함. 추가 결제 없이요.

특히 학생 팀이나 사이드 프로젝트 팀처럼 예산이 빠듯한 경우, 인당 비용이 기하급수적으로 불어나는 기존 도구들 대비 **압도적인 가성비**입니다.

Trial로 7일간 모든 Premium 기능을 체험해보실 수 있으니, 가격표 보면서 고민하기 전에 **일단 써보시는 걸 추천**합니다.

## 마치며

솔직히 프로젝트 관리 도구를 이것저것 써봤는데, BRIDGE는 **"딱 필요한 만큼"**이라는 느낌이에요.

화려한 기능이 잔뜩 있는 게 아니라, 매일 쓰는 칸반 보드가 정말 잘 동작합니다. 카드를 드래그하는 그 한 번의 동작으로 진행률이 업데이트되고, 멘션 하나로 팀원에게 알림이 가고, 오늘 할 일을 타임블록으로 정리하는 - 이런 작은 경험들이 모여서 팀의 생산성을 만들어주는 느낌이었어요.
