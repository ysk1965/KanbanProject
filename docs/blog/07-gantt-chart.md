## 간트차트의 비극

프로젝트 일정을 관리하려면 간트차트가 필요합니다.

그래서 많은 팀이 Google Sheets나 Excel로 간트차트를 만듭니다. 날짜를 열에 넣고, 작업을 행에 넣고, 셀에 색칠하고, 조건부 서식을 걸고...

처음엔 그럴듯합니다. 그런데 2주 정도 지나면 이런 일이 벌어집니다:

- **행을 추가하면** 조건부 서식이 깨짐
- **날짜를 수정하면** 다른 행의 색칠이 어긋남
- **시트를 복사해서** 버전이 2개가 됨
- **"이 차트 최신 맞아?"** 라는 질문이 매주 나옴

결국 간트차트 **유지보수에 쓰는 시간이, 실제 프로젝트에 쓰는 시간보다 많아지는** 아이러니가 발생합니다.

BRIDGE에서는 **카드를 만들면 간트차트가 알아서 그려집니다.** 수식도 없고, 색칠도 필요 없습니다.

[이미지: BRIDGE 간트차트 뷰 — Feature별 Task 바가 날짜 그리드 위에 표시된 화면]

## BRIDGE 간트차트, 이런 겁니다

### 자동 생성

Task에 **시작일과 마감일**을 설정하면, 간트차트에 바(Bar)가 자동으로 생성됩니다.

별도로 간트차트를 "만드는" 과정이 없습니다. 칸반 보드에서 Task를 만들 때 날짜를 설정하면, 간트차트 뷰로 전환했을 때 이미 거기에 바가 있습니다.

### Feature 단위 구조

간트차트의 왼쪽 패널에는 **Feature → Task 트리**가 표시됩니다.

```
▼ 사용자 인증 (진행률 67%)
    ├── 로그인 API          [===▓▓▓▓▓===]
    ├── 회원가입 폼         [=======▓▓▓]
    └── 비밀번호 찾기        [====▓▓▓▓▓▓▓▓]

▼ 결제 시스템 (진행률 25%)
    ├── PG 연동             [▓▓▓▓▓▓▓===]
    └── 결제 내역 조회       [===▓▓▓▓▓▓▓▓]
```

Feature를 접으면 하위 Task가 숨겨지고, Feature 레벨의 전체 기간만 보입니다. "큰 그림"과 "세부 일정"을 오가면서 볼 수 있습니다.

[이미지: 간트차트 왼쪽 패널 — Feature별 접기/펼치기가 있는 트리 구조]

## 색상 코드 — 보는 즉시 상태를 파악

간트차트의 바는 **상태에 따라 색상이 자동으로 바뀝니다.**

| 색상 | 의미 | 언제 적용되나 |
|------|------|-------------|
| 회색 | 시작 전 | 시작일이 아직 안 됨 |
| 틸(#2DD4BF) | 진행 중 | 시작일 지남, 마감까지 3일 이상 |
| 주황 | 마감 임박 | 마감까지 1~3일 남음 |
| 빨강 | 마감 초과 | 마감일이 지남 |
| 초록 | 완료 | Done 블록으로 이동됨 |

이 색상은 **설정할 필요 없이 자동**입니다. 칸반에서 카드를 Done으로 옮기면 간트차트의 바가 초록으로 바뀌고, 마감일이 지난 카드는 자동으로 빨갛게 표시됩니다.

차트를 열었을 때 **빨간 바가 많으면 프로젝트가 지연 중**이고, **초록 바가 늘어나면 순조로운 것**입니다. 숫자를 읽지 않아도 색상만으로 현황을 파악할 수 있습니다.

## 드래그로 일정 조정

간트차트에서 가장 많이 하는 작업은 **일정 변경**입니다.

BRIDGE에서는 세 가지 방법으로 바를 조정할 수 있습니다:

### 1. 바 전체 이동

바를 **길게 누른 후 좌우로 드래그**하면 시작일과 마감일이 함께 이동합니다.

```
Before:  [====바====]
                          →→→
After:            [====바====]
```

기간은 유지하면서 전체 일정만 밀거나 당길 때 사용합니다.

### 2. 시작일 변경

바의 **왼쪽 가장자리**에 마우스를 올리면 리사이즈 커서가 나타납니다. 왼쪽으로 드래그하면 시작일이 앞당겨지고, 오른쪽으로 드래그하면 늦춰집니다.

### 3. 마감일 변경

바의 **오른쪽 가장자리**를 드래그합니다. 마감을 늘리거나 줄일 수 있습니다.

모든 변경은 **실시간으로 반영**됩니다. 드래그하는 동안 날짜가 바뀌는 게 바로 보이고, 놓으면 칸반의 Task 정보도 함께 업데이트됩니다.

[이미지: 바 드래그 인터랙션 — 마우스로 가장자리를 잡아 리사이즈하는 장면]

## 일 단위 vs 주 단위

간트차트는 **두 가지 단위**로 볼 수 있습니다.

### 일 단위 (Day View)

- 열 하나 = 하루
- 바 드래그/리사이즈 **가능**
- 세밀한 일정 조정에 적합
- 1~2주 단위 프로젝트에 추천

### 주 단위 (Week View)

- 열 하나 = 일주일
- 바 드래그/리사이즈 **불가** (읽기 전용)
- 전체 일정 조감에 적합
- 1~3개월 단위 프로젝트에 추천

보통은 **주 단위로 전체 그림을 파악하고, 일 단위로 들어가서 세부 조정**하는 패턴으로 사용합니다.

## 오늘 표시선 — 현재 위치를 항상 확인

간트차트에는 **빨간 세로선**이 오늘 날짜에 그어집니다.

이 선이 중요한 이유:

- **선 왼쪽의 빨간 바** = 이미 지연된 작업 (즉시 대응 필요)
- **선 근처의 주황 바** = 곧 마감인 작업 (이번 주에 집중)
- **선 오른쪽의 틸 바** = 아직 여유 있는 작업

오늘 표시선을 기준으로 "왼쪽이 비어 있으면 좋은 것, 빨간 게 남아 있으면 나쁜 것" — 이렇게 직관적으로 판단할 수 있습니다.

## 마일스톤 필터 — 스프린트별로 보기

프로젝트가 크면 모든 Task를 한 번에 보는 건 오히려 불편합니다.

BRIDGE의 간트차트에는 **마일스톤 필터**가 있습니다. 마일스톤(예: Sprint 1, Sprint 2, v1.0 릴리즈)을 선택하면, 해당 마일스톤에 연결된 Feature와 Task만 간트차트에 표시됩니다.

"지금 Sprint 2에 집중하고 있으니, Sprint 2에 해당하는 일정만 보자" — 이런 사용이 가능합니다.

마일스톤 기능은 #9에서 자세히 다룹니다.

## 체크리스트 진행 게이지

간트차트의 각 Task 바에는 **미니 원형 게이지**가 표시됩니다.

이 게이지는 해당 Task의 **체크리스트 완료율**을 나타냅니다. 체크리스트 항목이 4개 중 2개 완료되면 게이지가 반원으로 차오릅니다.

바의 색상(상태)과 게이지(진행률)를 함께 보면:

- **틸 바 + 게이지 80%** = 거의 완료, 순조로움
- **주황 바 + 게이지 20%** = 마감 임박인데 진행이 느림, 위험
- **빨간 바 + 게이지 50%** = 마감 지났는데 아직 절반, 긴급 대응 필요

숫자를 읽지 않아도, 색상과 게이지의 조합으로 **위험 신호를 즉시 감지**할 수 있습니다.

## 스프레드시트 vs BRIDGE 간트차트

| | 스프레드시트 간트차트 | BRIDGE 간트차트 |
|--|------------------|---------------|
| **생성** | 수동 (셀 색칠, 조건부 서식) | 자동 (시작일/마감일만 입력) |
| **일정 변경** | 셀 값 수정 + 색칠 재조정 | 바 드래그 |
| **상태 표시** | 수동 색칠 | 자동 색상 코드 (5가지) |
| **진행률** | 별도 열에 수동 입력 | 체크리스트 기반 자동 계산 |
| **Feature 그룹** | 수동 정렬 | Feature → Task 트리 자동 |
| **오늘 표시** | 수동 선 그리기 | 자동 빨간선 |
| **칸반 연동** | 없음 (별도 문서) | 실시간 양방향 연동 |
| **버전 관리** | 파일 복사 → 혼란 | 항상 최신 (단일 소스) |

가장 큰 차이는 **"유지보수 비용"**입니다.

스프레드시트 간트차트는 만들 때도 시간이 걸리지만, **업데이트할 때마다** 시간이 듭니다. 행을 추가하고, 날짜를 바꾸고, 색을 다시 칠하고. BRIDGE에서는 카드를 드래그하면 끝입니다.

## 실전 팁 3가지

### 1. 시작일과 마감일을 꼭 설정하세요

간트차트에 바가 그려지려면 날짜가 필요합니다. Task를 만들 때 "대충 이 정도?"라도 날짜를 넣어두세요. 나중에 드래그로 조정하면 됩니다. 날짜가 없는 Task는 간트차트에 안 나타납니다.

### 2. 주 단위로 먼저 보세요

프로젝트 전체를 파악할 때는 주 단위로 봅니다. "어느 Feature가 이번 달에 끝나야 하는지"를 먼저 확인한 후, 일 단위로 전환해서 세부 일정을 조정하세요.

### 3. 빨간 바를 0으로 만드세요

간트차트를 열었을 때 **빨간 바 = 마감 초과**입니다. 이 바를 0개로 만드는 게 PM의 미션입니다. 마감을 연장하든, 자원을 재배분하든, 범위를 줄이든 — 빨간 바가 있으면 반드시 액션을 취하세요.

## 마치며

간트차트는 프로젝트 관리의 핵심 도구입니다. 하지만 스프레드시트로 만들면 **도구가 짐이 됩니다.**

BRIDGE의 간트차트는 칸반 보드와 연동되어 **Task를 만들면 바가 그려지고, 카드를 옮기면 색이 바뀌고, 드래그로 일정을 조정**합니다. 간트차트를 "만드는" 시간이 0이기 때문에, 간트차트를 "읽고 판단하는" 것에만 집중할 수 있습니다.
