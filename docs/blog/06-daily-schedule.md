## 칸반 보드의 한계

칸반 보드는 **전체 현황**을 보기엔 좋습니다. 어떤 작업이 어디까지 왔는지 한눈에 파악할 수 있으니까요.

그런데 아침에 노트북을 열었을 때 드는 생각은 이겁니다:

> "오늘 나는 뭘 해야 하지?"

칸반 보드에는 "오늘"이라는 개념이 없습니다. In Progress에 카드가 5개 있으면, 그걸 다 오늘 해야 하는 건지, 이번 주 안에 하면 되는 건지 알 수 없어요. 그래서 보통은 따로 메모장을 열거나, 투두 앱에 오늘 할 일을 다시 적습니다.

**BRIDGE의 데일리 스케줄**은 이 문제를 해결합니다. 칸반에서 만든 작업을 **오늘의 시간표로 바꿔줍니다.**

## 데일리 스케줄, 이런 겁니다

데일리 스케줄은 **두 가지 뷰**로 구성됩니다.

### 뷰 1. 타임블록 — 시간표처럼 배치

멤버별 컬럼에 **30분 단위의 타임블록**을 배치합니다.

```
         민수          지영          현우
09:00  [API 설계]    [디자인 검토]
09:30  [API 설계]    [디자인 검토]  [코드 리뷰]
10:00               [프로토타입]    [코드 리뷰]
10:30  [테스트]      [프로토타입]    [문서 작성]
11:00  [테스트]                    [문서 작성]
```

이게 타임블록의 핵심입니다. **누가, 언제, 무슨 작업을 하는지** 한 화면에서 보입니다.

**타임블록 만드는 법:**

1. 빈 시간 셀을 **위에서 아래로 드래그**
2. 체크리스트 항목 선택 모달이 뜸
3. 연결할 항목을 고르면 블록이 생성

이미 만든 블록은 **드래그로 시간을 옮기거나, 가장자리를 잡아 늘리거나 줄일 수 있습니다.** 회의가 갑자기 잡혀서 일정이 밀렸다? 블록을 아래로 끌면 끝입니다.

[이미지: 타임블록 드래그 — 블록 가장자리를 잡아 리사이즈하는 장면]

### 뷰 2. 데일리 체크리스트 — 오늘의 할 일 목록

타임블록이 "언제 할 건지"라면, 데일리 체크리스트는 **"오늘 뭘 할 건지"**입니다.

멤버별로 컬럼이 나뉘고, 각 멤버의 오늘 할 일이 체크리스트 형태로 표시됩니다.

```
민수                  지영                  현우
☑ API 엔드포인트 설계  ☑ 메인 화면 디자인     ☐ PR #42 리뷰
☐ 에러 핸들링 추가     ☐ 아이콘 세트 제작     ☐ 배포 스크립트 수정
☐ 테스트 코드 작성     ☐ 컴포넌트 가이드      ☑ 문서 업데이트
```

체크박스를 클릭하면 **즉시 완료 처리**되고, 상위 Task의 진행률에도 반영됩니다. 아침 스탠드업 미팅에서 이 화면만 공유하면 "어제 뭐 했고, 오늘 뭐 할 건지"가 바로 보입니다.

## 타임블록 vs 블록 모드 — 두 가지 시간 관리

BRIDGE는 팀마다 다른 시간 관리 방식을 지원합니다.

### 시간 모드 (Time-based)

출근 시간과 퇴근 시간을 설정하고, 실제 시계 시간에 맞춰 블록을 배치합니다.

- **설정 예시**: 09:00 ~ 18:00
- **표시**: HH:mm 형식 (09:00, 09:30, 10:00...)
- **적합한 팀**: 고정 근무시간이 있는 팀, 회의 시간과 맞춰야 하는 팀

### 블록 모드 (Block-based)

시계 시간 대신 **순서대로 번호가 매겨진 블록**을 사용합니다.

- **설정 예시**: 16블록 (= 8시간)
- **표시**: Block 1, Block 2, Block 3...
- **적합한 팀**: 유연 근무, 리모트 팀, 출근 시간이 다른 팀

블록 모드가 필요한 이유는 간단합니다. "나는 10시에 출근하고, 동료는 8시에 출근하는" 팀에서 시간 기반 스케줄은 맞지 않거든요. 블록 모드면 각자 "첫 번째 블록부터" 시작하면 됩니다.

**설정 방법**: 스케줄 뷰 상단의 설정 아이콘 → 시간/블록 모드 선택 → 범위 설정 → 저장

[이미지: 스케줄 설정 모달 — 시간 모드와 블록 모드 선택 화면]

## 주간 뷰 — 이번 주 전체를 한눈에

데일리 뷰가 "오늘"에 집중한다면, **주간 뷰는 이번 주 전체**를 보여줍니다.

### 간트차트 스타일 타임라인

왼쪽에 Feature/Task 트리가 있고, 오른쪽에 요일별 타임라인이 펼쳐집니다. Task에 시작일/마감일이 있으면 **색상 코드 바**로 표시됩니다.

| 색상 | 의미 |
|------|------|
| 회색 | 시작 전 |
| 틸(#2DD4BF) | 진행 중 |
| 주황 | 마감 1~3일 전 |
| 빨강 | 마감 초과 |
| 초록 | 완료 |

빨간 바가 보이면 즉시 대응할 수 있고, 초록 바가 늘어나면 진행이 순조롭다는 뜻입니다. **오늘 날짜에는 빨간 세로선**이 그어져서, 현재 시점과 일정의 관계를 직관적으로 파악할 수 있습니다.

### 바 드래그로 일정 조정

일 단위 뷰에서는 Task 바를 **직접 드래그해서 일정을 조정**할 수 있습니다.

- **바 전체 이동**: 길게 누른 후 좌우로 드래그
- **시작일 조정**: 왼쪽 가장자리를 드래그
- **마감일 조정**: 오른쪽 가장자리를 드래그

마우스로 바를 잡으면 시작일과 마감일이 실시간으로 바뀝니다. 엑셀에서 날짜를 일일이 수정하는 것보다 훨씬 빠릅니다.

## 데일리 체크리스트 — 이렇게 활용하세요

### 아침 스탠드업

팀 미팅에서 데일리 체크리스트 화면을 공유합니다. 멤버별 컬럼을 훑으면서:

- "어제 완료한 것" → 체크된 항목
- "오늘 할 것" → 체크 안 된 항목
- "블로커" → 빈 컬럼 (할 일이 없으면 업무 배분 필요)

여기에 **AI 스탠드업 요약** 기능을 활용하면 더 좋습니다. AI가 하루의 보드 활동 데이터를 분석해서 "어제 주요 성과", "주요 논의 사항", "주의 필요 항목"을 자동으로 정리해줍니다. 스탠드업 미팅에서 이 요약을 먼저 공유하고, 필요한 부분만 디테일하게 논의하면 **미팅 시간이 확 줄어듭니다.**

### 주간 요약

주간 요약 기능으로 멤버별 **한 주간의 성과**를 확인할 수 있습니다.

- **총 타임블록 수**: 이번 주에 배치한 블록
- **총 작업 시간**: 시간 환산
- **완료율**: 체크리스트 항목 완료 비율
- **일별 현황**: 요일별 작업 시간 바 차트
- **Feature별 시간 분배**: 어떤 기능에 시간을 많이 썼는지

"이번 주에 프론트엔드 작업에 12시간, 백엔드에 8시간을 썼다" — 이런 정보가 자동으로 집계됩니다.

## 다른 도구와의 차이

| | Trello | Notion | BRIDGE |
|--|--------|--------|--------|
| **데일리 뷰** | 없음 | 데이터베이스 뷰로 직접 구성 | 전용 타임블록 + 체크리스트 |
| **시간 배치** | 없음 | 캘린더 뷰 (제한적) | 30분 단위 드래그 배치 |
| **멤버별 뷰** | 없음 | 필터로 구현 | 네이티브 컬럼 |
| **주간 요약** | 없음 | 없음 | 자동 집계 (시간/완료율/Feature별) |
| **AI 스탠드업 요약** | 없음 | 없음 | 하루 활동 AI 자동 분석 |
| **칸반 연동** | 해당 없음 | 수동 | Task/Checklist 자동 연결 |

핵심 차이는 **칸반과의 연동**과 **AI 자동화**입니다. BRIDGE에서는 칸반의 Task 체크리스트를 데일리 스케줄로 가져오고, 데일리에서 체크하면 칸반의 진행률이 올라갑니다. 거기에 AI가 하루/주간 활동을 자동으로 분석해주니까, **별도 투두 앱도, 리포트 작성도 필요 없습니다.**

## 실전 팁 3가지

### 1. 아침 5분 루틴

출근하면 데일리 스케줄을 열고, 오늘 할 체크리스트 항목을 타임블록에 배치합니다. 5분이면 하루 계획이 끝납니다. 하루가 끝나면 체크 상태를 확인하고, 내일로 넘길 항목이 있으면 메모해둡니다.

### 2. 타임블록은 "집중 시간"에 쓰세요

모든 시간을 빈틈없이 채우지 마세요. 핵심 업무 3~4개만 타임블록에 배치하고, 나머지는 체크리스트로 관리하는 게 효과적입니다. 블록이 너무 많으면 오히려 압박감만 커집니다.

### 3. 주간 요약으로 회고하세요

매주 금요일, 주간 요약을 열어보세요. "이번 주에 어떤 Feature에 시간을 가장 많이 썼는지"를 보면, 다음 주의 시간 배분을 더 잘할 수 있습니다.

## 마치며

프로젝트 관리에서 가장 어려운 건 "큰 계획을 오늘의 행동으로 바꾸는 것"입니다.

BRIDGE의 데일리 스케줄은 칸반 보드의 Task를 **오늘 30분 단위의 타임블록**으로 바꿔줍니다. 그리고 체크리스트로 오늘 할 일을 정리하고, 완료하면 자동으로 칸반에 반영됩니다.

거창한 계획 도구가 아닙니다. **"오늘 뭐하지?"에 대한 답을 5분 만에 만드는 도구**입니다.
