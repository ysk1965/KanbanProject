2. 상태 파생 규칙 기존 로직 재사용

체크리스트 항목에는 상태 필드가 따로 없습니다. completed, start_date, due_date 조합으로 파생합니다. 이미 MiniKanbanView.tsx의 resolveColumn()에 동일 로직이 있어 그대로 재사용합니다.

상태조건UI
DONEcompleted === true완료(취소선), 완료일 표시
DOING미완료 & start_date != null && start_date ≤ 오늘기간 표시, 마감 지나면 빨강
TODO그 외 (미완료 & 시작 전/시작일 없음)예정일 또는 "미정"
드래그 이동 시 mutation (MiniKanbanView moveItemToColumn 재사용):
• → DONE: 미완료면 onToggleChecklist 호출
• → DOING: 완료면 완료 해제, patch({ start_date: 오늘 })
• → TODO: 완료면 완료 해제, patch({ start_date: null })

3. 구현 계획 FE only · 백엔드 변경 없음

1
모드 상태 추가 — TaskDetailModal.tsx
const [checklistViewMode, setChecklistViewMode] = useState<'list'|'board'>('list')
localStorage checklistViewMode_{taskId} 로 영속화 (선택). 모든 hook은 early-return 위에 선언 — React #310 주의.
2
토글 UI — 진행률 바 좌측 header-right에 삽입 (목업 위치)
KanbanBlock의 탭 버튼 그룹 패턴 재사용: bg-foreground/5 pill 컨테이너 + active bg-foreground/10. 아이콘 Lucide List / LayoutGrid. 44px 터치타겟 · aria-label.
3
상태 파생 유틸 추출 — utils/checklistStatus.ts (신규)
MiniKanbanView의 resolveColumn(item, today) / isOverdue() 를 공용 유틸로 이동 → MiniKanbanView도 이 유틸을 import 하도록 리팩토링(중복 제거).
4
보드 뷰 컴포넌트 — ChecklistStatusBoard.tsx (신규, TaskDetailModal 하위)
visibleChecklistItems를 3컬럼으로 useMemo 그룹핑. 각 카드는 기존 ChecklistItemRow의 표시 정보(제목/기간/담당자/예상시간/체크박스)를 컴팩트하게 렌더. 편집·삭제·담당자 변경은 카드 클릭 시 기존 로직 재사용.
5
드래그 앤 드롭 — @dnd-kit (이미 설치됨)
컬럼별 useDroppable, 카드 useDraggable. onDragEnd에서 target 컬럼 판정 → moveItemToColumn 로직으로 handleToggleChecklistItem / handleUpdateChecklistItem({start_date}) 호출. 실시간 동기화는 기존 핸들러가 이미 WebSocket 반영.
6
조건부 렌더링 — 섹션 body에서 checklistViewMode === 'board' ? <ChecklistStatusBoard/> : <기존 리스트>
빈 상태 / AI 추가 / 필터(isChecklistFilterActive) / 진행률(77%)은 두 모드 공통 유지. AddChecklistItemInput은 board 모드에서 TODO 컬럼 하단 또는 섹션 하단에 배치.
7
i18n — task.checklistView.list / .board, 컬럼 라벨 todo/doing/done (10개 언어)
빌드 검증: cd frontend && npm run build

4. 결정 필요 / 고려사항

  • 기본 모드: list 유지 권장 (기존 사용성 보존), 사용자별 마지막 선택 기억.
  • 보드 모드 정렬 기준: DONE 컬럼은 최근 완료순(completed_at desc), DOING은 마감 임박순, TODO는 position 순 제안.
  • Viewer(읽기전용): 드래그 비활성, 보기만 허용 (canEdit 가드 재사용).
  • 4분류 vs 3분류: KanbanBlock은 오늘완료/기존완료/진행중/미시작 4분류를 씀. 여기서는 요청대로 3컬럼(DONE 통합) 채택 — 카드에 "오늘 완료" 뱃지만 부가.
  • DnD 라이브러리 주의: 리스트 모드는 @dnd-kit 세로 정렬, MiniKanban은 커스텀 마우스 이벤트. 보드 모드는 @dnd-kit의 DndContext 재사용이 일관적.
모든 작업은 프론트엔드 한정 · 백엔드/DB/마이그레이션 변경 없음 · 기존 상태 파생·mutation 로직 재사용
