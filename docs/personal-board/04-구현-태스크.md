## Phase 1: BE — Board 도메인 확장 + Personal Board 생성

> 의존성: 없음 (첫 번째로 실행)
> 예상 공수: 3h

### 목표
Board에 `board_type` 필드를 추가하고, Personal Board 자동 생성 로직을 구현한다.

### 작업 목록

#### 1-1. BoardType Enum 생성
```
신규: backend/src/main/java/com/kanban/domain/board/BoardType.java
```
- `TEAM` (기본값), `PERSONAL`

#### 1-2. Board 엔티티 수정
```
수정: backend/src/main/java/com/kanban/domain/board/entity/Board.java
```
- `boardType` 필드 추가 (`@Enumerated(EnumType.STRING)`, default `TEAM`)
- `isPersonal()`, `canInviteMembers()`, `canAccessMeeting()` 메서드 추가

#### 1-3. BoardResponse DTO 수정
```
수정: backend/src/main/java/com/kanban/domain/board/dto/BoardResponse.java
```
- Simple, Detail, Full 모든 응답에 `board_type` 필드 추가

#### 1-4. BoardRepository 확장
```
수정: backend/src/main/java/com/kanban/domain/board/repository/BoardRepository.java
```
- `existsByOwnerAndBoardType()`, `findByOwnerAndBoardType()` 추가

#### 1-5. DB 마이그레이션
```
신규: backend/src/main/resources/db/migration/V38__add_board_type.sql
```
- `ALTER TABLE boards ADD COLUMN board_type VARCHAR(20) NOT NULL DEFAULT 'TEAM'`
- Unique index: 1인 1 Personal Board

#### 1-6. BoardService에 createPersonalBoard() 추가
```
수정: backend/src/main/java/com/kanban/domain/board/service/BoardService.java
```
- 1인 1개 제한 검증

- OWNER 멤버십 + Trial 구독 생성
- `ensurePersonalBoard(User)` — lazy 생성 로직
- `GET /api/v1/boards/personal` — 엔드포인트 추가

#### 1-7. AuthService 연동
```
수정: backend/src/main/java/com/kanban/domain/auth/service/AuthService.java
```
- signup() + OAuth 신규 유저 시 `createPersonalBoard()` 호출

#### 1-8. ErrorCode 추가
```
수정: backend/src/main/java/com/kanban/global/exception/ErrorCode.java
```
- `PERSONAL_BOARD_ALREADY_EXISTS`, `PERSONAL_BOARD_NO_INVITE`, `PERSONAL_BOARD_NO_MEETING`

### 검증

## Phase 2: BE — Today API + Personal 가드

> 의존성: Phase 1
> 예상 공수: 3h

### 목표
Today 통합 조회 API를 구현하고, Personal Board에서 팀 전용 기능을 차단한다.

### 작업 목록

#### 2-1. Today API
```
신규: backend/src/main/java/com/kanban/domain/board/controller/BoardTodayController.java
신규: backend/src/main/java/com/kanban/domain/board/service/BoardTodayService.java
신규: backend/src/main/java/com/kanban/domain/board/dto/TodayResponse.java
```
- `GET /api/v1/boards/{boardId}/today`
- 응답: due_today(Task[]) + in_progress(Task[]) + personal_events(PersonalEvent[]) + daily_checklist + completion_rate
- **핵심**: PersonalEvent는 user_id로 직접 조회 (board 소속이 아니므로)

#### 2-2. 팀 전용 API 가드
```
수정 대상 Controller (각 메서드 시작에 isPersonal() 체크 추가):
- InviteController — createInviteLink() 차단
- MeetingController — createMeeting() 차단
- SlackWebhookController — createWebhook() 차단
- MemberController — inviteMember() 차단
- StandupController — createConfig() 차단
```

### 검증
- [ ] `GET /boards/{id}/today` → 오늘 Task + PersonalEvent + Checklist 통합 반환
- [ ] Personal Board에서 `POST /meetings` → 403
- [ ] Personal Board에서 `POST /invite-links` → 403
- [ ] Team Board에서는 모든 기능 정상 (기존 호환)
