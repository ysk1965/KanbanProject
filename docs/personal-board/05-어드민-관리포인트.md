# 05. Admin 관리 포인트 — Personal Board 운영 기획

> Personal Board 도입으로 Board에 `TEAM`/`PERSONAL` 구분이 생기고,
> Diary·PersonalEvent·Cross-Board 이동 등 새로운 도메인이 추가된다.
> 기존 Admin 9개 탭 중 5개 탭에 변경이 필요하며, 운영 도구 2건을 추가한다.

---

## 현황: 기존 Admin 기능 요약

| 탭 | 핵심 기능 |
|----|----------|
| **Dashboard** | 전체 유저·보드·구독 수, Tier 분포 (TRIAL/STANDARD/PREMIUM) |
| **Analytics** | 가입 추이, DAU/WAU/MAU, Trial→Paid 전환율 |
| **Users** | 유저 검색, 역할 변경, 활성화/비활성화, 보드 목록 |
| **Boards** | 보드 검색 (Tier 필터), Tier 변경, 소유권 이전, 좌석·AI크레딧 조정 |
| **Subscriptions** | 구독 목록 조회 |
| **Announcements** | 공지사항 CRUD |
| **System** | 유지보수 모드 ON/OFF |
| **Monitoring** | 시스템 상태 |
| **Inquiries** | 문의 관리·답변 |

### 1-2. 추가 메트릭

기존 4개 카드 아래에 **Personal Board 섹션** 추가:

```
── Personal Board ──────────────────────────────────

[PB 생성 N개]  [PB 채택률 N%]  [PB 활성 N개]  [일기 작성 N건]

Board Type 분포                Diary 상태
  TEAM      ████████░░  72%     이번 주 작성 ███████  120건
  PERSONAL  ████░░░░░░  28%     완료/대화중   85% / 15%
```

| 지표 | 산출 | 의미 |
|------|------|------|
| **PB 생성 수** | `boards WHERE board_type = 'PERSONAL'` | 생성된 Personal Board 총 수 |
| **PB 채택률** | PB 생성 수 / 전체 유저 수 × 100 | Lazy 생성 특성상 100% 미만 → 실제 접근 유저 비율 |
| **PB 활성** | 최근 7일 내 Task 변경 있는 PB 수 | 실사용 중인 Personal Board |
| **일기 작성** | `diary_entries` 전체 수 | Diary 도메인 사용량 |
| **Board Type 분포** | TEAM vs PERSONAL 비율 | 서비스 구성 비율 변화 추적 |

### 2-2. BoardDetailModal Personal 분기

**Personal Board일 때 숨기는 섹션:**

| 기존 섹션 | Personal Board | 이유 |
|----------|---------------|------|
| Members 목록 + 역할 변경 | 숨김 | 1인 보드, 소유자 = 유일한 멤버 |
| Transfer Ownership | 숨김 | 이전 불가 (1:1 매핑) |
| Seat Count 변경 | 숨김 | 의미 없음 |
| Invite Link 생성 | 숨김 | 초대 불가 |

**Personal Board일 때 추가하는 섹션:**

```
── Personal Board 활동 ──────────────────

Task:  12개 (To Do 5 / Doing 3 / Done 4)
Diary: 28건 (이번 달 8건, 완료율 85%)
일정:  15건 (이번 주 3건)
마지막 활동: 2시간 전
```

| 지표 | 쿼리 | 비고 |
|------|------|------|
| Task 현황 | `tasks WHERE board_id = ?` 상태별 집계 | 블록 타입으로 구분 |
| Diary 수 | `diary_entries WHERE user_id = ?` | 이번 달 + 전체 |
| Diary 완료율 | COMPLETED / 전체 × 100 | 대화 중 vs 완료 |
| 일정 수 | `personal_events WHERE user_id = ?` | 이번 주 + 전체 |
| 마지막 활동 | Board의 `updated_at` | 가장 최근 변경 시각 |

### 4-3. Personal → Team 전환율

Personal Board만 가진 유저가 Team Board에도 가입하는 비율:

```
── Personal → Team 전환 ────────────────

기간: [30일 ▼] [90일] [180일] [365일]

전환 퍼널
  PB Only 유저: 340명
  → Team 가입:  52명 (15.3%)
  → Team 생성:  12명 (3.5%)

월별 전환 추이
  20%│     ╭─╮
  15%│  ╭─╮│ │╭─╮
  10%│╭─╮ ││ ││ │
   5%│┴─┴─┴┴─┴┴─┴─
      11월 12월 1월 2월
```

| 지표 | 산출 |
|------|------|
| PB Only 유저 | 유저 중 Personal Board만 가진 수 (Team 미소속) |
| Team 가입 | PB Only → board_members에 Team Board 참여한 수 |
| Team 생성 | PB Only → Team Board를 직접 생성한 수 |
| 월별 전환율 | 해당 월 Team 가입 / 해당 월 PB Only 유저 × 100 |

```
Phase 1 (Board 확장)
    │

    │
Phase 4 (칸반 탭 출시)
    │

    │
Phase 5 (Today View)
    │

    ├── P2: Analytics Diary 참여

    │
    ├── P2: Analytics Personal→Team 전환
    │

    │

```

## 검증 체크리스트

### P0 (Phase 1 동시)
- [ ] Admin Boards 탭에서 Type 필터로 PERSONAL만 조회 가능
- [ ] Board 목록에 Type 뱃지 표시
- [ ] Personal Board Detail 열 때 Members/Transfer/Seat/Invite 숨겨짐
- [ ] Personal Board Detail에서 Task/Diary/일정 수 표시
- [ ] Team Board Detail은 기존과 동일 (하위 호환)

### P1 (Phase 4 이후)
- [ ] Dashboard에 Personal Board 메트릭 4개 표시
- [ ] Dashboard에 Board Type 분포 차트 표시
- [ ] User Detail에서 Personal Board 요약 정보 표시
- [ ] PB 미보유 유저에서 "생성" 버튼 동작
- [ ] Users 목록에서 PB 보유 여부 한눈에 파악 가능

### P2 (Phase 5 이후)
- [ ] Analytics에 PB 채택 추이 차트 표시 (7/14/30/90일)
- [ ] Analytics에 Diary 참여 지표 차트 표시
- [ ] Analytics에 Personal→Team 전환 퍼널 표시
- [ ] 기간 변경 시 차트 정상 갱신

### P3 (운영 안정화 후)
- [ ] System에서 PB 미생성 유저 수 정확히 표시
- [ ] 일괄 생성 실행 후 모든 유저에게 PB 생성 확인
- [ ] 일괄 생성 중복 실행 시 에러 없음 (이미 있으면 스킵)
