# 01. 킬러 콘텐츠 분석 — 듀얼 전략: 생산성 + 라이프스타일

> v2 업데이트: 기존 v8.0 Diary/PersonalEvent 구현을 반영하여 "라이프스타일 축"을 추가.
> Personal Board가 성공하려면 "아침엔 생산성, 저녁엔 라이프스타일" 듀얼 루프가 필요하다.

---

## 1. 듀얼 킬러 콘텐츠 모델

### 1.1 왜 두 축이 필요한가?

```
생산성만 (Todoist, Things 3):
  → 할 일 끝나면 앱 닫음 → 저녁/주말 접속 없음 → DAU 한계

라이프스타일만 (Day One, 일기앱):
  → 팀 전환 경로 없음 → 수익 모델 약함 → 성장 한계

둘 다 (BRIDGE):
  → 아침에 할 일 확인 (생산성)
  → 낮에 칸반 드래그 (생산성)
  → 저녁에 일기 대화 (라이프스타일)
  → 전일 리텐션 → 팀 전환 유도 가능
```

### 1.2 시간대별 사용 매핑

```
┌────────┬─────────────────────┬─────────────────────┐
│ 시간대  │ 생산성 축 (🎯)       │ 라이프스타일 축 (🌙)   │
├────────┼─────────────────────┼─────────────────────┤
│ 아침    │ Today View 확인      │                     │
│        │ Quick Capture       │                     │
├────────┼─────────────────────┼─────────────────────┤
│ 오전    │ 칸반 Doing 이동      │                     │
│        │ Daily Checklist     │                     │
├────────┼─────────────────────┼─────────────────────┤
│ 오후    │ 칸반 Done 이동       │ 일정 확인/추가        │
│        │ 캘린더 마감일 확인     │                     │
├────────┼─────────────────────┼─────────────────────┤
│ 저녁    │ 내일 할 일 세팅       │ AI 일기 대화          │
│        │                     │ 감정 태그 기록         │
├────────┼─────────────────────┼─────────────────────┤
│ 주말    │ 주간 캘린더 정리      │ 일기 되돌아보기        │
│        │                     │ (향후) 습관 리뷰       │
└────────┴─────────────────────┴─────────────────────┘
```

## 2. 생산성 킬러 콘텐츠 TOP 5 (신규 구현 필요)

### #1. Quick Capture — "3초 안에 적는다"

**왜 킬러인가:**
- 개인 생산성의 시작점 = 캡처
- 입력 허들이 높으면 → 메모장/포스트잇 사용 → 이탈
- Things 3, Todoist의 핵심 경쟁력

**경쟁사 벤치마크:**
| 앱 | 캡처 속도 | 방법 |
|----|----------|------|
| Todoist | 2초 | Quick Add (단축키 Q) |
| Things 3 | 2초 | Quick Entry (단축키) |
| **BRIDGE 현재** | **10초+** | 보드 → + 버튼 → 모달 → 입력 |
| **BRIDGE 목표** | **3초** | Ctrl+K → 제목 입력 → Enter |

**구현:** Personal Board의 "To Do" 블록에 즉시 Task 추가. 기존 `QuickAddTaskModal.tsx` 간소화.

---

### #2. Today View — "오늘에 집중한다"

**왜 킬러인가:**
- 개인 유저가 앱을 여는 #1 이유: "오늘 뭐 하지?"
- "오늘 완료율 80%"라는 숫자가 도파민 → 리텐션

**구성 요소:**
```
┌─────────────────────────────────────────┐
│  ☀️ 2026년 2월 17일                      │
│  "오늘 할 일 7개 중 3개 완료"             │
│  ━━━━━━━━━━━━━━━━━ 43% ━━              │
│                                          │
│  📋 오늘 마감 Task                        │
│  ☐ API 설계 리뷰              Due today  │
│  ☑ 운동 30분                  ✓ 완료     │
│                                          │
│  📌 진행 중 (Doing)                       │
│  ◉ Personal Board 기획       → Doing     │
│                                          │
│  📅 오늘 일정 (PersonalEvent 연동)        │
│  09:00~11:00  기획 작업                   │
│  14:00~15:00  영어 공부                   │
│                                          │
│  [+ 할 일 추가]                           │
└─────────────────────────────────────────┘
```

**기존 재사용:** Task due_date 필터 + PersonalEvent 일간 조회 (이미 구현) + DailyChecklist

---

### #3. Simple Kanban — "3컬럼이면 충분하다"

**왜 킬러인가:**
- To Do / Doing / Done = 직관적
- 드래그 완료 시 쾌감 = 리텐션

**기존 재사용:** Block/Task CRUD 100% 동일. Board(PERSONAL) 생성 + assignee 숨김만 추가.

---

### #4. 캘린더 뷰 — "마감일 한 눈에"

**왜 킬러인가:** 시간 감각 = 개인 생산성의 핵심

**기존 재사용:** `CalendarView.tsx` 100% 재사용 (이미 Feature/Task 렌더링). PersonalEvent도 함께 표시하면 통합 캘린더 완성.

---

### #5. 체크 완료의 쾌감 — "Done의 만족감"

**왜 킬러인가:** 완료 경험 = 리텐션의 핵심. "오늘 12개 완료!" → 자기효능감 → 내일도 접속.

**구현 포인트:** 체크마크 애니메이션 + 진행률 바 즉시 업데이트 + 토스트 메시지

---

## 3. 라이프스타일 킬러 콘텐츠 TOP 3 (이미 구현 / 설계 완료)

### #1. AI 일기 — "대화로 하루를 정리한다" ✅ 구현 완료

**왜 킬러인가:**
- 빈 종이 앞에서의 부담감 제거 → AI가 질문해주니까 쉽게 시작
- 감정 태그 + 월간 뷰 → 자기 이해의 도구
- Day One, 일기 앱과 차별화: **대화형** AI

**이미 구현된 것:**
- DiaryEntry + DiaryMessage 엔티티 (BE)
- CHATTING → COMPLETED 상태 흐름
- AI 질문 5종 + 대화 순서별 응답
- 월간 일기 리스트 + 감정 이모지 (FE)
- 채팅 UI + 완료 뷰 (FE)

**향후 강화 (Pro):**
- 실제 LLM 연동 (현재는 규칙 기반)
- 주간/월간 감정 분석 리포트
- 사진 첨부 (v8.0 기획에 포함)

---

### #2. 개인 일정 — "내 시간을 블로킹한다" ✅ 구현 완료

**왜 킬러인가:**
- 시간 블로킹 = 개인 생산성의 고급 기법
- 캘린더 앱 대체 → BRIDGE 안에서 모든 것 해결

**이미 구현된 것:**
- PersonalEvent 엔티티 (BE) — 제목, 시간, 컬러, all-day
- 주간 7일 그리드 뷰 (FE)
- CRUD + 컬러 피커 (FE)
- 주간 네비게이션 + Today 버튼 (FE)

---

### #3. 습관 트래커 — "매일 반복하는 것을 기록한다" 📋 설계 완료 (v8.0)

**v8.0 기획에 포함:**
- Habit 엔티티 설계 완료 (카테고리, 빈도, 목표 횟수, 스트릭)
- HabitLog 엔티티 설계 완료 (일일 체크)
- DailyChecklist 구조 확장으로 재사용 가능
- **Phase 3에서 구현 예정**

## 6. 듀얼 리텐션 루프

```
┌──────────────────────────────────────────────────┐
│              BRIDGE Personal 듀얼 루프              │
│                                                    │
│   🎯 생산성 루프 (아침~낮)                           │
│   Trigger: 아침에 앱 열기                            │
│   → Action: Today View 확인                        │
│   → Quick Capture: 할 일 추가                       │
│   → Kanban: 드래그하며 진행                          │
│   → Reward: 체크 완료 ✓ + 진행률 상승                │
│   → Investment: 내일 할 일 미리 세팅                  │
│                                                    │
│   🌙 라이프스타일 루프 (저녁)                         │
│   Trigger: 하루 마무리 시간                           │
│   → Action: AI 일기 시작 ("오늘 어땠어?")             │
│   → Conversation: AI와 대화하며 하루 정리              │
│   → Reward: 감정 기록 + 일기 완성                     │
│   → Investment: 내일 일정 확인                        │
│                                                    │
│   → 다음 날 아침 → 생산성 루프 반복                    │
│                                                    │
│   ✨ 주간 연결 포인트:                                │
│   "이번 주 할 일 12개 완료, 일기 5일 작성"             │
│   → AI 주간 요약 (생산성 + 감정 통합 리포트)            │
└──────────────────────────────────────────────────┘
```

## 7. 개인 → 팀 전환 트리거

```
트리거 1: "이 Task를 동료한테 공유하고 싶다"
  → Task 이동 기능 → "팀 보드 만들면 함께 관리할 수 있어요"

트리거 2: "프로젝트가 혼자 감당 안 된다"
  → Feature 5개+ 시 넛지 → "팀으로 확장해보세요"

트리거 3: "미팅 내용을 정리하고 싶다"
  → 미팅 AI 전사는 팀 보드에서만 → 전환 유도

트리거 4: "일기에서 업무 스트레스 언급 반복"
  → AI 일기 분석 → "팀 보드에서 업무 정리해보는 건 어떨까요?" 넛지
  (라이프스타일 → 생산성 → 팀으로의 자연스러운 전환)
```

## 8. 결론

**단일 축 앱의 한계:**
- 생산성 앱: 할 일 끝나면 닫는다 → DAU 한계
- 라이프스타일 앱: 팀 전환 불가 → 수익 한계

**BRIDGE의 듀얼 전략:**
- 아침엔 생산성, 저녁엔 라이프스타일 → **전일 리텐션**
- 개인 Task가 팀으로 흐른다 → **자연스러운 팀 전환**
- 이미 Diary + PersonalEvent 구현 완료 → **빠른 론칭 가능**
