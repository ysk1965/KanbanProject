## 개요

BRIDGE를 팀 협업 도구에서 **개인 생산성 + 라이프스타일 + 팀 협업 통합 플랫폼**으로 확장하는 기획입니다.

### 핵심 가설

> "개인이 매일 쓰는 도구가 되면, 자연스럽게 팀에 도입된다."
> — Slack, Notion, Linear의 성장 공식

### 기존 작업 현황 (v8.0 커밋 기반)

| 완료 | 미완 |
|------|------|
| Diary 도메인 (BE+FE) — AI 대화형 일기 | Board.board_type 확장 |
| PersonalEvent 도메인 (BE+FE) — 개인 일정 | 개인 칸반 (To Do/Doing/Done) |
| `/my-board` 라우트 + 탭 UI | Today View, Quick Capture |
| Dashboard "My Space" 카드 | 개인↔팀 Task 이동 |
| 기획서 v8.0 (일정, 일기, 습관, AI코치, 갤러리) | 팀 전환 유도 |

### 통합 방향

```
v8.0 기존 작업 (라이프스타일)     +     신규 기획 (생산성)
━━━━━━━━━━━━━━━━━━━━━━━━━━━    ━━━━━━━━━━━━━━━━━━━━━━━
• AI 일기 (Diary)                • 개인 칸반 보드 (Kanban)
• 개인 일정 (PersonalSchedule)    • Today View
• /my-board 라우트               • Quick Capture
• Dashboard My Space 카드        • Task 이동 (개인↔팀)
                                 • Board.board_type=PERSONAL
                                 • 캘린더 뷰 (CalendarView 재사용)
                     ↓
          합쳐진 My Space = 생산성 + 라이프스타일
```

## 1. 제품 전략

### 1.1 포지셔닝 변화

```
AS-IS: "소규모 팀을 위한 올인원 협업 플랫폼"
TO-BE: "나의 하루부터 팀의 프로젝트까지, 하나의 BRIDGE로"
```

### 1.2 듀얼 킬러 전략

BRIDGE Personal은 두 가지 사용자 동기를 동시에 잡는다:

```
┌─────────────────────────────────────────────┐
│              My Space                        │
│                                              │
│   🎯 생산성 축                 🌙 라이프스타일 축  │
│   ──────────                 ──────────────   │
│   칸반 보드 (To Do/Doing/Done)  AI 일기         │
│   Quick Capture               개인 일정         │
│   Today View                  (향후) 습관 트래커  │
│   캘린더 뷰                   (향후) 갤러리       │
│   Daily Checklist             (향후) AI 코치     │
│                                              │
│        ↕ Task 이동으로 팀 보드 연결 ↕           │
└─────────────────────────────────────────────┘
```

**왜 둘 다인가?**
- 생산성만 → Todoist, Things 3와 경쟁 (레드오션)
- 라이프스타일만 → 팀 전환 경로 약함
- **둘 다** → "일하는 시간도, 쉬는 시간도 BRIDGE에서" = 전일 리텐션

### 1.3 성장 퍼널

```
┌─────────────────────────────────────────────────────┐
│                    ACQUISITION                       │
│  "AI 일기 앱" + "할 일 관리 앱" → 두 채널 유입       │
├─────────────────────────────────────────────────────┤
│                    ACTIVATION                        │
│  가입 즉시 My Space 생성 → 칸반 + 일기 둘 다 체험     │
├─────────────────────────────────────────────────────┤
│                    RETENTION                         │
│  아침: Today View + Quick Capture (생산성 루프)       │
│  저녁: AI 일기 대화 (라이프스타일 루프)                │
├─────────────────────────────────────────────────────┤
│                    REVENUE                           │
│  Personal Pro ($2.99/월) 또는 팀 전환 ($5/seat/월)    │
├─────────────────────────────────────────────────────┤
│                    REFERRAL                          │
│  "나 이거 쓰는데 우리 팀도 써보자" → 팀 보드 생성     │
└─────────────────────────────────────────────────────┘
```

### 1.4 경쟁 포지셔닝

```
           개인 생산성 강함
                ↑
    Things 3    │    Todoist
                │
  ──────────────┼──────────────→ 협업 강함
                │
    Day One     │    Notion
    (일기 전문)  │    (but 너무 복잡)
                │
           개인 약함
                           ★ BRIDGE 목표 위치:
                             생산성(할 일) + 라이프스타일(일기)
                             + 팀 전환 원클릭
```

## 2. My Space 서비스 구조

### 2.1 탭 구성

```
/my-board

┌─────────────────────────────────────────────────┐
│  My Space                                        │
│                                                   │
│  [📋 칸반] [📅 일정] [📓 일기] [📆 캘린더]          │
│  ────────────────────────────────────────────     │
│                                                   │
│  현재 선택된 탭의 콘텐츠                             │
│                                                   │
└─────────────────────────────────────────────────┘
```

| 탭 | 내용 | 구현 상태 | 인프라 |
|----|------|----------|--------|
| **📋 칸반** | To Do / Doing / Done 3컬럼 | **미구현** | Board(PERSONAL) + Block + Task |
| **📅 일정** | 주간 개인 일정 | **구현 완료** | PersonalEvent 도메인 |
| **📓 일기** | AI 대화형 일기 | **구현 완료** | Diary 도메인 |
| **📆 캘린더** | 월간 캘린더 (Task 마감일) | **미구현** | CalendarView 재사용 |

### 2.2 사용자 여정 (통합)

```
아침 루틴 (생산성 축):
  1. 앱 열기 → Today View에서 오늘 할 일 확인
  2. Quick Capture로 떠오른 할 일 바로 추가
  3. 칸반에서 Doing으로 드래그하며 작업

낮 작업:
  4. 완료 → Done으로 이동 (체크 쾌감 ✓)
  5. 캘린더에서 마감일 확인
  6. 일정 탭에서 시간 블록 관리

저녁 루틴 (라이프스타일 축):
  7. AI 일기 → "오늘 하루 어땠어요?" 대화
  8. 감정 태그 선택 → 일기 완성
  9. 내일 할 일 미리 추가

주간:
  10. 캘린더에서 주간 흐름 확인
  11. (Pro) AI 주간 요약 리포트
```

## 3. 기능 범위 (Scope) — 통합 버전

### 3.1 이미 완료 (v8.0 커밋)

| 기능 | 상태 | 비고 |
|------|------|------|
| AI 일기 (Diary) BE+FE | ✅ 완료 | 대화형 AI, 감정 태그, 월간 뷰 |
| 개인 일정 (PersonalEvent) BE+FE | ✅ 완료 | 주간 뷰, CRUD, 컬러 |
| `/my-board` 라우트 + 탭 구조 | ✅ 완료 | Schedule / Diary 2탭 |
| Dashboard My Space 카드 | ✅ 완료 | 그라데이션 카드 → /my-board |
| 타입 정의 (FE) | ✅ 완료 | PersonalEvent, DiaryDetail 등 |
| API 함수 (FE) | ✅ 완료 | personalEventAPI, diaryAPI |
| 기획서 v8.0 | ✅ 완료 | 6개 모듈 설계 문서 |

### 3.2 MVP 추가 개발 (Phase 1) — 2~3주

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| Board.board_type 확장 | BE 도메인에 PERSONAL 타입 추가 | P0 |
| 개인 칸반 탭 | To Do/Doing/Done 3컬럼 + Task CRUD | P0 |
| Today View | Dashboard 오늘 할 일 위젯 | P0 |
| Quick Capture | 최소 입력 할 일 추가 (Ctrl+K) | P0 |
| 캘린더 탭 | CalendarView 재사용 (Task 마감일 표시) | P1 |
| Personal 가드 | 팀 전용 기능 API 차단 | P1 |

### 3.3 Growth (Phase 2) — 2~3주

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| Task 이동 (개인↔팀) | 개인 Task를 팀 보드로 이동/복사 | P1 |
| Cross-Board 내 할 일 | 모든 보드의 내 Task 통합 뷰 | P1 |
| 개인 Pro 구독 | $2.99/월 개인 구독 모델 (v8.0 기획 반영) | P2 |
| 온보딩 & 전환 유도 | 개인→팀 넛지 + Welcome 흐름 | P2 |

### 3.4 Expansion (Phase 3) — v8.0 기획의 나머지

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 습관 트래커 (Habit) | v8.0에 설계 완료, 구현 대기 | P3 |
| AI 코치 | 대화형 라이프 코칭 | P3 |
| 갤러리 | 일기 사진 모아보기 | P3 |
| 목표 추적 (Goals) | Milestone 리프레이밍 | P3 |
