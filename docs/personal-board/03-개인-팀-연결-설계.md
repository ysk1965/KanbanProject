# 03. 개인 ↔ 팀 연결 설계

> Personal Board와 Team Board는 격리되지 않는다. 데이터가 자유롭게 흐를 수 있어야 한다.

---

## 1. 연결의 원칙

### 1.1 왜 연결이 중요한가?

```
연결 없는 경우 (나쁜 UX):
  "개인 보드에서 정리한 Task를 팀에 공유하려면... 복사해서... 다시 만들고..."
  → 이중 작업 → 짜증 → 하나만 씀 → 가치 하락

연결 있는 경우 (좋은 UX):
  "개인 보드에서 정리한 Task를 팀 보드로 드래그" (또는 한 번 클릭)
  → 자연스러운 전환 → 두 보드 모두 활발히 사용
```

### 1.2 연결 원칙

| 원칙 | 설명 |
|------|------|
| **단방향 이동** | Task는 개인→팀, 팀→개인 양방향으로 이동 가능 |
| **원본 유지** | 이동 시 원본은 삭제되고 대상 보드에 생성 (move, not copy) |
| **복사 옵션** | 원본을 유지하고 싶으면 "복사" 선택 가능 |
| **관계 보존** | Task 이동 시 Checklist, Comment도 함께 이동 |
| **참조 독립** | 이동 후에는 원본 보드와 관계 없음 (참조 끊김) |
| **집계 가능** | Dashboard에서 모든 보드의 내 Task를 통합 조회 |

## 2. 연결 메커니즘

### 2.1 Task 이동 (Move)

```
┌─────────────────────┐          ┌─────────────────────┐
│   Personal Board     │          │   Team Board         │
│                      │          │                      │
│  ┌────────────┐     │   Move   │  ┌────────────┐     │
│  │ Task A     │─────│──────────│──│ Task A     │     │
│  │ + Checklist│     │    →     │  │ + Checklist│     │
│  │ + Comments │     │          │  │ + Comments │     │
│  └────────────┘     │          │  └────────────┘     │
│                      │          │  (assignee 재할당)   │
│  (Task A 삭제됨)     │          │                      │
└─────────────────────┘          └─────────────────────┘
```

**이동 프로세스:**

```java
// TaskMoveService.java (신규)
@Service
@RequiredArgsConstructor
public class TaskMoveService {

    @Transactional
    public TaskResponse moveTask(String taskId, String targetBoardId,
                                  String targetBlockId, String userId) {
        Task task = taskRepository.findById(taskId)
                .orElseThrow(() -> new BusinessException(ErrorCode.TASK_NOT_FOUND));

        Board sourceBoard = task.getBlock().getBoard();
        Board targetBoard = boardRepository.findById(targetBoardId)
                .orElseThrow(() -> new BusinessException(ErrorCode.BOARD_NOT_FOUND));

        // 권한 검증: 소스 보드 MEMBER 이상 + 타겟 보드 MEMBER 이상
        boardMemberService.checkMemberOrAbove(sourceBoard.getId(), userId);
        boardMemberService.checkMemberOrAbove(targetBoard.getId(), userId);

        Block targetBlock = blockRepository.findById(targetBlockId)
                .orElseThrow(() -> new BusinessException(ErrorCode.BLOCK_NOT_FOUND));

        // Task 이동
        task.moveToBlock(targetBlock);

        // Personal → Team: assignee 초기화 (팀에서 재할당 필요)
        if (sourceBoard.isPersonal() && !targetBoard.isPersonal()) {
            task.clearAssignee();  // 팀에서 누가 할지 다시 결정
        }

        // Team → Personal: assignee를 본인으로 자동 세팅
        if (!sourceBoard.isPersonal() && targetBoard.isPersonal()) {
            task.setAssignee(userId);
        }

        // Checklist items도 함께 이동 (FK cascade)
        // Comments도 함께 이동 (FK cascade)

        // 양쪽 보드에 Activity Log 기록
        activityLogService.log(sourceBoard, "TASK_MOVED_OUT", task.getTitle());
        activityLogService.log(targetBoard, "TASK_MOVED_IN", task.getTitle());

        return TaskResponse.from(task);
    }
}
```

### 2.2 Task 복사 (Copy)

```java
@Transactional
public TaskResponse copyTask(String taskId, String targetBoardId,
                              String targetBlockId, String userId) {
    Task source = taskRepository.findById(taskId).orElseThrow(...);

    // 새 Task 생성 (제목에 "(복사)" 미부여 — 원본과 동일)
    Task copy = Task.builder()
            .title(source.getTitle())
            .description(source.getDescription())
            .block(targetBlock)
            .dueDate(source.getDueDate())
            .startDate(source.getStartDate())
            .position(getNextPosition(targetBlock))
            .createdBy(userId)
            .build();
    taskRepository.save(copy);

    // Checklist items 복사
    for (ChecklistItem item : source.getChecklistItems()) {
        ChecklistItem copyItem = ChecklistItem.builder()
                .task(copy)
                .content(item.getContent())
                .isChecked(false)  // 복사본은 미체크 상태
                .position(item.getPosition())
                .build();
        checklistItemRepository.save(copyItem);
    }

    // Comments는 복사하지 않음 (맥락 달라짐)

    return TaskResponse.from(copy);
}
```

### 3.2 통합 조회 API

```java
// UserTaskController.java (신규)
@RestController
@RequestMapping("/api/v1/users/me")
public class UserTaskController {

    // 내 전체 할 일 조회 (모든 보드 통합)
    @GetMapping("/tasks")
    public ResponseEntity<MyTasksResponse> getMyTasks(
            @AuthUser String userId,
            @RequestParam(required = false) String filter,  // "today", "week", "overdue"
            @RequestParam(defaultValue = "due_date") String sort
    ) {
        return ResponseEntity.ok(userTaskService.getMyTasks(userId, filter, sort));
    }
}

// MyTasksResponse.java
public record MyTasksResponse(
    List<BoardTaskGroup> boards,
    int total_count,
    int completed_count,
    int in_progress_count
) {
    public record BoardTaskGroup(
        String board_id,
        String board_name,
        BoardType board_type,
        List<TaskResponse> tasks
    ) {}
}
```

### 3.3 통합 조회 쿼리

```java
// UserTaskService.java
@Service
public class UserTaskService {

    public MyTasksResponse getMyTasks(String userId, String filter, String sort) {
        // 유저가 속한 모든 보드 조회
        List<BoardMember> memberships = boardMemberRepository.findByUserId(userId);

        List<BoardTaskGroup> groups = new ArrayList<>();

        for (BoardMember membership : memberships) {
            Board board = membership.getBoard();

            // 개인 보드: 모든 Task
            // 팀 보드: 나에게 할당된 Task + 내가 만든 Task
            List<Task> tasks;
            if (board.isPersonal()) {
                tasks = taskRepository.findByBoardId(board.getId());
            } else {
                tasks = taskRepository.findByBoardIdAndAssignee(
                    board.getId(), userId
                );
            }

            // 필터 적용
            if ("today".equals(filter)) {
                LocalDate today = LocalDate.now(ZoneOffset.UTC);
                tasks = tasks.stream()
                    .filter(t -> today.equals(t.getDueDate()))
                    .collect(toList());
            }

            if (!tasks.isEmpty()) {
                groups.add(new BoardTaskGroup(
                    board.getId(), board.getName(),
                    board.getBoardType(), tasks.stream().map(TaskResponse::from).toList()
                ));
            }
        }

        return new MyTasksResponse(groups, totalCount, completedCount, inProgressCount);
    }
}
```

### 5.2 Task 이동 시퀀스

```
사용자: Task 우클릭 → "Team Board A로 이동"
    │
    ▼
Frontend: POST /api/v1/tasks/{taskId}/move
    │     body: { target_board_id: "A", target_block_id: "todo" }
    │
    ▼
Backend:
    1. 권한 검증 (양쪽 보드 MEMBER 이상)
    2. Task.block을 target_block으로 변경
    3. assignee 처리:
       - Personal→Team: assignee 초기화
       - Team→Personal: assignee = userId
    4. Activity Log 양쪽 기록
    5. WebSocket 알림 (팀 보드 멤버에게)
    │
    ▼
Frontend:
    1. 소스 보드에서 Task 제거 (optimistic update)
    2. Toast: "Task가 Team Board A로 이동되었습니다"
    3. [되돌리기] 버튼 (5초간 표시)
```

## 6. 엣지 케이스 처리

| 케이스 | 처리 |
|--------|------|
| Team 보드 Task 수 제한 초과 시 | 이동 거부 + 에러 메시지 |
| Personal Pro 아닌데 이동 시 | Standard 제한 내에서만 허용 |
| Feature에 속한 Task 이동 시 | Feature 연결 해제 후 이동 (독립 Task로) |
| 이동 중 동시 수정 발생 | 낙관적 잠금 (version 필드) |
| 되돌리기 요청 | 5초 내 Undo → 원래 보드/블록으로 복귀 |
| 삭제된 보드로 이동 시도 | 404 에러 → "보드가 존재하지 않습니다" |
